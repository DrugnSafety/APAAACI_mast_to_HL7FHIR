# 💬 증상 피드백 수집 가이드

## 1. 대화 설계 원칙

### 1.1 사용자 중심 설계
- **명확성**: 의학 용어 최소화, 일상 언어 사용
- **단계별 진행**: 한 번에 하나의 질문만
- **피드백 제공**: 각 단계 완료 시 확인 메시지
- **오류 관용성**: 잘못된 입력 시 친절한 재입력 안내

### 1.2 정보 수집 전략
```
1단계: 양성 항목 제시
2단계: 증상 있었던 항목 선택
3단계: 나머지 항목 분류
4단계: 최종 확인
5단계: JSON 생성
```

## 2. 대화 예시

### 2.1 표준 흐름
```
봇: 검사에서 양성으로 나온 6개 항목입니다:
    1) 집먼지진드기 (House dust mite)
    2) 고양이 비듬 (Cat dander)
    3) 개 비듬 (Dog dander)
    4) 자작나무 꽃가루 (Birch pollen)
    5) 돼지풀 꽃가루 (Ragweed pollen)
    6) 우유 (Milk)
    
    실제 증상이 있었던 번호를 선택해주세요.

사용자: 1, 2, 4번이요

봇: 감사합니다. 나머지 3개 항목은 어떠신가요?
    3) 개 비듬
    5) 돼지풀 꽃가루
    6) 우유
    
    A: 접촉했지만 증상 없음
    B: 아직 접촉한 적 없음

사용자: 3-A, 5-B, 6-A

봇: 확인하겠습니다:
    ✅ 증상 있음: 집먼지진드기, 고양이 비듬, 자작나무 꽃가루
    ⭕ 증상 없음: 개 비듬, 우유
    ❓ 노출 없음: 돼지풀 꽃가루
    
    맞으신가요?

사용자: 네

봇: 기록이 완료되었습니다!
```

### 2.2 예외 처리
```
사용자: 잘 모르겠어요

봇: 괜찮습니다. 확실한 것만 선택해주세요. 
    기억나지 않는 항목은 '노출 경험 없음'으로 
    분류하겠습니다.
```

## 3. 데이터 품질 확보

### 3.1 응답 검증
| 검증 항목 | 규칙 | 처리 방법 |
|----------|------|----------|
| 번호 범위 | 1 ≤ n ≤ 총 항목 수 | 범위 초과 시 재입력 |
| 중복 선택 | 각 항목은 한 번만 | 중복 제거 후 확인 |
| 분류 완전성 | 모든 항목 분류 필수 | 누락 항목 재질문 |

### 3.2 신뢰도 지표
```json
{
  "response_confidence": {
    "immediate_response": 1.0,
    "after_clarification": 0.8,
    "uncertain": 0.5,
    "no_response": 0.0
  }
}
```

## 5. 개선 사항 추적

### 5.1 메트릭스
- 평균 대화 완료 시간
- 재입력 요청 횟수
- 대화 중단율
- 사용자 만족도
