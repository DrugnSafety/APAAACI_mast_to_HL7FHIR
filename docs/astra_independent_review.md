# gpt-6-astra 독립 검증 결과 (2026-09-18)

작성된 내용을 사람이 하나씩 보기 어려워, 별도 모델(`gpt-6-astra`)에 **적대적 검증**을 맡겼습니다.
영역을 7개로 나눠 "틀렸거나 위험한 것만, 인용과 함께" 지적하도록 했습니다.

## 1. 환자 안전 (critical)

### 응급번호가 한국 119 뿐이었다
미국 거주 환자도 쓰는 서비스인데 응급 안내가 119 로 고정이었습니다.
→ 거주국·답변 언어별로 표기합니다(KR 119 / US 911 / 모르면 둘 다).

**실측:** 미국 거주 + "지금 멜론 먹고 쌕쌕거려요" → "**지금 바로 911(미국)…**", 한국 거주 → "119".

### 천명이 "악화 중"이어야 응급으로 봤다
`trouble breathing or wheezing that is getting worse` — 노출 직후 새로 생긴 천명은 악화가 아직
아니어도 아나필락시스일 수 있습니다.
→ "새로 생긴 천명·가슴답답함은 **악화 중이 아니어도** 해당"으로 고쳤습니다.

### 가벼운 증상엔 응급 언급을 무조건 금지했다
`For these, do NOT mention emergency care at all.` — 두드러기 몇 개라도 목 부종·실신감이 같이
있으면 응급입니다. 규칙 12(응급)와 충돌했습니다.
→ "해당 증상만 **단독·안정·적신호 없음**일 때만" 생략하도록 조건화했습니다.

### 약 권고 금지가 에피네프린 안내를 막을 수 있었다
규칙 10(약 권하지 말 것)과 규칙 12(처방된 에피네프린 즉시 사용)가 충돌했습니다.
→ 규칙 12b 추가: **이미 처방된 에피네프린 사용 안내는 약 조언이 아니며, 절대 생략하지 않는다.**

### 음식 조언이 자가 재섭취로 읽혔다
- `먹은 뒤 증상이 반복되는 음식만 우선 피하세요` → 한 번 뚜렷한 반응이 있었던 음식을 다시 먹어도
  된다는 뜻으로 읽힙니다.
- `생과일에서 증상이 있으면 익혀서 시도해 보세요` → 가정에서의 재섭취 유도.

→ 두 문구를 바꾸고, **"한 번이라도 뚜렷한 반응이 있었다면 스스로 다시 시도하지 마세요"**를
넣었습니다. 음식 템플릿에 아나필락시스 적신호(호흡곤란·목 조임·목소리 변화·실신)와
**즉시 행동**(에피네프린 사용 + 119/911)을 추가했습니다. 피부 증상이 없어도 생길 수 있다는 점도 밝힙니다.

**실측:** "작년에 새우 먹고 한 번 온몸에 두드러기" → "알레르기가 아니라고 단정할 수 없어요 …
**새우를 다시 일부러 먹어보지 마세요**".

## 3. 식물 동정 (major)

검사 패널의 한국어 이름은 제조사 기준이라, **이름이 비슷한 국내 식물과 다른 종**인 경우가 있습니다.
여기에 국내 개화 시기를 그대로 붙이면 환자가 주변 식물을 검사 항원으로 오인합니다.

| 항원 | 실제 | 국내 동명 식물 |
|---|---|---|
| Acacia | 아카시아속 | 아까시나무 = *Robinia pseudoacacia* (다른 속) |
| Velvet grass | *Holcus lanatus* | 잔디 = *Zoysia japonica* |
| English plantain | *Plantago lanceolata* (창질경이) | 질경이 = *P. asiatica* |
| White ash | *Fraxinus americana* (북미) | 물푸레나무 = *F. rhynchophylla* |

→ `species_caution_ko` 를 넣어 항원 지식에 함께 실립니다.

**텍사스 마운틴 시더**: `notable_plants` 에 `Japanese cedar` 를 넣었는데, 마운틴 시더는
*Juniperus ashei* 이고 삼나무는 *Cryptomeria japonica* 로 **다른 식물**입니다(같은 측백나무과일 뿐).
→ 대표 식물에서 빼고, 본문에서 "다른 식물이지만 같은 과라 교차반응 보고"로 정정했습니다.
예보 매핑도 `JUNIPER` 등을 **교차반응군**으로 분리해, 답변에서 "검사한 식물이 아니라 같은 과 예보"
라고 밝힙니다.

## 4. 달력 보정

- **한국 수목 3~5월 ↔ 자체 삼나무 표 2~4월** 모순 → 전국 수목을 **2~5월**로, 제주 2월 시작을 명시.
- **캘리포니아**: 수목 1~4 → 1~6월(올리브·참나무), 잔디 3~6 → 3~10월(버뮤다그래스 등 난지형).
- **남동부**: 잔디 4~9 → 3~10월, 플로리다 남부는 사실상 연중임을 하한으로 표시.
- **올리브**: "지중해" 한정 → 미국 남서부·캘리포니아 조경/재배지 노출도 포함.

## 5. 성분군 정정

- **저장단백**: 2S 알부민만 다루면서 저장단백 전체처럼 설명 → 7S vicilin·11S legumin 은 별개임을 명시.
- **포유류 고기**: 혈청알부민으로만 설명 → **알파갈(alpha-gal) 증후군** 추가.
  진드기 물림 후 발생, **충분히 익힌 고기에도 반응**, 섭취 3~6시간 뒤 늦게 나타남. 미국 환자에게 특히 중요합니다.
- **동물**: "침실 제한이 **가장 효과가 큽니다**" 최상급 → 보조 조치로 완화(집 안에 있으면 옷·공기로 퍼짐).

## 7. 수정하다 낸 회귀 2건 (실측으로 발견해 다시 고침)

astra 지적을 반영한 뒤 실서버로 확인하다가 **제가 만든 회귀**를 찾았습니다.

1. **언어 혼입 재발**: 응급번호를 `911 (USA)` 같은 영어 라벨로 프롬프트 끝에 넣자, 한국어 답변의
   마지막 문장이 영어로 나오고 구자라트 문자(`હાલ`)까지 섞였습니다.
   → 번호를 답변 언어로 표기하고, 프롬프트 **맨 끝에서 언어를 다시 못 박았습니다**.
2. **모델이 규칙을 소리 내어 생각함**: 규칙이 길어지자 답변 끝에
   `"is allowed per emergency rule ... rescue inhaler no because medication advice. Final."` 이 붙었습니다.
   → "환자에게 할 답만 쓰고, 규칙을 인용·언급·추론하지 말라"는 출력 규칙을 추가했습니다.

**재검증:** 5개 질문 × 3회 = 15회에서 다른 문자·영어 문장·메타 발화 **0건**.

## 반영하지 않은 지적

- **한국 권역 세분화(제주 별도 달력)**: 종별 표에 삼나무 2~4월이 있고 전국 수목에 2월을 넣어
  당장의 누락은 막았습니다. 제주를 별도 권역으로 나누는 것은 근거 자료를 더 모은 뒤가 맞다고 봅니다.
- **권역별 '수목/잔디/잡초' 단위의 한계**: 텍사스 환자의 자작나무에도 그 권역 수목 시즌이 붙습니다.
  종 단위 정밀도는 실시간 예보(Google Pollen API)를 켜야 얻을 수 있어, 한계로 문서화했습니다.
