# 비용 모델 입력 반영 · 반응 평가 시점 적용 (8차)

제공된 입력을 모두 반영했다. **비용 축이 가상 점수에서 실제 계산으로 전환**되어, 이제 4개 축 중 이상반응·편의성만 가상으로 남았다.

---

## 1. 반영된 약가 (급여 상한금액, 2026-08 제공 기준)

| 약제 | 상한금액 | 계산 방식 |
|---|---|---|
| Omalizumab (졸레어) | 150mg 216,755원 · 75mg 114,440원 | IgE×체중 용량표(확인 완료) → 회당 용량을 150/75mg 조합으로 환산 |
| Mepolizumab (누칼라) | 1,280,000원/회 | 4주 간격, 연 13회 |
| Reslizumab (싱케어) | 399,552원 | **100mg 바이알 가정** — 3mg/kg×체중을 바이알 올림(잔량 폐기 반영). 규격 확인 필요 ⚠ |
| Benralizumab (파센라) | 2,842,543원/회 | 첫해 8회 / 유지 6.5회 |
| Dupilumab (듀피젠트) | 200mg 571,862원 · 300mg 675,753원 | 요법 자동 분기(아래) · 초회 부하 2배(1회분 추가) 반영 |
| Tezepelumab (테즈파이어) | **비급여** | 비용 산정 제외 표시 + 비용 축 0점 처리 |

### Dupilumab 요법 분기 (제공 스케줄 반영)

- 일반 중증 천식: 초회 400mg(200mg×2) → 200mg q2w → 200mg 단가 적용
- OCS 의존(또는 아토피피부염·비용종 동반): 초회 600mg(300mg×2) → 300mg q2w → 300mg 단가 적용
- 데모 구현: 유지 OCS 입력 >0이면 300mg 요법 자동 선택. 동반질환(아토피·비용종) 기준 분기는 비용종 입력 추가 시 확장 가능.

### 비용 표시 3종 (카드별)

```
평가 시점(W주)까지 약제비 · 본인부담(입력 %, 기본 30) · 첫해 약제비   — 모두 표시가 기준
```

검증 예 (기본 환자 65kg·IgE 120·OCS 7.5): benralizumab 16주까지 3회 × 2,842,543 = 8,527,629원(본인부담 30% 약 256만원), 첫해 8회 22,740,344원. mepolizumab 16주 4회 5,120,000원, 첫해 16,640,000원. omalizumab 300mg q4w → 회당 433,510원, 첫해 5,635,630원.

### 비용 축 점수 (실제 계산 전환)

```
s_비용(d) = 100 × min(첫해 약제비) ÷ 첫해 약제비(d)   (최저가 = 100)
tezepelumab(비급여) = 0점 (전액 본인부담·가격 미상 — 명시적 처리)
```

주의 두 가지: ① 기준 최저가는 전 약제(비적격 포함) 중 최저로 계산 — 적격군 내 최저로 바꿀지는 운영위 선택 사항. ② 표시 비용은 약제비만 포함(투여 행위료·진찰료·검사비 제외), 표시가 기준(RSA 환급은 공단-제약사 간 사안).

## 2. 반응 평가 시점 3~6개월 — 적용 방식

"보통 3~6개월에 평가"를 도구에는 **선택 파라미터**로 구현했다:

- **입력**: 반응 평가 시점 선택 — 12주(3개월) / 16주(4개월, 기본값) / 24주(6개월)
- **비용 창 연동**: 선택한 시점까지의 누적 약제비가 카드의 주 비용 표시가 된다. 투여 주기가 달라 시점 선택이 약제 간 비교에 실질 영향을 준다(예: 16주 기준 benra 3회 vs dupi 8회+부하).
- **진료 흐름 연동**: 평가 시점 도달 = Response evaluation 도구(MCID 판정)로 넘어가는 시점 — "Prediction(시작 전) → 3~6개월 → Response evaluation(파정) → KQ7 감량/KQ8 교체"의 시간축이 완성된다.
- **향후 정교화**: ① 약제별 기본값 차등 가능(예: omalizumab은 16주 평가가 관행·급여 기준과 연결, anti-IL-5류는 4개월 이후) — 운영위에서 약제별 권장 시점을 정하면 기본값을 약제별로 주입. ② 지침 본문·급여 고시의 지속투여 평가 시점이 확정되면 그 값을 기본값으로 교체. ③ MCID 근거의 시점 창(KQ PICOTS 12~60주)과 정합하므로 12~24주 평가에 MCID 기준을 적용하는 것은 근거 범위 안이다.

## 3. 처리 현황 정리

| 입력 | 상태 |
|---|---|
| 의료진 설문 원자료 | 추후 구현 (합의) — 그때까지 2:1 근사 토글 유지 |
| 약가 6종 | ✅ 반영 (비용 축 실계산 전환) |
| Dupilumab 스케줄 | ✅ 반영 (요법 자동 분기 + 초회 부하 2배) |
| Omalizumab 용량표 | ✅ 확인 완료 처리 (캐비앳 문구 제거) |
| 반응 평가 시점 | ✅ 12/16/24주 선택 구현 (기본 16주) |

## 남은 확인 사항

1. Reslizumab 바이알 규격(100mg 가정) 및 잔량 폐기 vs mg 단위 산정 방식
2. 비용 축 기준 최저가: 전 약제 vs 적격군 내 (운영위)
3. Tezepelumab 비급여 0점 처리의 수용성 (대안: 비급여 약제는 비용 축 제외 후 재정규화 — 단 '부담 큼' 정보 손실)
4. 투여 행위료·진찰료 포함 여부 (현재 약제비만)
5. 실손보험 모듈 (설계 완료, 구현 대기)
