1 · Main Idea

메인 아이디어

"진료지침의 근거를, 개별 환자의 맥락에서, 순위 단정 없이, 투명하게."
  • 순위가 아니라 병렬 카드 — 약제 간 head-to-head 근거가 없으므로 우열을 단정하지 않는다. 적격 약제의 근거를 동일 형식 카드로 병렬 표시하고, 선호도 점수는 '우선 검토 후보' 그룹핑까지만, 산출 내역은 전부 공개.
  • 3계층 구조 — ① 사실(위약 대비 효과·확실성·MCID 판정) ② 매칭(환자 표현형·기저치와 근거의 부합) ③ 결정(선호 가중·공유 의사결정). 위로 갈수록 가치 판단이 개입하고, 계층별 규칙이 분리된다.
  • 결측·불확실성의 정직한 표시 — '근거 없음'(제외·재정규화), '효과 없음의 근거'(0점), '비급여'(실부담 계산 또는 축 제외)를 구분하고 사유를 화면에 노출.
  • 이중 모드 — 의료진 보기(전 지표·CI·GRADE·계산 상세) / 환자 보기(쉬운 문장·자기 기준 전후 비교·점수 숨김·"의사와 상의" 프레임).
  • 성격 — 진료 판단 보조·교육 도구. 치료를 지시하지 않음(SaMD 비해당 설계 원칙), 입력 미저장.

3-A · Eligibility

적격성 필터 (결정적 규칙)

각 약제의 작용 기전상 표적 표현형과 급여·허가 조건을 단순화한 통과/탈락 게이트다.

  • Omalizumab — 통년성 알레르겐 감작 = 예 AND 총 IgE ≥ 30 IU/mL (용량표 범위 IgE 30~1300 · 체중 20~150kg 밖이면 "용량표 범위 밖" 별도 표시)
  • Mepolizumab — 혈중 호산구 ≥ 150/µL (≥300이면 '부합 높음' 배지)
  • Reslizumab — 혈중 호산구 ≥ 400/µL
  • Benralizumab — 혈중 호산구 ≥ 150/µL (≥300은 하위군 근거 일관 '부합 높음' · 150–299는 불확실 표기)
  • Dupilumab — 호산구 ≥ 150/µL or FeNO ≥ 25 ppb or OCS 의존
  • Tezepelumab — 표현형 무관 (부합 판정 불필요)

운영 원칙:

  • 규칙은 데모 단순화판 — 게시 전 허가사항·급여 고시 원문 대조 필요.
  • 비적격 약제는 숨기지 않고 회색 카드 + 탈락 사유로 표시(필터 투명성).
  • 문턱값(150/300/400 등)은 KQ 하위군 분석·급여 기준 출처와 함께 관리.

Q. "IgE·통년성 감작 항목 때문에 omalizumab이 무조건 점수가 높다?"

  • 적격성 필터는 점수에 전혀 기여하지 않는다 — 통과/탈락뿐이다. 해당 항목 때문에 점수가 오르는 구조가 아니다.
  • 실제 원인은 효과 데이터: KQ1의 omalizumab 점추정치는 5개 지표 중 4개(OCS −85.2% · ACQ −0.51 · FEV1 +0.22L · AQLQ +0.64)에서 MCID를 넘는 유일한 약제다. 초과확률 방식은 역치를 넘는 점추정치에 0.5 이상을 주므로 효과 축이 앞선다.
  • 문제는 이 4개 지표의 확실성이 모두 낮음(⊕⊕◯◯)인데 무보정 초과확률은 이를 벌점하지 않았다는 것 — "크지만 불확실한 추정치"가 "정밀하지만 작은 추정치"를 항상 이겼다. 지적의 정당한 핵심.
  • v2.1 보정: GRADE 확실성 계수(3-C) 도입으로 omalizumab 효과 축 76 → 62점. 여전히 높지만 '점추정치 크기'와 '낮은 확실성 벌점'이 모두 수식에 명시된다.
  • 1단계 알고리즘의 omalizumab 1순위 관행과 충돌하지 않으며, 도구는 어차피 순위 단정이 아닌 '우선 검토 후보' 그룹핑만 제공한다. 계수 값은 캘리브레이션 대상(§6).

3-B · Absolute Effects

환자 기저치 결합 절대효과 (표시 계층)

상대효과와 95% CI를 환자 기저치에 적용해 "그 환자의 숫자"로 보여준다 — GRADE SoF의 절대효과 산출과 동일 기법.

  • 악화 (RAR형) — 기저 악화 × [RAR, CI] → "연 3.0회 → 약 1.4회 (CI 0.9–1.8)". omalizumab 악화는 발생률비(event RR)라 횟수 환산 불성립 → 위험 감소율 표기.
  • OCS 감량 (%MD형) — 기저 용량 × (1 + MD/100), 하한 0 절단 → "7.5 → 약 3.8 mg/day".
  • ACQ · FEV1 · AQLQ (MD형) — MD 자체가 절대량 → 그대로 표시(기저치는 도달값 문장에만 사용).
  • 라벨 3원칙 — ① 이 CI는 평균 효과의 신뢰구간(개인 예측구간 아님) ② 상대효과 일정(portability) 가정 명시 ③ 기저값 측정 오차·평균 회귀 주의.

Q. "시험 평균과 다른 환자에게 시험의 상대효과를 적용하는 것은 논리적 모순인가?"

  • 모순이 아니라 공개된 가정이다. 시험이 추정한 것은 "기저 2.2회 집단에서 55% 감소"가 아니라 "상대적으로 55% 감소"라는 비율이며, 상대효과는 기저 위험이 달라도 비교적 안정적이라는 것이 메타역학의 반복된 관찰이다. GRADE SoF가 "여러 기저 위험 × 동일 상대효과"로 절대효과를 제시하는 근거와 같다.
  • 절대효과(횟수 차이)야말로 기저치에 따라 크게 달라지므로, 시험의 절대효과를 그대로 옮기는 쪽이 오히려 논리적으로 취약하다.
  • 가정이 약해지는 구간: 환자 기저치가 시험 모집단 범위를 크게 벗어나는 경우(예: 연 10회 악화). 보완책 — 시험 모집단 기저치 범위 표기 + 범위 밖 입력 외삽 경고(구현 예정, §6).
  • MD형 지표는 반대 주의: "ACQ −0.42"는 고정 절대량 가정이므로 기저 ACQ가 낮은 환자에겐 과대 표시 가능(천장/바닥 효과) — 라벨 3원칙과 함께 안내.

3-C · Scoring

지표 점수화 — MCID 초과확률 × GRADE 확실성 계수

직관. 각 지표에 "참효과가 델파이 합의 MCID를 넘을 확률"을 점수로 준다. 점추정치만 쓰면 CI가 버려지고, 배수(효과÷MCID)를 쓰면 극단값이 지배한다. 초과확률은 CI의 폭과 위치를 한 번에 반영하며 자연히 0~1로 유계다.

SE 복원:   SE = (CI상한 − CI하한) / 3.92          (비율 지표는 ln 스케일)
비율 지표(악화):         s₀ = Φ( (ln 0.8 − ln v) / SE_ln )
음수-우호 MD(OCS·ACQ):   s₀ = Φ( (MCID − v) / SE )      MCID: OCS −50% · ACQ −0.5
양수-우호 MD(FEV1·AQLQ): s₀ = Φ( (v − MCID) / SE )      MCID: FEV1 +0.2L · AQLQ +0.5
확실성 보정: s = s₀ × CERT(GRADE)
CERT = 높음 1.00 · 중등도 0.90 · 낮음 0.75 · 매우낮음 0.55

기호 설명

기호의미
v그 지표의 KQ 근거 프로파일 점추정치(메타분석 요약효과) 자체 — "환자에게 적용된 값"이 아니라 "메타분석이 보고한 값". 예: benralizumab OCS의 v = −50(%MD).
3.9295% CI로부터 SE를 역산하는 상수. 95% CI = 점추정치 ± 1.96×SE이므로 CI 폭 = 2×1.96×SE = 3.92×SE → SE = (상한−하한)/3.92. Cochrane Handbook의 표준 SE 복원 공식과 동일.
ln 0.8악화(AAER)는 비율 지표(RR)라 로그 스케일에서 정규 근사(로그정규 근사 — 비율은 로그를 취해야 0.5와 2.0이 1로부터 대칭). MCID 0.8도 로그를 취해 ln(v)와 같은 척도로 맞춘다. MD 지표(OCS·ACQ·FEV1·AQLQ)는 로그를 쓰지 않는다.
Φ표준정규분포 누적분포함수(CDF). z = (역치−점추정치)/SE를 "참효과가 MCID를 넘을 확률"로 해석 — 점추정치를 분포 중심, SE를 퍼짐으로 두는 근사(평평한 사전분포 가정의 베이지안 근사와 사실상 동일, GRADE 문헌에서도 통용).

예: benralizumab 악화(RAR 0.45, CI 0.29–0.60) → SEln=0.186 → z=+3.10 → Φ(3.10)=0.999 — "참 위험감소 효과가 MCID를 넘을 확률 99.9%".

확실성 계수를 도입한 이유 (v2.1). 무보정 초과확률의 두 편향 — ① 점추정치가 MCID 미달인 약제는 CI가 넓을수록 s₀가 0.5로 끌려 올라간다(불확실성 보상). ② 점추정치가 MCID를 넘으면 확실성이 낮아도 벌점이 없다(omalizumab 사례). CERT는 두 경우 모두 낮은 확실성을 일괄 감점해 "정밀한 근거 > 부정확한 근거" 순서를 복원한다. 계수 값은 운영 결정·캘리브레이션 대상.

계산 예시 4건 (KQ 실측치)

① 전형 — benralizumab 악화 RAR 0.45 (0.29–0.60) · ⊕⊕⊕◯
SEln = (ln0.60−ln0.29)/3.92 = 0.186 → z = (ln0.8−ln0.45)/0.186 = +3.10 → s₀ = Φ(3.10) = 0.999 → s = 0.999×0.90 = 0.899. 점추정치가 MCID를 여유 있게 넘고 CI도 좁아 만점에 근접.
② 경계 — benralizumab OCS −50% (−64.1~−35.9) · ⊕⊕⊕◯
SE = 28.2/3.92 = 7.19 → z = (−50−(−50))/7.19 = 0 → s₀ = 0.500 → s = 0.45. 점추정치가 정확히 MCID 위 — "넘을 확률 반반"이라는 직관과 일치.
③ 크지만 불확실 — omalizumab OCS −85.2% (−153.0~−14.3) · ⊕⊕◯◯
SE = 138.7/3.92 = 35.4 → z = (−50+85.2)/35.4 = +0.99 → s₀ = 0.840 → s = 0.840×0.75 = 0.630. 점추정치는 MCID의 1.7배지만 CI가 매우 넓다. v2까지 0.84를 그대로 받던 것이 v2.1에서 감점.
④ 명확한 미달 — dupilumab OCS −28.2% (−36.9~−19.5) · ⊕⊕⊕◯
SE = 4.44 → z = (−50+28.2)/4.44 = −4.91 → s₀ ≈ 0 → s = 0. CI가 좁아 "MCID 미달"이 거의 확실 — 0점이 정당.

결측 구분 규칙 — 효과 없음의 근거 ≠ 근거의 부재

  • tezepelumab OCS = 0점 (효과 없음의 근거) — KQ6 원문 재확인 결과 OCS 관련 유일 지표는 "OCS ≤5mg/day 도달 비율 RR 1.06 (0.87–1.30)" (SOURCE 단일연구 · ⊕⊕⊕◯ · 위약 1000명당 697→738). 타 약제의 %감량 MD와 측정지표가 다르고 유의하지 않다 — OCS-감량 전용 시험에서 효과 미확인이므로 0점 정당. 카드에 수치·출처 그대로 표기. ※ SOURCE = tezepelumab OCS-감량 전용 3상 RCT(OCS 의존 환자, N≈150). 근거 프로파일 범위에 %감량 MD 없음 확인 → 미결 해소.
  • reslizumab OCS = 축 제외 + 재정규화 (근거의 부재) — OCS-sparing 시험 자체가 없음. 0점을 주면 "효과 없음"으로 오독되므로 지표를 빼고 남은 가중치 합으로 나눈다.

  • 환자는 증상 조절(0.335) 최우선, 의료진은 악화·OCS 최우선 — I-7 인식 차이의 정량화이자 관점 병기(3-H)의 근거.

3-G · MCDA

MCDA 총점 — 전체 파이프라인과 계산 예시

총점(d) = w_효과×s_효과 + w_비용×s_비용 + w_이상반응×s_AE + w_편의×s_편의
w_i = 축_i 배분값 ÷ (4개 축 배분값의 합)   — 기본 프리셋 (35,25,25,15, 합 100) = 환자 조사 평균 근사
축 제외 시(비급여 가격 미상 · 입원+실손): 총점 = 남은 축 가중합 ÷ (1 − 제외 축 w)

네 축은 EtD 프레임의 기준 축약(효과 desirable effects · 비용 resource use · 이상반응 undesirable effects · 편의 acceptability/feasibility). 축 내부 점수가 전부 0~100으로 정규화되어 있으므로 가중합이 곧 총점.

w는 왜 "4축 배분 ÷ 합계"인가

사용자는 화면 4개 칸(천식 개선 효과·경제적 부담·약제 이상반응·사용 편의성)에 점수를 입력한다 — "100점 파이를 나눠 담는" 형태의 UI. 이 입력값은 그 자체로는 임의 단위의 배분량일 뿐 가중치가 아니다: 가중합 공식이 성립하려면 w들의 합이 정확히 1이어야 한다. 그래서 네 입력값의 실제 합으로 각 값을 나눠 비율로 바꾼다. 기본 프리셋 (35,25,25,15)는 합이 정확히 100이라 결과가 "÷100"과 같지만, 사용자가 합이 100이 아니게 입력해도(예: 40/30/20/20, 합 110) 그 합(110)으로 나눠 w=(0.364, 0.273, 0.182, 0.182)로 자동 정규화된다 — 화면에 "배분 합계: 110점 (100점이 아니면 비율로 자동 정규화)"라고 표시. 정규화 기준은 "입력값의 합"이며 100은 기본 프리셋의 값일 뿐이다.

u(3-D, 지표 내부 가중)와 w(축 간 가중) — 서로 다른 층, w는 항상 환자 입력

  • ① 지표 내부 가중 u — 5개 임상지표(악화·OCS·ACQ·FEV1·AQLQ) 배분으로 s_효과 하나의 숫자를 만든다(3-D). 출처를 '환자 설문/의료진 설문/균등/직접 입력' 중 토글로 선택 가능.
  • ② 축 간 가중 w — 4개 축 배분. "① 환자 선호" 입력값 하나뿐이며 의료진용 w는 별도로 없다.

s_효과 안에는 이미 (환자 또는 의료진) 가중이 반영돼 있고, 총점을 낼 때 w로 또 한 번 환자 가중이 반영된다 — 하지만 u의 출처는 의료진으로 바꿀 수 있어도 w는 항상 환자의 4축 배분 하나다. "의료진 가중치를 반영한 별도의 총점"은 산출되지 않는다. 유일한 예외인 3-H '관점 병기'는 u만 pt↔med로 바꾸고(w는 그대로) 1순위가 바뀌는지만 비교한다 — 총점 자체를 의료진 버전으로 별도 산출하지는 않는다. 이는 3-H "가치 판단의 기본 주인은 환자(EtD 원칙)"라는 설계 의도이며, 의료진의 축 간(4축) 선호를 직접 물은 설문 문항이 없어(I-5는 지표 내부 가중과 축 참고값만 제공) 구현 근거 데이터도 현재는 없다.

3-H · Dual Perspective

관점 병기 (합성 금지)

환자 가중과 의료진 가중을 평균하지 않는다. 각각의 1순위를 계산해 일치/상이("환자 A vs 의료진 B — 상담 포인트")를 표시한다. 가치 판단의 기본 주인은 환자(EtD 원칙), 불일치는 공유 의사결정의 대화 재료. 환자 보기에서는 의료진·고급 설정 전체가 숨겨진다.

7 · Glossary

부록 — 용어

  • SOURCE 시험 — tezepelumab의 경구스테로이드(OCS) 감량 전용 3상 RCT(OCS 의존 중증 천식 · N≈150). KQ6의 OCS 지표("≤5mg/day 도달 비율")가 이 단일 시험에서 나오며, NAVIGATOR와 달리 OCS 감량 우월성을 보이지 못했다.
  • reslizumab 규격 — 제품이 유통되는 바이알 단위 용량. 국내 급여 등재는 100mg/10mL 단일 규격(제공 상한가 기준)이므로 4mg/kg 처방량을 100mg 단위로 맞추는 내림 규칙이 필요하다. 해외 일부 시장의 25mg 소용량이 도입되면 내림 오차가 줄어든다.
  • MCID — 최소 임상적 중요 차이. 본 지침 델파이 3라운드 합의값: 악화 RAR 0.8 · OCS −50% · ACQ −0.5 · FEV1 +0.2L · AQLQ +0.5.
