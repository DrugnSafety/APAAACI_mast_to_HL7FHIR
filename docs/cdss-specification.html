1 · Main Idea

메인 아이디어

"진료지침의 근거를, 개별 환자의 맥락에서, 순위 단정 없이, 투명하게."
  • 순위가 아니라 병렬 카드 — 약제 간 head-to-head 근거가 없으므로 우열을 단정하지 않는다. 적격 약제의 근거를 동일 형식 카드로 병렬 표시하고, 선호도 점수는 '우선 검토 후보' 그룹핑까지만, 산출 내역은 전부 공개.
  • 3계층 구조 — ① 사실(위약 대비 효과·확실성·MCID 판정) ② 매칭(환자 표현형·기저치와 근거의 부합) ③ 결정(선호 가중·공유 의사결정). 위로 갈수록 가치 판단이 개입하고, 계층별 규칙이 분리된다.
  • 결측·불확실성의 정직한 표시 — '근거 없음'(제외·재정규화), '효과 없음의 근거'(0점), '비급여'(실부담 계산 또는 축 제외)를 구분하고 사유를 화면에 노출.
  • 이중 모드 — 의료진 보기(전 지표·CI·GRADE·계산 상세) / 환자 보기(쉬운 문장·자기 기준 전후 비교·점수 숨김·"의사와 상의" 프레임).
  • 성격 — 진료 판단 보조·교육 도구. 치료를 지시하지 않음(SaMD 비해당 설계 원칙), 입력 미저장.

입력 모델

계층항목소비처
① 임상 지표호산구 · FeNO · 총 IgE · 통년성 감작 · 12개월 악화 횟수 · 유지 OCS · 체중적격성 · 절대효과 환산 · 자동 재가중 · 용량 계산
② 평가 설정반응 평가 시점 (12/16/24주, 기본 16주)비용 주 표시 창 · Response evaluation 연계
③ 비용·보험 (접힘)본인부담률(기관 종별, 기본 상급종합 60%) · 실손 → [투여 환경 → 외래 시 공제·자기부담률·회당 한도] · 테즈파이어 예상가비용 모델

3 · Algorithms

주요 알고리즘

A. 적격성 필터 (결정적 규칙)

표현형·허가 기준의 단순화 규칙(원문 대조 필요): omalizumab = 감작+IgE≥30 · mepolizumab = 호산구≥150 · reslizumab = ≥400 · benralizumab = ≥150(≥300 부합 높음) · dupilumab = 호산구≥150 or FeNO≥25 or OCS 의존 · tezepelumab = 표현형 무관. 비적격은 회색 카드+사유로 표시(숨기지 않음).

B. 환자 기저치 결합 절대효과 (표시 계층)

상대효과와 95% CI를 기저치에 적용: "연 3.0회 → 약 1.4회 (CI 0.9–1.8)", OCS "7.5 → 약 3.8 mg/day". GRADE SoF 절대효과와 동일 기법. 라벨 3원칙: 평균 효과의 CI(개인 예측구간 아님) · 상대효과 일정 가정 명시 · 기저값 측정 오차 주의. omalizumab 악화는 event RR이라 위험 감소율로 표기.

C. 지표 점수화 — MCID 초과확률 (확정)

비율(악화):        SE=(ln hi − ln lo)/3.92,  s = Φ((ln 0.8 − ln v)/SE)
음수-우호 MD(OCS·ACQ): SE=(hi−lo)/3.92,     s = Φ((MCID − v)/SE)
양수-우호 MD(FEV1·AQLQ):                    s = Φ((v − MCID)/SE)

극단값 지배(0~1 유계)와 점추정치 편중(CI 통합)을 동시에 해결. 결측 구분: 측정지표 이질(teze OCS) = 0점+사유 / 적격 RCT 부재(resli OCS) = 가중치 제외·재정규화.

D. 효과 축 합성 — 가중 출처와 자동 재가중

지표환자 설문 (표7.2 · N=108)의료진 설문 (I-5 원자료 · N=52)균등
악화0.1470.228 (평균 8.73 · 1순위 37/52)0.2
OCS0.2140.220 (8.42)0.2
조절도 ACQ0.3350.194 (7.44)0.2
폐기능 FEV10.1580.188 (7.21)0.2
삶의 질 AQLQ0.1460.171 (6.56)0.2

환자는 증상(조절도) 최우선, 의료진은 악화·OCS 최우선 — I-7의 인식 차이가 가중치로 정량화된다. 설문의 부작용(6.62)·접근성(7.10)은 이상반응·비용 축의 축 수준 참고값, 일반 QoL(5.23)은 미사용. '직접 입력' = 진료 의사 개인 배분. 자동 재가중(확정): 악화 ≥3회 → 악화 ×2, OCS 사용 → OCS ×2 후 재정규화(내역 노출).

E. 비용 모델

  • 약가(2026-08 상한가): 졸레어 150/75mg 216,755/114,440 · 누칼라 1,280,000 · 싱케어 100mg 399,552 · 파센라 2,842,543 · 듀피젠트 200/300mg 571,862/675,753 · 테즈파이어 비급여.
  • 용량·스케줄: omalizumab IgE×체중 용량표(확인 완료) · reslizumab 4mg/kg, 100mg 바이알 내림(잔량 미발생) · benralizumab 첫해 8회/유지 6.5회 · dupilumab 요법 자동 분기(OCS 의존 600→300mg q2w / 일반 400→200mg q2w, 초회 부하 2배) · mepo·teze 13회/년.
  • 기간 창: 주 표시 = 반응 평가 시점까지 · 부 표시 = 첫 12개월.
  • 실부담: 급여 = 표시가 × 기관 종별 본인부담률(상급종합 60% 기본, 산정특례 미적용 전제) · 비급여 = 예상가 100%.
  • 실손: 외래+가입 시 회당 실부담 = 본인부담금 − min(max(본인부담금 − max(정액공제, 정률자기부담), 0), 외래 통원 회당 한도). 입원+가입 시 비용 축 자동 제외(재정규화).
  • 비용 축 점수 = 100 × min(적격군 내 첫해 실부담) ÷ 첫해 실부담. 비급여 예상가 미입력 시 축 제외·재정규화.

F. MCDA 총점

총점(d) = w효과×s효과 + w비용×s비용 + wAE×s_AE + w편의×s편의
비용 축 제외 시: 남은 축 가중합 ÷ (1 − w비용)

s_AE = 전 약제 동일 90점(전 KQ에서 위약 대비 유의 초과 없음 — 차등 근거 없음). s_편의 = 투여 간격·경로 기반(마지막 가상 축).

G. 관점 병기 (합성 금지)

환자·의료진 가중을 평균하지 않고 각각의 1순위를 비교해 관점 일치/상이를 표시 — 불일치는 공유 의사결정의 대화 재료. 환자 보기에서는 의료진·고급 설정 전체 숨김.

H. NMA 비교 모듈 (예정)

공통 하위군(호산구 ≥300 주 분석 · OCS 의존 시험군 부 분석) 제한 네트워크의 비교 참고치를 부합 환자에게만 활성화. 별 모양 네트워크(일치성 검정 불가)·이행성 한계 명시. KQ7·KQ8은 네트워크 비대상 — Response evaluation의 후속 경로.
