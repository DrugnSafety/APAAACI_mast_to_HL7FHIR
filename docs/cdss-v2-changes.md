# CDSS 데모 변경 내역 — v2 → v2.1 (2026-08-18)

파일: `prediction-tool-demo.html` · 사양: `cdss-specification.md`(.html)

## v2.1 (이번 회차)

### 1. MCID 초과확률 × GRADE 확실성 계수 (신설)

- 지표 점수 `s = Φ(z) × CERT(GRADE)`, CERT = 높음 1.0 · 중등도 0.9 · 낮음 0.75 · 매우낮음 0.55.
- 배경: "omalizumab이 항상 점수가 높다"는 지적의 원인 분석 — 적격성 필터는 점수에 기여하지 않으며(통과/탈락 게이트), 실제 원인은 KQ1 점추정치가 4개 지표에서 MCID를 넘는데 그 확실성(⊕⊕◯◯)을 무보정 초과확률이 벌점하지 않던 것. 보정 후 omalizumab 효과 축 76 → 62점.
- 계수 값은 운영위 캘리브레이션 대상(미결 #1).

### 2. 편의성 축 규칙화 (마지막 가상 점수 폐기)

- `s_편의 = 100 × 6.5 ÷ 연간 유지기 투여 횟수`, reslizumab ×0.8(원내 IV).
- 결과: benra 100 · mepo/teze 50 · omal 50/25(q4/q2주) · resli 40 · dupi 26회 → 25.
- 근거가 전부 관찰 가능한 속성(허가 용법 투여 빈도·경로) — "남은 가상 요소" 항목 소멸.

### 3. KQ6(tezepelumab) OCS·안전성 원문 반영

- KQ6 재확인 결과 OCS 관련 유일 지표 = "OCS ≤5mg/day 도달 비율 RR 1.06 (0.87–1.30)" (SOURCE 단일연구 · ⊕⊕⊕◯ · 위약 697→738/1000) — **유의하지 않음** → 0점 유지가 정당(효과 없음의 근거). 카드 문구를 실측치로 교체.
- 안전성 행 갱신: 전체 AE RR 0.95 · SAE RR 0.67(위약보다 유의하게 낮음 — 효과 중첩 가능성, 이상반응 축 보너스는 미부여).
- 미결이던 "KQ6 부록 OCS %감량 존재 확인" 해소: 근거 프로파일 범위에는 없음.

### 4. 확정 반영

- reslizumab 100mg 바이알 **내림 확정**(잔량 미발생) — 체중 결합 기술: 65kg → 260mg 처방량 → 2바이알 200mg 투여(77%), 회당 799,104원.
- 비용 범위 **약제비만** 확정(행위료·진찰료 제외).

### 5. 사양서 재구성 (요청 반영)

- 3-A 적격성·3-B 절대효과를 bullet 재구성, omalizumab 점수 편중 Q&A와 "시험 평균 ≠ 환자 기저치" 논리 Q&A 수록.
- 3-C 초과확률 계산 예시 4건(전형·경계·크지만 불확실·명확한 미달), 3-D 선호도 가중 도출 전 과정(환자 표7.2 / 의료진 I-5 정규화 공식 / 자동 재가중 산술), 3-G MCDA 기본 환자 전 약제 완전 계산표 추가.
- 부록 용어(SOURCE 시험 · reslizumab 규격 · MCID) 신설.

## v2 (직전 회차)

### 1. 의료진 설문 원자료 반영 (N=52)

- I-5 전문가 설문(9점 척도)의 문항별 평균을 정규화해 **정밀 의료진 가중**으로 교체 (기존 핵심적:중요한 2:1 근사 폐기):
  - 악화 **0.228** (평균 8.73 · 1순위 선택 37/52 · 가중 순위점수 134)
  - OCS **0.220** (8.42 · 순위점수 78)
  - 조절도 ACQ **0.194** (7.44 · 41)
  - 폐기능 FEV1 **0.188** (7.21 · 16)
  - 삶의 질 AQLQ **0.171** (6.56 · 15)
- 근사 대비 훨씬 평탄 — 2:1 근사가 악화·OCS를 과대 가중(0.286)하고 있었음.
- 설문의 나머지 항목은 축 배치가 다름: 치료 부작용 6.62 → 이상반응 축 참고, 치료 접근성 7.10 → 비용 축 참고, 일반 QoL 5.23 → 미사용(도구에 해당 지표 없음).
- 환자(조절도 0.335 최우선) vs 의료진(악화·OCS 최우선) 인식 차이가 정량 확인됨 — 관점 병기 UI의 근거 강화.

### 2. 단순화 (지난 회차 피드백 반영)

- **확정 규칙 토글 제거**: 지표 점수화(MCID 초과확률 고정), 자동 재가중(적용 고정 — 내역 표기는 유지). 남은 토글은 '효과 축 가중 출처' 하나(미확정 사안).
- **비용·보험 입력 접힘**: ③ 섹션을 접이식으로 — 기본값으로도 계산되며, 필요할 때만 펼침.
- 결과: 최초 화면의 입력 요소가 임상 지표 7개 + 평가 시점 + 선호 4축으로 압축.
