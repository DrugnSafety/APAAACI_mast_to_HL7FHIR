# AI 엔진 선택 — OpenAI / 연구실 DGX Spark (Ollama) (2026-09-24)

화면 상단 **'AI 엔진'** 에서 고른다. 선택은 브라우저에 기억되고, 모든 API 호출에
`X-LLM-Backend: openai|ollama` 헤더로 실려 간다. 서버는 이 헤더로 OCR(비전 모델)과
상담·번역(텍스트 모델)의 백엔드를 고른다. 코드: `services/llm_backend.py`.

| 설정(.env) | 기본값 | 뜻 |
|---|---|---|
| `LLM_BACKEND` | openai | 화면에서 고르지 않았을 때 |
| `OLLAMA_BASE_URL` / `OLLAMA_API_KEY` | (없음) | 연구실 서버 주소·토큰. 커밋 금지 |
| `OLLAMA_VISION_MODEL` | qwen3.8:27b | OCR |
| `OLLAMA_CHAT_MODEL` | gpt-oss:120b | 상담·번역 |
| `OLLAMA_OCR_REASONING` | none | OCR 은 추론을 끈다 |
| `OLLAMA_CHAT_REASONING` | low | |
| `OLLAMA_TIMEOUT` | 600 | 초. SDK 자동 재시도는 끔 |

## 모델 선정 근거 (실측)

**OCR** — 합성 결과지 3장(인쇄본 69행·촬영본·중국어), 한 번 읽기, 추론 끔

| 모델 | 인쇄본 | 촬영본 | 중국어 | 양성 누락 | 장당 |
|---|---|---|---|---|---|
| **qwen3.8:27b** | 100% | 100% | 100%(등급 정확) | 0/31 | 90–200초 |
| qwen3.5:35b | 100% | 100% | 등급 13% | 0/31 | 한 장 49분 지연 |
| gemma4:26b | 100% | 100% | 행 93.5% | 1/31 | 37–91초 |
| qwen2.5vl:7b | 행 94.2% | 100% | 등급 13% | 0/31 | 73–157초 |
| llama4 | 43.5% | 40.5% | 0% | 30/31 | 부적합 |
| gemma4:31b | 45분 무응답 | | | | 중단 |

추론을 켠 채로는 69행 한 장에 약 19분. `/v1` 에서는 `reasoning_effort="none"` 만 통한다
(`extra_body={"think": false}` 는 무시됨).

**상담** — 음성 결과 질문(강아지), 질환 질문, 영어 답변

| 모델 | 결과 | 시간 |
|---|---|---|
| **gpt-oss:120b** | 3/3 정확 | 7–20초 |
| qwen3.8:27b | 3/3, 한국어 답에 태국어 단어 섞임 | 30–44초 |
| gemma4:26b | 1/3 (2개 응답 실패) | 44–54초 |
| qwen3:latest | 환자가 하지 않은 말을 지어냄, 약 권유 | 15–26초 |

## 주의

- 연구실 서버(11444)는 **http** 다. TLS 적용 전에는 실제 환자 결과지를 보내지 않는다. 화면 선택지에 ⚠️ 표시.
- 속도: OpenAI(gpt-5.6-luna) OCR 장당 약 28초(두 번 읽기 포함) vs 연구실 서버 1.5–3분(한 번 읽기).
  두 번 읽기를 켜면 두 배가 된다.
- 함께 고친 기존 버그: 번역이 chat 모델(gpt-5.6-luna)에 `max_tokens`·`temperature` 를 넘겨
  HTTP 400 으로 실패하고 있었다 — 캐시에 없는 문장은 한국어로 남았다.
