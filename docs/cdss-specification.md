## 1. 메인 아이디어

**"진료지침의 근거를, 개별 환자의 맥락에서, 순위 단정 없이, 투명하게."**

성인 중증 천식 환자에게 6종 생물학적 치료제(omalizumab·mepolizumab·reslizumab·benralizumab·dupilumab·tezepelumab) 중 무엇을 검토할지 결정하는 과정을 지원하는 진료지침 기반 CDSS. 세 가지 설계 철학이 전체를 관통한다.

1. **순위가 아니라 병렬 카드** — 약제 간 head-to-head RCT가 없으므로 "A가 B보다 좋다"는 단정을 만들지 않는다. 적격 약제들의 근거를 동일 형식 카드로 나란히 보여주고, 선호도 가중 점수는 '우선 검토 후보' 그룹핑까지만 제공하며 산출 내역을 전부 공개한다.
2. **3계층 구조** — ① 사실 계층(위약 대비 효과 + 확실성 + MCID 판정), ② 매칭 계층(환자 표현형·기저치와 근거의 부합), ③ 결정 계층(환자·의료진 선호 가중과 공유 의사결정). 계층이 위로 갈수록 가치 판단이 개입하며, 각 계층의 규칙이 분리되어 있다.
3. **결측·불확실성의 정직한 표시** — 근거 없음(제외·재정규화), 효과 없음의 근거(0점), 비급여(실부담 계산 또는 축 제외)를 구분하고 사유를 화면에 노출한다. 결측을 숨긴 매끈한 순위보다 결측을 명시한 비교가 낫다는 입장.

이용자 구분: **의료진 보기**(전 지표·CI·GRADE·계산 상세)와 **환자 보기**(쉬운 문장, 자기 기준 전후 비교, 점수 숨김, "의사와 상의" 프레임). 산출물의 최종 성격은 진료 판단 보조·교육 도구이며, 치료를 지시하지 않는다(SaMD 비해당 설계 원칙).

| ③ 비용·보험 (접힘) | 본인부담률(외래 기관 종별, 기본 상급종합 60%), 실손 가입 → [투여 환경 → 외래 시 정액공제·자기부담률·회당 한도], 테즈파이어 비급여 예상가 | 비용 모델 |

## 3. 알고리즘

### 3-A. 적격성 필터 (결정적 규칙)

| 약제 | 규칙 (데모 단순화판 — 허가·급여 원문 대조 필요) |
|---|---|
| Omalizumab | 통년성 감작 = 예 AND IgE ≥ 30 |
| Mepolizumab | 호산구 ≥ 150 (≥300이면 부합 높음) |
| Reslizumab | 호산구 ≥ 400 |
| Benralizumab | 호산구 ≥ 150 (≥300 하위군 근거 일관, 150–299는 불확실 표기) |
| Dupilumab | 호산구 ≥150 or FeNO ≥25 or OCS 의존 |
| Tezepelumab | 표현형 무관 |

비적격 약제는 숨기지 않고 회색 카드 + 사유로 표시한다(필터 투명성).

### 3-B. 환자 기저치 결합 절대효과 (표시 계층)

상대효과와 그 95% CI를 환자 기저치에 적용한다: 악화(RAR형) `기저 악화 × [RAR, CI]` → "연 3.0회 → 약 1.4회 (CI 0.9–1.8)". OCS(%MD형) `기저 용량 × (1+MD/100)`, 하한 0 절단. ACQ·FEV1·AQLQ는 MD 자체가 절대량. omalizumab 악화는 발생률비(event RR)라 횟수 환산이 성립하지 않아 위험 감소율로 표기.

**라벨 3원칙**: ① 이 CI는 평균 효과의 신뢰구간이며 개인 예측구간이 아니다, ② 상대효과 일정(portability) 가정의 명시, ③ 기저값 측정 오차(평균 회귀) 주의. GRADE SoF의 절대효과 산출과 동일 기법.

### 3-C. 지표 점수화 — MCID 초과확률 (확정)

각 지표의 점수 s ∈ [0,1] = **P(참효과가 델파이 합의 MCID를 넘음)**, 정규근사로 계산:

```
비율 지표(악화):  SE_ln=(ln hi − ln lo)/3.92,  s = Φ((ln 0.8 − ln v)/SE_ln)
음수-우호 MD(OCS −50, ACQ −0.5): SE=(hi−lo)/3.92,  s = Φ((MCID − v)/SE)
양수-우호 MD(FEV1 0.2, AQLQ 0.5):               s = Φ((v − MCID)/SE)
```

선정 이유: 극단값 지배(자연 유계 0~1)와 점추정치 편중(CI 통합)을 동시에 해결하고, ns 지표도 특별 규칙 없이 수식이 자연 처리하며, NMA의 'MCID 초과 확률' 해석 프레임과 일치. 대안이던 상한 1.5·로그 감쇠는 민감도 분석용으로 사양에만 남긴다(v2에서 토글 제거).

**결측 구분 규칙**: 측정지표가 이질적이어서 환산 불가한 경우(teze OCS의 RR형)는 0점 + 사유 표기, 해당 outcome의 적격 RCT 자체가 없는 경우(resli OCS)는 **가중치 제외 후 재정규화** — "효과 없음의 근거"와 "근거의 부재"를 다르게 처리한다.

### 3-D. 효과 축 합성

```
s_효과(d) = Σ_j u_j × s_j(d) ÷ Σ_j u_j   (근거 없는 j 제외)
```

지표 가중치 u의 출처 (토글):

| 지표 | 환자 설문 (표7.2, N=108) | **의료진 설문 (I-5 원자료, N=52 — 정밀값)** | 균등 |
|---|---|---|---|
| 악화 | 0.147 | **0.228** (평균 8.73/9, 1순위 선택 37/52) | 0.2 |
| OCS | 0.214 | **0.220** (8.42) | 0.2 |
| 조절도 ACQ | 0.335 | **0.194** (7.44) | 0.2 |
| 폐기능 FEV1 | 0.158 | **0.188** (7.21) | 0.2 |
| 삶의 질 AQLQ | 0.146 | **0.171** (6.56) | 0.2 |

의료진 가중은 9점 척도 평균의 정규화(2:1 근사 폐기). 환자는 증상(조절도) 최우선, 의료진은 악화·OCS 최우선 — I-7의 환자-의료진 인식 차이가 가중치로 정량화된다. 설문의 나머지 항목은 축 배치가 다르다: 치료 부작용(6.62)→이상반응 축, 치료 접근성(7.10)→비용 축의 축 수준 참고값, 일반 QoL(5.23)→도구 미사용(해당 지표 없음). '직접 입력'은 진료 의사 개인의 5지표 100점 배분.

**환자 문제별 자동 재가중 (채택 확정)**: 악화 ≥3회/년 → u_악화 ×2, 유지 OCS 사용 → u_OCS ×2, 이후 재정규화. 적용 내역은 결과 헤더와 계산 상세에 노출.

### 3-E. 비용 모델

- **약가** (급여 상한금액, 2026-08): 졸레어 150mg 216,755 / 75mg 114,440 · 누칼라 1,280,000 · 싱케어 100mg 399,552 · 파센라 2,842,543 · 듀피젠트 200mg 571,862 / 300mg 675,753 · 테즈파이어 비급여.
- **용량·스케줄**: omalizumab = IgE×체중 용량표(확인 완료, 회당 75~375mg, q2/4주) → 150/75mg 조합 단가. reslizumab = 4mg/kg, 100mg 바이알 **내림**(잔량 미발생 — 용량 미달 구간의 임상 타당성 확인 항목). benralizumab 첫해 8회/유지 6.5회. dupilumab **요법 자동 분기**: OCS 의존 → 초회 600mg(300×2) 후 300mg q2w, 일반 → 초회 400mg(200×2) 후 200mg q2w(초회 부하 1회분 추가 반영). mepolizumab·tezepelumab 13회/년.
- **기간 창**: 주 표시 = 치료 시작→반응 평가 시점(선택값), 부 표시 = 첫 12개월.
- **환자 실부담**: 급여 약제 = 표시가 × 본인부담률(외래 기관 종별: 상급종합 60% 등, 산정특례 미적용 전제). 비급여(teze) = 예상가 입력 시 100%.
- **실손보험**: 외래+가입 시 회당 `실부담 = 본인부담금 − min(max(본인부담금 − max(정액공제, 본인부담금×자기부담률), 0), 외래 통원 회당 한도)`. **입원+가입 시 비용 축 자동 제외**(실손 입원 보장 전제; 남은 축 재정규화). 증권 파라미터는 자가 입력(세대별 자동 판정은 오입력 위험으로 배제).
- **비용 축 점수**: `s_비용(d) = 100 × min(적격군 내 첫해 실부담) ÷ 첫해 실부담(d)`. 비급여 예상가 미입력 시 비용 축 제외·재정규화.

### 3-F. MCDA 총점

```
총점(d) = w_효과×s_효과 + w_비용×s_비용 + w_이상반응×s_AE + w_편의×s_편의
w = 환자 4축 100점 배분(정규화) — 기본값은 환자 조사 평균 근사(35/25/25/15)
비용 축 제외 시: 총점 = 남은 축 가중합 ÷ (1 − w_비용)
```

s_AE는 현재 전 약제 동일 90점(전 KQ에서 위약 대비 유의 초과 없음 — 차등 근거 없음; AE 세부 RR 추출 후 정밀화 예정). s_편의는 투여 간격·경로 기반(마지막 남은 가상 점수).

### 3-G. 관점 병기 (합성 금지)

환자 가중과 의료진 가중을 평균하지 않는다. 각각으로 1순위를 계산해 **일치("관점 일치: 동일(약제)")/상이("환자 A vs 의료진 B — 상담 포인트")**를 표시한다. 가치 판단의 기본 주인은 환자(EtD 원칙), 불일치는 공유 의사결정의 대화 재료다. 환자 보기에서는 의료진·고급 설정 전체가 숨겨진다.

### 3-H. NMA 비교 모듈 (예정)

공통 하위군(호산구 ≥300 주 분석, OCS 의존 시험군 부 분석) 제한 네트워크로 약제 간 비교 참고치(MCID 초과 확률 + CINeMA 확실성)를 산출하되, **환자가 해당 하위군에 부합할 때만 활성화**하고 비부합 시 사유를 고지한다. 별 모양 네트워크(일치성 검정 불가)와 이행성 한계를 명시한다. KQ7(감량)·KQ8(교체)은 네트워크 비대상 — Response evaluation의 후속 경로로 연결.

## 6. 미결·확인 사항

1. SOURCE(teze)의 OCS 감량률(%) 데이터 존재 확인 → 지표 동일화 (근거팀)
2. reslizumab 바이알 내림의 임상 타당성 / 25mg 규격 존재 여부
3. 테즈파이어 비급여 예상가 대표값 · 급여 등재 시 갱신
4. 실손 세대별 프리셋 대표값 (보험 실무)
