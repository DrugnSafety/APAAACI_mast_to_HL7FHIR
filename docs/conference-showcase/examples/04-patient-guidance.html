합성 사례의 환자 안내

검사값과 시뮬레이션 문진을 함께 해석한 예시입니다.

이 안내는 진료를 대신하지 않습니다. 실제 치료와 회피 계획은 담당 의료진과 정하십시오.

즉시 진료가 필요한 증상

호흡곤란, 목 부종, 실신이 있으면 응급진료를 받으십시오.

새 음식 섭취 뒤 전신 증상이 있으면 즉시 의료진에게 알리십시오.

먼저 확인할 내용

  • 개 항목은 7.14 IU/mL, Class 3입니다.
  • 집먼지진드기 항목은 0.64 IU/mL, Class 1입니다.
  • 시뮬레이션 답변은 두 노출 뒤 코 증상을 보고합니다.

오늘 할 일

  1. 침구를 주 1회 세탁하십시오.
  2. 청소할 때 먼지 노출을 줄이십시오.
  3. 개를 침실 밖에서 관리하십시오.
  4. 2주 동안 노출과 증상을 기록하십시오.

음식 결과

  • 오렌지는 5.66 IU/mL, Class 3입니다.
  • 시뮬레이션 답변은 오렌지 섭취 후 증상이 없습니다.
  • 검사 양성만으로 먹던 음식을 중단하지 마십시오.
  • 전복은 29.90 IU/mL, Class 4입니다.
  • 전복을 처음 먹는 행동을 시험으로 삼지 마십시오.
검사값은 합성 검사지의 기준값입니다. 증상은 가상 환자의 문진 답변입니다.
