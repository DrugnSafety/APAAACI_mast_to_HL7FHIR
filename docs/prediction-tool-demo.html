약제 선택 지원 — 순위 없는 병렬 카드 데모

환자 지표를 입력하면 적격성 필터가 후보를 가리고, 각 카드가 환자 기저치 기준 절대 기대효과(95% CI)를 주 표시로 보여줍니다. 효과 축 점수는 'MCID 배수 × 환자 설문 지표 가중치'로 합성되며, 선호도 가중치에 따라 우선 검토 후보가 바뀝니다.

v2 데모 고지 — 효과 수치는 KQ1~KQ6 근거 프로파일 실측치, 의료진 가중은 I-5 설문 원자료(52명) 정밀값, 비용 축은 급여 상한금액(2026-08)·허가 용법 기반 실제 계산입니다. 확정 규칙(MCID 초과확률·자동 재가중)의 토글은 제거했고 비용·보험 입력은 접힘 처리했습니다. v2.1: MCID 초과확률에 GRADE 확실성 계수를 곱해 넓은 신뢰구간이 보상받는 편향을 보정했고, 편의성 축을 가상 점수에서 규칙 기반(유지기 연간 투여 횟수 역비례 · 원내 정맥투여 감점)으로 교체했습니다(이상반응 축은 전 약제 동일 — 유의 초과 근거 없음). 본 데모는 지침의 공식 알고리즘이 아니며 진료 판단을 대체하지 않습니다.

환자 지표 입력

① 임상 지표 — 적격성·기대효과 계산
② 평가 설정
③ 비용·보험 — 펼쳐서 입력 (기본값으로도 계산됩니다)
본인부담률은 국민건강보험 외래 기관 종별 차등(상급종합 60% 등)·산정특례 미적용 전제. 실손 '있음' 선택 시 투여 환경을 묻고, 외래면 증권의 외래 통원 기준 3개 항목을 입력합니다(세대·특약별 상이). 입원이면 공제·한도 입력이 불필요하며 비용 축이 자동 제외됩니다(실손 입원의료비 보장 전제 — 입원 적정성·세대별 보장률 확인 필요).

선호도 가중치

① 환자 선호 — 4축 100점 배분 (환자 본인 입력 · I-7 설문 형식)
② 의료진·고급 설정 — 의료진 보기 전용 (운영위 기본값 확정 후 일반 사용자에게는 숨김 예정)
효과 축 가중:
환자 설문 가중은 표7.2(환자 108명 100점 배분), 의료진 설문 가중은 I-5 원자료(52명, 9점 척도 평균 정규화: 악화 0.228·OCS 0.220·조절도 0.194·폐기능 0.188·AQLQ 0.171)입니다. '직접 입력'은 진료 의사 개인의 가중치입니다. 확정 규칙(토글 제거됨): 지표 점수화 = MCID 초과확률 · 환자 문제별 자동 재가중 적용(악화 ≥3회 → 악화 ×2, OCS 사용 → OCS ×2).
효과 수치 출처(전부 실측): KQ1 Omalizumab — 악화 발생 RR 0.68 (0.60–0.77), OCS −85.2% (−153.0~−14.3), ACQ −0.51, FEV1 +0.22 L, AQLQ +0.64 · KQ2 Mepolizumab — AAER 0.48 (0.40–0.57), OCS −50.0% (−81.5~−18.5), ACQ −0.42, FEV1 +0.12 L, AQLQ ns · KQ3 Reslizumab — AAER 0.45 (0.35–0.56), ACQ −0.25, FEV1 +0.13 L, AQLQ +0.24 (OCS 근거 없음) · KQ4 Benralizumab — AAER 0.45 (0.29–0.60), OCS −50% (경계), ACQ −0.32, FEV1 +0.14 L, AQLQ +0.27 · KQ5 Dupilumab — AAER 0.54 (0.43–0.68), OCS −28.2%, ACQ −0.28, FEV1 +0.23 L, AQLQ +0.31 · KQ6 Tezepelumab — AAER 0.37 (0.24–0.51), OCS ns, ACQ −0.34, FEV1 +0.18 L, AQLQ +0.34. MCID 판정·근거수준(⊕)은 각 KQ 문서 기준. 절대 수치는 평균 상대효과와 그 신뢰구간을 환자 기저치에 적용한 값으로 개인 결과의 예측 범위가 아니며, omalizumab 악화 지표는 발생률비(event RR)라 횟수 환산 대신 위험 감소율로 표기합니다. 비용 계산 기준(2026-08 제공 급여 상한가): 졸레어 150mg 216,755·75mg 114,440원 / 누칼라 1,280,000원 / 싱케어 100mg 399,552원(4mg/kg·바이알 내림, 잔량 미발생) / 파센라 2,842,543원 / 듀피젠트 200mg 571,862·300mg 675,753원(OCS 의존 시 초회 600mg 후 300mg, 일반 초회 400mg 후 200mg — 초회 부하 2배 반영) / 테즈파이어 비급여(예상가 입력 시 전액 본인부담으로 계산, 미입력 시 비용 축 제외·재정규화). 비용 축 점수 = 첫해 실부담(본인부담률·외래 실손 반영) 역비례, 적격군 내 최저 = 100. 외래+실손 시 회당 실부담 = 본인부담금 − min(max(본인부담금 − max(정액공제, 정률자기부담), 0), 회당 한도). 입원+실손 선택 시 비용 축 자동 제외(실손 입원의료비 보장 전제 — 입원 적정성·세대별 보장률·비급여 특약은 별도 확인). 표시 비용은 약제비만 포함(투여 행위료·진찰료 제외) · 표시가 기준(RSA 환급은 공단-제약사 간 사안).
