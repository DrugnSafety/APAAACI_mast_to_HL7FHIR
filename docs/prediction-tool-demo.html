약제 선택 지원 — 순위 없는 병렬 카드 데모

환자 지표를 입력하면 ① 적격성 필터가 후보 약제를 가리고, ② 각 약제 카드가 위약 대비 효과·MCID·근거수준을 병렬로 보여주며, ③ 선호도 가중치를 조정하면 '우선 검토 후보' 그룹핑이 산출 내역과 함께 표시됩니다.

데모 고지 — Benralizumab 카드만 KQ4 근거 프로파일 실제 수치이며, 다른 약제 카드의 효과·비용·이상반응·편의성 수치는 UI 시연용 가상 예시값입니다(카드에 표기). 본 데모는 지침의 공식 알고리즘이 아니며 진료 판단을 대체하지 않습니다.

환자 지표 입력 (Tier 1·2)

선호도 가중치 — 100점 배분 (I-7 설문 문항 형식)

기본값은 환자 108명 가치·선호도 조사의 평균 우선순위를 근사 환산한 것입니다(공식 환산 방식은 운영위 확정 예정).

실측 데이터 출처: KQ4 Benralizumab 근거 프로파일(2026.08) — AAER RAR 0.45 (95% CI 0.29–0.60), OCS MD −50% (−64.1~−35.9, 단일연구), ACQ MD −0.32, FEV1 MD +0.14 L · 6 RCT (SIROCCO·CALIMA·ZONDA·SOLANA·ANDHI·MIRACLE). 적격성 규칙·부합 강도는 권고문(조건부·호산구성)과 KQ4 하위군 분석(호산구 ≥300 vs <300)·연구 등록기준(Table 4-3)을 단순화한 데모 규칙입니다. ⊕ 표기는 GRADE 근거수준. 채워진 원 = MCID 충족 + 유의, 빈 원 = 유의하나 MCID 미달/경계, 회색 = 통계적 유의성 없음. 약제 간 직접 비교(head-to-head) 근거는 없으며, 카드 정렬은 선호도 가중 점수에 따른 '우선 검토 후보' 그룹핑일 뿐 약제 간 우열 판정이 아닙니다.
