# 알레르기 감별 문진 — 임상 시나리오 설계 (Scenario Graph)

> 목적: 검사 양성(감작)이 **실제 알레르기(임상적 유의)**인지 감별하는 문진을,
> 카테고리별 임상 시나리오로 구조화한다. 문진은 **OCR 양성 알러젠 + 스크리닝**에 따라
> 동적으로 생성되며(personalized), 각 카테고리는 아래 결정 그래프를 따른다.

## 0. 공통 원칙
- 검사 양성 = **감작(sensitization)**. 임상적 알레르기는 *노출 시 재현성 있는 증상*이 있어야 성립.
- 각 알러젠은 **① 노출/시즌 신호 → ② 증상 유무 → ③ 재현성**을 확인.
- 교차반응(cross-reactivity)으로 **검사에 없거나 음성인 항목도 증상을 유발**할 수 있어, 별도로 물어야 함.
- 반대로 **강양성이어도 실제 노출 시 무증상 → 감작만**(과도한 회피 금지). 특히 갑각류.

## 1. 스크리닝(기저) — 전체 문진의 컨텍스트
```
증상 패턴? ──┬─ 연중(perennial) ─────────→ 실내(진드기·곰팡이·바퀴)·동물 가중
             ├─ 계절성(seasonal) ─────────→ 꽃가루 시즌 대조 가중
             ├─ 둘 다(both) ──────────────→ 둘 다
             └─ 없음(none) ───────────────→ 감작 우세 가능성
악화 계절? (봄/여름/가을/겨울)  → 꽃가루 피크와 자동 대조
침범 장기? (코/눈/하기도/피부/소화기/전신)  → 전신=고위험 신호
동반 질환? (비염/천식/아토피/두드러기/아나필락시스/음식·약물 알레르기)
약제? 항히스타민제 → SPT 위음성 주의
```

## 2. 카테고리별 결정 그래프

### 2.1 집먼지진드기 (HDM: Der p / Der f)
```
[HDM 양성]
  ├─ 저녁·새벽·이른아침 악화?  ─ 예 → 실내 알러젠 시그니처(+)
  ├─ 집 비우면 호전?           ─ 예 → 실내 원인(+)
  ├─ 먼지·이불정리 시 악화?     ─ 예 → HDM 특이(+)
  │      → 위 중 하나라도 예 & 연중/둘다 → clinically_relevant
  │      → 모두 아니오            → sensitized_only
  │      → 정보부족              → indeterminate
  └─ [교차반응] 트로포마이오신(Der p 10) ↔ 갑각류
         "새우·게를 먹으면 입/전신 증상?"  (갑각류 검사 없거나 음성이어도 질문!)
           ├─ 입·목만            → 갑각류 OAS 가능(경도) — 생물 주의
           ├─ 두드러기·호흡곤란   → 갑각류 알레르기 의심(고위험) — 전문의 평가
           └─ 잘 먹음/없음        → 교차 무증상
         + 저장진드기(가루) 오염 밀가루 → 팬케이크증후군(드묾)
  ▶ 면역치료 1순위 대상
```

### 2.2 꽃가루 (수목/화본과/잡초)
```
[꽃가루 양성]
  └─ 해당 시즌(봄 나무/초여름 잔디/가을 잡초)에 코·눈 악화?
         예 → clinically_relevant / 아니오 → sensitized_only / 모름 → indeterminate
  └─ [교차반응] PR-10·profilin ↔ 생과일·채소·견과 (PFAS/구강알레르기증후군)
         "생과일·채소·견과 먹으면 입·목 가려움/부종?" (OAS)
           예 → 감작된 꽃가루의 연관 음식 목록 제시 → 먹었을 때 증상 있는 것 선택
                · 자작/오리/참나무 → 사과·복숭아·체리·헤이즐넛·당근·콩…
                · 쑥              → 셀러리·당근·향신료·망고…
                · 돼지풀          → 멜론·바나나·오이…
                · 화본과(잔디)     → 멜론·토마토·오렌지·키위…
           → 대개 생물에서만, 가열 시 완화. 견과·콩·셀러리는 전신반응 주의.
  ▶ 면역치료 대상
```

### 2.3 동물 (고양이/개)
```
[동물 양성]
  ├─ 사육/자주 접촉?  ─ 아니오 → indeterminate(향후 반려동물 결정에 참고)
  └─ 접촉 늘 때 코·눈·피부·호흡기 악화?
         예 → clinically_relevant / 접촉하는데 무증상 → sensitized_only(분리 불필요)
  · 고양이(Fel d 1)는 공기 중 강력 → 직접 접촉 없는 공간에서도 반응 가능
  ▶ 회피 우선, 면역치료 가능
```

### 2.4 곰팡이 / 바퀴
```
[곰팡이] 습한 곳·장마·곰팡이 공간 악화? 예→relevant / 아니오→sensitized (Alternaria=중증천식 연관)
[바퀴]   오래된 건물·주방에서 악화? 예→relevant  (연중 실내, 천식 연관)
```

### 2.5 음식 (2가지 기전 구분이 핵심)
```
[음식 양성] → 어떤 기전인가?
  A. 일차 음식알레르기(전신):  먹은 뒤 두드러기·혈관부종·구토·호흡곤란·아나필락시스
        → clinically_relevant, criticality 높음, 전문의 평가/응급계획
  B. 이차/교차(OAS):  생과일·채소 등, 입·입술·목 국소 가려움, 가열 시 완화, 대개 경도
        → clinically_relevant(경도) 또는 관리 대상
  C. 감작만:  검사 양성인데 실제로 먹으면 무증상 (특히 갑각류에서 흔함)
        → sensitized_only, 불필요한 식이제한 금지
  질문: "이 음식 먹으면 어떤 증상?" [입·목만 / 두드러기·피부 / 소화기 / 호흡곤란·전신 / 없음(잘 먹음)]
```

#### 갑각류(새우·게) 특화 — 양방향
```
[새우/게 양성]  ── 실제로 먹었을 때?
   ├─ 잘 먹음(무증상)         → sensitized_only  ★강양성이어도 흔함, 회피 강요 금지
   ├─ 입·목만(OAS)           → 경도, 생물 주의
   └─ 두드러기·호흡곤란·전신   → 갑각류 알레르기(고위험) 전문의 평가
[HDM만 양성, 갑각류 미검사/음성]  → 트로포마이오신 교차로 갑각류 반응 가능 → 위 질문 동일하게 확인
```

## 3. 개인화 규칙 (어떤 문진을 보여줄지)
| 조건(양성 알러젠/스크리닝) | 추가되는 문진 섹션 |
|---|---|
| 진드기 양성 | 실내 시그니처 + 갑각류 교차반응 질문 |
| 꽃가루 양성 | 시즌별 확인 + (OAS=예 시) 연관 과일 목록 |
| 동물 양성 | 동물별 접촉/악화 |
| 곰팡이/바퀴 양성 | 습도/환경 질문 |
| 갑각류(새우·게) 양성 | 섭취 시 반응(무증상/OAS/전신) |
| 기타 음식 양성 | 섭취 시 증상 유형(다중) |
| 스크리닝 아나필락시스/전신 병력 | criticality 상향, 전신반응 질문 강조 |

## 4. 데이터로 관리 (well-made DB 재활용)
- `data/allergen_knowledge_base.json` — 알러젠 backdata/회피/면역치료
- `data/pollen_food_cross_reactivity.json` — 교차반응:
  - `pollen_food` (PFAS, PR-10/profilin)
  - `mite_shellfish` (tropomyosin: 진드기↔갑각류)
- 문진/판정 로직: `services/questionnaire_service.py` (위 그래프를 코드로 구현)
- 새 알러젠·교차반응은 위 JSON에 **항목만 추가**하면 문진·리포트·카드뉴스·FHIR에 자동 반영.
