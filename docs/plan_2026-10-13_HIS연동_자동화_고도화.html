09. FAQ

OCR 경로는 없어지나?

아니다. HIS 수신 건은 OCR·결과 점검 화면을 건너뛰고, 타 기관 결과지·과거 결과는 기존 업로드 경로를 그대로 쓴다.

외부 LLM API 를 완전히 끊어도 동작하나?

판정·리포트 구조·FHIR·카드뉴스·추천 질문은 결정론 경로라 LLM 없이 동작한다. LLM 은 리포트 문장 다듬기·번역·자유 질문 챗봇에만 쓰이며 로컬 Ollama 로 간다. 외부 키를 비우면 호출 경로가 닫힌다.

환자 식별정보는 어디까지 나가나?

알림톡 대행사에는 전화번호와 토큰 URL 만 나간다. 이름·등록번호·검사 결과는 병원망 안의 서버에만 있고, URL 의 토큰은 추측할 수 없는 난수이며 본인확인을 거쳐야 열린다.

왜 A-3(DB 뷰) 를 먼저 하나?

인터페이스 엔진 작업은 의료정보팀 일정에 묶인다. 읽기 전용 뷰는 보통 더 빨리 열리므로 실제 결과 데이터로 매핑·판정·리포트를 먼저 검증하고, HL7 경로가 열리면 어댑터만 바꿔 끼운다.

진행 상태는 어떻게 공유하나?

상단 '진행 상태 복사' 로 JSON 을 복사해 메신저·노션에 붙이면 상대가 '가져오기' 로 같은 상태를 본다. 노션의 과업 데이터베이스가 공식 기록이고 이 페이지는 작업용이다.
