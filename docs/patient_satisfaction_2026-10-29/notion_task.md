## 목적과 상태

환자가 결과 자료를 받은 뒤 이용 경험을 평가합니다.
임상 문진과 별도 만족도 알림톡을 계획합니다.
설문은 APAAACI-SAT-01 v0.1입니다.
IRB 문서는 v0.2 초안으로 개정합니다.
약 2분은 설계 목표이며 예비 조사로 확인합니다.

## 간단한 설문 구성

먼저 응답자를 선택합니다.
본인, 입력 도움을 받은 본인, 보호자로 구분합니다.
보호자는 직접 이용한 서비스 경험을 답합니다.
아이의 만족도를 추측해서 답하지 않습니다.

확인한 자료를 선택합니다.
보고서, 카드뉴스, 둘 다, 미열람으로 구분합니다.
미열람자는 이유만 고르고 평정 문항을 건너뜁니다.

| 번호 | 문항 |
| --- | --- |
| S1 | 글과 화면을 보기 쉬웠습니다. |
| S2 | 검사 결과의 설명을 이해하기 쉬웠습니다. |
| S3 | 생활에서 주의할 점을 이해하는 데 도움이 됐습니다. |
| S4 | 휴대전화에서 결과 자료를 확인하기 편리했습니다. |
| S5 | 결과 자료를 필요한 시점에 받았습니다. |
| S6 | 전반적으로 이 결과 안내 서비스에 만족합니다. |

각 문항은 1~5점 중 하나를 고릅니다.
1점은 전혀 그렇지 않다입니다.
5점은 매우 그렇다입니다.
평가 어려움과 응답하지 않음도 선택할 수 있습니다.
공란도 허용합니다.

개선 의견은 선택이며 최대 300자입니다.
이름, 전화번호, 자세한 건강정보는 쓰지 않게 안내합니다.

## 자료 수령 후 별도 알림톡

아래 일정은 병원과 IRB가 확정할 제안입니다.

| 단계 | 제안 |
| --- | --- |
| 수령 기준 | 승인 자료의 인증 후 첫 열람 또는 연구자 수령 확인 |
| 초대 | 수령 확인 24시간 후 |
| 응답 기간 | 초대 후 7일과 결과 확정 후 30일 중 이른 때까지 |
| 늦은 초대 | 응답 시간이 24시간 미만 남으면 미발송 |
| 재알림 | 초대 후 3일째 1회 |
| 발송 횟수 | 같은 등록 검사 회차에 설문 1회 |
| 중단 | 응답, 거절, 철회, 만료 후 예약과 재시도 중단 |
| 결과 정정 | 예약 보류 후 검토. 같은 회차에 자동 추가 초대 금지 |

사업자 전달 영수증만으로 수령이나 읽음을 판단하지 않습니다.
발송 직전마다 동의와 수신 권한을 확인합니다.
소아는 보호자 관계와 수신자를 확인합니다.
본문에는 검사값과 진단명을 넣지 않습니다.
URL은 병원 본인 확인 뒤 설문으로 연결합니다.

알림톡 초안:

> 받으신 결과 안내 자료의 이용 경험을 알려 주세요.
> 설문은 약 2분이며 참여는 선택입니다.
> 답하지 않아도 진료에 불이익이 없습니다.
> 아래 버튼에서 본인 확인 후 참여할 수 있습니다.
> 버튼: 만족도 설문 참여

## 분석과 개인정보

S6의 1~5점 응답 중 4~5점 비율을 제시합니다.
문항별 분포, 유효 응답 수, 중앙값, 사분위 범위를 제시합니다.
합산 점수를 만들거나 검증된 척도로 표현하지 않습니다.
본인과 보호자 응답은 별도로 제시합니다.
입력 도움 여부와 확인 자료도 구분합니다.

평가 어려움, 거절, 공란, 미열람을 점수로 바꾸지 않습니다.
만족도로 임상 정확성이나 치료 효과를 판단하지 않습니다.

설문은 연구번호와 검사 회차로 가명 연결합니다.
완전 익명 설문으로 설명하지 않습니다.
새 이름이나 연락처를 수집하지 않습니다.
자유 의견을 외부 AI나 모델 학습에 보내지 않습니다.
접근 권한과 보관 기간은 IRB 계획을 적용합니다.

## IRB 개정 범위

연구계획서에 사후 설문 목적, 일정과 분석을 추가합니다.
성인과 보호자 설명문에 추가 부담과 선택권을 반영합니다.
동의서에 사후 설문 안내 수신 선택을 분리합니다.
소아 승낙, 개인정보 항목, 철회 절차도 반영합니다.
CRF와 알림톡 문안은 설문 정의와 맞춥니다.
의료정보센터 요청서에 발송 예약과 인수 시험을 추가합니다.
