# 환자 만족도 설문 자료

설문 v0.1 · IRB v0.2 반영 · 승인 전 초안

index.html을 여십시오.
환자용 HTML은 단계별 미리보기입니다.
실제 환자정보를 입력하지 마십시오.
미리보기는 답변을 병원에 전송하지 않습니다.

patient_satisfaction.doc은 Word 바이너리 파일입니다.
patient_satisfaction.docx은 편집용 Word 파일입니다.
patient_satisfaction.pdf는 HTML 인쇄본입니다.
Word의 실제 페이지 배치는 직접 확인하지 못했습니다.

평정 문항은 6개입니다.
개선 의견은 선택이며 300자까지 적습니다.
약 2분은 설계 목표입니다.
실제 소요 시간은 예비 조사로 확인하십시오.

implementation_guide.html에서 발송과 분석 계획을 확인하십시오.
기존 구글 드라이브 설문 3종의 참고 범위도 제공합니다.
원본 응답과 과거 연락처는 포함하지 않습니다.

설문 문항은 survey_definition.json에서 관리합니다.
같은 정의를 IRB study_config.json에 반영합니다.
문항 변경 시 설명문과 동의서도 함께 확인하십시오.

별도 알림톡은 자료 수령 확인 24시간 후를 제안합니다.
응답은 최대 7일이며 재알림은 3일째 1회입니다.
개인 참여 30일을 넘기지 않습니다.
병원과 IRB가 일정과 동의를 확정해야 합니다.
실제 알림톡과 병원 서버 연계는 추가 구현이 필요합니다.

notion_page.json에 하위 작업 주소를 기록합니다.
ZIP의 다른 자료 링크는 원래 프로젝트에서 사용하십시오.
IRB와 의료정보센터 문서는 별도 자료 묶음입니다.
