환자 만족도 설문 운영 안내

작성일: 2026-10-29 · 설문 v0.1 · IRB 문서 v0.2

보고서 수령 후 별도 알림톡으로 설문을 안내합니다. 평가 6문항과 선택 의견란으로 구성합니다. 약 2분은 설계 목표입니다. 연구팀은 예비 조사로 실제 시간을 확인합니다.

이 문서는 IRB 검토용 초안입니다. 병원 연계와 실제 발송 기능은 아직 구현하지 않았습니다.

1. 파일 선택

  • 환자용 HTML 설문을 여십시오.
  • Word DOC 설문지를 받으십시오.
  • Word DOCX 설문지를 받으십시오.
  • 인쇄용 PDF를 받으십시오.
  • 설문 정의 JSON을 확인하십시오.
  • IRB 문서 모음을 확인하십시오.
  • 의료정보센터 협조 요청

HTML은 화면과 분기를 확인하는 미리보기입니다. 미리보기는 답변을 병원 서버로 전송하지 않습니다. 미리보기에 실제 환자정보를 입력하지 마십시오.

2. 임상 문진과 만족도 설문

항목 임상 문진 사후 만족도 설문
목적 검사 해석에 필요한 증상과 노출 확인 자료 이용 경험 평가
시점 검사 확정 후 자료 생성 전 승인 자료 수령 후
소요 시간 10~15분 제안 약 2분 목표
응답 기간 초대 후 14일 제안 초대 후 7일 제안
재알림 3일·7일째, 최대 2회 3일째, 최대 1회
개인 참여 상한 검사 결과 확정일부터 30일 같은 30일 안에서 종료

두 설문의 목적과 알림톡 양식을 구분합니다. 만족도 설문은 보고서 생성 조건이 아닙니다. 참여를 거절해도 진료와 자료 제공에 불이익이 없습니다.

3. 환자가 답하는 순서

  1. 환자 또는 보호자는 결과 자료를 받습니다.
  2. 환자 또는 보호자는 별도 설문 알림톡을 받습니다.
  3. 환자 또는 보호자는 본인 확인을 합니다.
  4. 응답자는 본인·입력 도움·보호자 중 하나를 고릅니다.
  5. 응답자는 본 자료를 고릅니다.
  6. 자료를 본 응답자는 평가 6문항에 답합니다.
  7. 응답자는 원하면 개선 의견을 적습니다.
  8. 응답자는 답변을 확인한 뒤 제출합니다.

자료를 아직 보지 못했다면 평가 문항을 건너뜁니다. 이때 열기 어려움 등 선택 이유만 확인합니다. 모든 평가 문항에서 응답을 건너뛸 수 있습니다.

보호자는 자신이 자료를 이용한 경험을 답합니다. 보호자는 아이의 만족도를 추측해서 답하지 않습니다. 입력만 도움받은 답변은 환자 본인 응답으로 기록합니다. 미성년자 경로는 승인한 동의·승낙 기준을 따릅니다.

4. 발송 일정과 중단 조건

아래 일정은 연구팀과 IRB가 확정할 제안값입니다.

조건 처리
자료 수령의 기준 인증 후 자료를 연 첫 기록 또는 연구자의 수령 확인
첫 초대 수령 확인 후 24시간
응답 만료 초대 후 7일과 개인 참여 종료 중 이른 시각
개인 참여 종료 검사 결과 확정 시각부터 30일
응답 기회 부족 초대 시 잔여 기간이 24시간 미만이면 미발송
재알림 초대 3일 후 1회, 응답·거절·철회 시 제외
정정 중 기존 보고서 관련 예약과 재시도를 보류
이미 초대한 회차 정정 후 자동으로 추가 초대하지 않음

알림톡 전달 영수증만으로 자료 수령을 단정하지 않습니다. 자료를 연 기록은 내용을 읽거나 이해했다는 증거가 아닙니다. 연구자는 첫 문항으로 실제로 본 자료를 다시 확인합니다. 열람 기록 수집도 승인한 개인정보 범위에 포함합니다.

서버는 모든 예약과 발송 직전에 동의를 재확인합니다. 서버는 수신자와 보호자 권한을 다시 확인합니다. 철회·기응답·수신 거절 상태이면 발송하지 않습니다.

6. 의료정보팀 구현 항목

서버는 설문 초대를 보고서 생성 큐와 분리합니다. 서버는 승인한 문항 버전을 고정합니다. 서버는 같은 회차에 초대를 중복 생성하지 않습니다.

영역 최소 요구사항
초대 고유키 가명 연구번호 + 등록 검사 회차 + 설문 버전
회차 제한 연구번호와 등록 회차당 설문 인스턴스 1개
보고서 연결 승인 버전·파일 해시·수령 근거·수령 시각

응답자 연결 본인·입력 도움·보호자, 승인된 수신자와 결합
상태 대기·예약·초대·진행·응답·거절·만료·철회·보류
알림톡 기록 대행사 접수·전달 결과·재알림 횟수
응답 API 인증·만료·권한·문항 버전·입력값 검증
저장 병원 승인 DB, 암호화, 접근 기록, 역할 권한
대조 제출 중복·재시도·연결 끊김·정정·철회 경합

서버는 동일 요청의 재전송에 같은 접수 결과를 반환합니다. 설문 토큰은 해당 인스턴스에만 권한을 갖습니다. 주소에는 연구번호나 병원 환자번호를 노출하지 않습니다. 토큰과 자유 의견은 웹 접근 로그에 기록하지 않습니다.

운영 서버는 연구번호와 식별 연결표를 분리합니다. 응답과 자유 의견은 외부 AI에 보내지 않습니다. 보관 기간은 IRB 문서와 병원 정책을 따릅니다.

미리보기 HTML에는 운영용 인증과 수신 API가 없습니다. 화면의 완료 동작은 병원 제출을 뜻하지 않습니다. 운영판은 서버의 접수 확인 후에만 제출 완료를 표시합니다.

7. 응답 데이터와 분석

설문은 익명 조사가 아닙니다. 연구팀은 가명 연구번호로 검사 회차와 연결합니다. 설문은 이름·생년월일·전화번호를 다시 묻지 않습니다. 응답자는 의견란에 자세한 건강정보를 쓰지 않습니다.

평가값은 1~5 정수로 저장합니다. 평가 어려움과 응답 거절은 별도 코드로 저장합니다. 빈 답변과 미열람은 별도 상태로 저장합니다. 서버는 이 상태를 0점이나 3점으로 바꾸지 않습니다.

주요 만족도 지표는 S6의 응답 분포입니다. S6의 15점 응답자 수를 분모로 사용합니다. 45점 응답자 비율을 함께 제시합니다. 각 문항의 유효 수·중앙값·사분위 범위를 제시합니다.

6문항의 합산 점수는 기본 분석으로 만들지 않습니다. 환자와 보호자 응답은 구분해서 분석합니다. 자료 종류와 입력 도움 여부도 구분해서 제시합니다. 작은 소아 하위군은 재식별 위험을 검토합니다.

흐름별 분모 구분할 상태
적격 대상자 참여·연락 동의, 등록 검사 회차
보고서 전달 발송 접수, 전달 성공, 전달 실패
자료 수령 확인 인증 후 접속, 연구자 확인, 근거 없음
설문 초대 발송 대상, 실제 초대, 기간 부족, 중단
응답 과정 시작, 미열람, 거절, 만료, 제출
S6 분석 1~5점, 평가 어려움, 거절, 빈 답변

설문 도달률과 응답률은 만족도와 별도로 보고합니다. 초대 접수와 전달 성공을 같은 상태로 합치지 않습니다. 미응답자를 불만족자로 분류하지 않습니다. 연구팀은 선택 편향과 회상 편향을 함께 설명합니다. 이 문항은 검증된 표준 척도가 아닙니다. 만족도는 임상 정확성이나 치료 효과를 증명하지 않습니다.

8. 기존 설문의 참고 범위

사용자 드라이브의 빈 설문지 3종을 참고했습니다. 연구팀은 아래 영역을 이 연구에 맞게 재작성했습니다. 기존 환자의 응답 내용은 사용하지 않았습니다.

출처 반영한 영역 제외한 내용
약물알레르기 앱 설문 가독성·편의성·시점·전반 만족도 반복 문항·정확성 판정·과거 연락처·보상
식품알레르기 앱 설문 환자·보호자 구분, 이해와 이용 이니셜·나이·기기 이력 재수집
약이랑 서비스 설문 생활 안내 도움, 선택 개선 의견 긴 다중 영역·치료 효과·익명 처리 표현

S1은 가독성, S2는 설명 이해를 평가합니다. S3은 생활 안내의 도움을 평가합니다. S4는 휴대전화 이용 편의성을 평가합니다. S5는 전달 시점, S6은 전반 만족도를 평가합니다. 원척도의 검증이나 사용 허가를 승계했다고 주장하지 않습니다. 연구팀은 환자·보호자 예비 조사로 문구를 확인합니다.

9. 제출 전 점검

  • 연구팀은 문항과 2분 목표를 예비 조사합니다.
  • 연구팀은 초대 시점과 응답 기간을 확정합니다.
  • 연구팀은 소아·보호자 응답 경로를 확정합니다.
  • 연구팀은 동의서의 선택 항목을 확인합니다.
  • 병원은 알림톡 양식과 위탁 범위를 승인합니다.
  • 의료정보팀은 인증과 콜백을 시험합니다.
  • 의료정보팀은 중복·철회·정정 경합을 시험합니다.
  • 연구팀은 IRB 변경 사항과 버전을 확인합니다.
  • 병원은 실제 발송 전 최종 인수 시험을 완료합니다.
