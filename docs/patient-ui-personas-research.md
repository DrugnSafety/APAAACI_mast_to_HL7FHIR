# 환자용 UI 재구성 — 환자 질문 브레인스토밍 · 페르소나 설계 (10차)

> 브레인스토밍 전용 스킬/플러그인은 설치 목록에 없음(SearchSkills 0건)을 확인 후, 다각도 구조화 브레인스토밍(여정 단계·JTBD·두려움/희망·이해관계자 렌즈)을 직접 수행하고 웹 조사로 보강했다.

## 1. 조사 요약 — 환자는 무엇을 궁금해하는가

### 문헌·도구 조사 (핵심 소스)

| 소스 | 핵심 발견 |
|---|---|
| 미국폐협회 Biologics Decision Tool | 의료진용 위주 — **환자용 결정 보조 도구는 공백**에 가까움 (우리 도구의 자리) |
| 공유 의사결정 질적 연구 (J Asthma 2025) | 환자 목표는 QoL 개선·악화 감소·**신체 활동 회복** — 의료진이 먼저 물어야 표출됨 |
| 생물학적제제 순응도 심리 요인 스코핑 리뷰 (2025) | 반복 장벽: **주사 공포**, 질병 부정, 낙인, 비용·보험 절차 복잡성. 촉진 요인: 효과 체감, 정서적 안심, 공유 의사결정 |
| DCE 선호 연구 (미국 301명 / 캐나다) | 효과·안전 > 편의. 단 **일상 활동 개선**·월 실부담·투여 빈도가 독립 속성으로 유의 |
| 국내 기사·환자단체 (2025) | 연 800만~1000만원 실부담·본인부담 60% — **치료 중단 사유 1위 = 비용(10명 중 9명)**. 산정특례 요구 활발 |

### 브레인스토밍 — 환자 질문 마스터 리스트 (여정 단계별)

**A. 시작 전 (지금 이 도구를 보는 순간)**
1. 나한테 맞는 주사가 있긴 한가? 왜 6개나 되나?
2. 지금 쓰는 흡입제·스테로이드로는 안 되는 건가?
3. 효과가 얼마나 좋은가 — "나"의 경우 악화가 몇 번에서 몇 번으로 주나?
4. 언제부터 효과를 느끼나? (기대 설정)
5. 부작용은? 오래 맞아도 안전한가?
6. 주사가 아픈가? 병원에서 맞나 집에서 맞나?
7. 한 달/1년에 얼마 드나? 실손보험은 적용되나?
8. 검사(호산구·IgE)는 왜 필요한가? 내 수치를 모르면?

**B. 선택 시점**
9. 6개 중 왜 이 약을 먼저 검토하나? 다른 약과 뭐가 다른가?
10. 스테로이드(프레드니솔론)를 끊을 수 있나? 언제부터 줄이나?
11. 비염·비용종·아토피도 같이 좋아지나?
12. 임신 계획이 있는데 맞아도 되나? *(도구 범위 밖 — "의사와 상의" 항목)*
13. 얼마나 자주, 얼마나 오래 맞아야 하나? 평생인가?

**C. 시작 후 (연계 안내)**
14. 효과가 있는지 언제, 무엇으로 판단하나? (→ Response evaluation 연결)
15. 효과가 없으면? 다른 약으로 바꿀 수 있나?
16. 여행·출장 때는? 한 번 건너뛰면?

→ **환자 UI의 정보 구조는 이 16개 질문에 답하는 순서로 재편**한다. 점수·수식·CI는 전부 배제(기존 결정 11 유지), 질문-답 형태의 카드로 제공.

## 2. 페르소나 설계 — 6종

DCE·설문 근거(효과/활동/비용/편의 우선순위 차이)와 입력 모델의 판별 가능 신호를 결합해 정의. **페르소나 = 4축 선호 프리셋 + 질문 카드 우선순위 + 말투 프레임**이며, 진단 분류가 아니다(화면에 명시).

| # | 페르소나 | 한 줄 정체성 | 자동 추천 신호 (입력 기반) | 4축 가중 (효과/비용/이상반응/편의) | 최우선 질문 카드 |
|---|---|---|---|---|---|
| P1 | **응급실이 무서워요** (잦은 악화형) | "또 새벽에 응급실 갈까 봐 늘 불안해요" | 악화 ≥3회/년 | 50/15/20/15 | Q3 악화 감소, Q4 효과 시점, Q15 무효 시 대안 |
| P2 | **스테로이드를 줄이고 싶어요** (OCS 의존형) | "먹는 스테로이드 부작용이 무서워요" | 유지 OCS > 0 | 45/15/25/15 | Q10 감량 가능성, Q5 장기 안전성 |
| P3 | **바쁜 일상이 우선이에요** (편의 중시형) | "병원 갈 시간이 없어요, 집에서 맞고 싶어요" | 악화<3 & OCS 0 (조절 문제 위주) | 30/15/15/40 | Q6 자가주사, Q13 투여 간격, Q16 여행 |
| P4 | **비용이 제일 걱정이에요** (비용 민감형) | "효과 좋아도 못 버티면 소용없잖아요" | 비용·보험 섹션 입력/실손 응답 | 25/45/15/15 | Q7 실부담, 실손, 중단 시 |
| P5 | **다른 병도 같이 있어요** (동반질환형) | "비염·비용종·피부까지 다 힘들어요" | 동반질환 체크(신규 입력: 비염/비용종/아토피) | 40/15/25/20 | Q11 동반질환 동시 효과 |
| P6 | **예전처럼 움직이고 싶어요** (활동 회복형·기본값) | "계단, 등산, 아이랑 뛰는 게 소원이에요" | 그 외 기본 | 40/20/20/20 | Q3+QoL·활동, Q14 반응 평가 |

- **추천 규칙**: 신호 충족 페르소나를 점수순 정렬해 **상위 1~2개를 "추천" 배지로 제시하되, 6개 모두 선택 가능**(자기결정 존중 — 페르소나는 제안이지 판정이 아님). P1·P2 동시 충족 시 둘 다 추천.
- 페르소나 선택은 ① 정보 카드의 배치 순서(그 페르소나의 질문이 위로), ② 숨은 4축 가중(우선 검토 후보 결정), ③ 문장 프레임("응급실 방문을 줄이는 것이 목표라면…")에만 영향. **약제 자체를 바꾸지 않는다** — 적격성은 임상 지표만으로 판정.
- 4축 가중 프리셋 값은 데모용 가안 — 운영위·환자위원 검토 대상 (미결 항목).

## 3. 이중 UI 구조 결정 (화면 전면 재구성)

기존: 한 화면 + 보기 토글 → **개편: 진입점부터 분리된 두 페이지**

| | 의료인용 (기존 데모 승계) | 환자용 (신규) |
|---|---|---|
| 파일 | `prediction-tool-demo.html` | `prediction-tool-patient.html` |
| 진입 | 전 지표 입력 폼 | **대화형 단계 진행** (내 상황 → 페르소나 → 결과 → 상담 준비) |
| 입력 | 검사치 필수 | 검사치 "**모름**" 허용 — 모름이면 해당 약제를 "검사 후 판단" 상태로 표시 |
| 정보 단위 | 지표·CI·GRADE·점수·계산 상세 | 질문-답 카드, 전후 막대(자기 기준), 점수·CI 숨김 |
| 프레임 | MCDA 우선 검토 후보 | "**의사 선생님과 상의할 준비**" — 상담 질문 체크리스트 생성 |
| 연결 | → 환자용 링크 | → 인쇄/저장해 진료실 지참 |

핵심 기능 승계(환자용): 적격성 필터(쉬운 문장 사유), 기저치 결합 절대효과(전후 막대), 비용·실손 실부담, 편의성(투여 횟수·자가주사), 반응 평가 시점 안내. 제외: MCDA 점수 표시, 가중 출처 토글, GRADE 표기(말로 풀어씀: "근거가 탄탄해요/근거가 아직 제한적이에요").

## 4. 미결 추가 항목

1. 페르소나 4축 프리셋 값 검증 (환자위원회·I-7 재분석)
2. 동반질환 입력 추가에 따른 dupilumab 적격성 문구(비용종·아토피 이득) 감수
3. 임신·수유 등 "의사와 상의" 고정 항목 문안 감수 (학회)
4. 환자용 문해력 수준 검증 (읽기 연령 — 환자단체 사용성 테스트)
