## 1. NMA 관련

### 1-1. Kyriakopoulos 2024 (Eur Respir Rev)와의 차이

확인 결과 Kyriakopoulos 2024는 **NMA가 아니라 쌍별(pairwise) 메타분석**이다 — 48개 RCT, 16,350명을 통합해 '생물학적 제제 전체 vs 위약'의 효과(AAER RAR 0.56, 입원 0.40)를 산출하고, 약제별·T2 생체표지자별 **하위군 분석**을 제시했다. 약제 간 간접 비교(랭킹)는 하지 않았다.

우리 과제가 수행할 NMA와의 차이:

| 항목 | Kyriakopoulos 2024 | 본 과제 NMA(안) |
|---|---|---|
| 설계 | 쌍별 MA (약제 전체 풀링 + 하위군) | 약제 간 간접 비교 (네트워크) |
| 근거 시점 | ~2023 검색 | **MIRACLE(2024)·DIRECTION(2025) 포함** — 근거 최신성 우위 |
| 해석 기준 | 통계적 유의성 중심 | **한국 델파이 MCID 대비 해석** (효과가 MCID를 초과할 확률) |
| 모집단 | 전체 | 전체 + **생체표지자 공통 하위군 제한 네트워크** |
| 맥락 | 독립 리뷰 | 한국 진료지침·온라인 플랫폼 연동 |

### 1-2. 기존 천식 생물학적 제제 NMA 현황과 출판 가능성

기존 NMA가 이미 여러 편 존재한다:

- **Akenroye 2022 (JACI)** — 호산구성 천식에서 tezepelumab·mepolizumab·benralizumab·dupilumab 베이지안 NMA (teze·mepo·dupi는 악화 50% 감소 확률 >99%, benra 66%)
- **Ando 2022** — T2 생체표지자 역치별 tezepelumab vs 타 약제 NMA
- **WAO Journal 2024** — 6개 약제 전체 NMA (검색 ~2022.8; 약제 간 유의한 차이 없음, tezepelumab이 수치상 1위)
- **Menzies-Gow 2022 (J Med Econ)** — tezepelumab 간접비교(ITC)
- **2025년 알레르기성 천식 대상 NMA** 등

**출판 가능성: 있다 — 단, 차별점을 명확히 해야 한다.** 기존 NMA의 단순 반복은 신규성이 없다. 방어 가능한 차별점 4가지:

1. **근거 최신성**: 기존 NMA 검색창은 대부분 2022년 중반까지 — MIRACLE(Lai 2024), DIRECTION(Yang 2025) 등 이후 대규모 RCT가 미반영. 이 두 시험은 아시아 인구 비중도 높아 한국 맥락과의 관련성 논거도 된다.
2. **MCID 준거 해석**: "각 약제 효과가 한국 전문가 합의 MCID를 초과할 확률"이라는 프레임은 기존 NMA에 없다 — 델파이 MCID 성과물과 NMA를 결합하는 것이 본 과제만의 자산.
3. **공통 하위군 제한 네트워크 + CINeMA/GRADE-NMA 확실성 등급**: 이행성 위협을 정면으로 다루는 설계.
4. **가이드라인·의사결정 플랫폼 연동(living NMA)**: 지침 개정 주기와 연동된 갱신 계획.

투고 후보: AAIR(지침 연계 논문과 자매 구성), ERJ Open Research, JACI: In Practice, World Allergy Organ J. 지침 본문 논문과 별도의 방법론 논문으로 분리 투고하는 구성을 권장.

### 1-3. 호산구 ≥300 외 추가 분석 축 — 있다

KQ 문서들의 부록 4(하위군 forest plot)가 실제 보유한 축:

| 분석 축 | 근거 가용성 | 비고 |
|---|---|---|
| 혈중 호산구 (≥300 / 150–299 / <150) | 전 약제 | 주 분석 축 (KQ4 사전 층화, KQ6 post-hoc — 질 차이 명시 필요) |
| FeNO (≥25 / <25) | KQ5·KQ6 중심 | 제2형 축 — dupilumab·tezepelumab 비교에 유용 |
| 알레르기성 (감작/IgE) | KQ1·KQ6 등 | omalizumab 포함 네트워크의 자연 축 |
| **OCS 의존** | ZONDA(benra)·SIRIUS(mepo)·VENTURE(dupi)·SOURCE(teze) | **별도 네트워크로 구성 가능한 가장 깔끔한 축** — 'OCS 감량 목적 시험'끼리는 설계·모집단이 서로 유사 |
| ICS 용량, 과거 악화 횟수(1–2 vs ≥3) | KQ6 등 | 보조 축 |
| 비용종 동반 | KQ5 | dupilumab 특이 축 |

특히 **OCS 의존 환자 네트워크**는 시험 설계 자체가 동질적(OCS-sparing design)이라 이행성 가정이 가장 잘 성립하는 두 번째 주 분석 후보다.

### 1-4. 환자가 여러 하위군에 동시 해당할 때 — 곱하지 말고, 위계와 일치성으로

핵심 원칙: **하위군 효과들은 서로 독립이 아니므로 곱하거나 합성할 수 없다** (같은 환자들이 여러 하위군에 중복 포함 — 곱하면 이중계상). 형식적 해법은 IPD(개별 환자 데이터) 메타분석 또는 다변량 메타회귀뿐인데 IPD는 현재 없다. 따라서 도구 규칙:

1. **사전 지정 위계(hierarchy)**: 주 축 1개를 미리 정한다 — 권장: 호산구(근거 질이 가장 높음 — 사전 층화 존재) > OCS 의존(설계 동질) > FeNO > 알레르기성. 환자가 여러 축에 해당하면 **위계상 최상위 축의 NMA 결과를 주 결과로** 표시.
2. **일치성(concordance) 병렬 표시**: 해당하는 다른 축들의 결과를 부 결과로 나란히 보여주고, 방향이 일치하면 "하위군 간 일관됨" 배지, 불일치하면 "하위군 간 상이 — 해석 주의" 배지. 정량 합성은 하지 않는다.
3. **표현**: "당신은 3개 분석군에 해당합니다. 주 분석(호산구 ≥300)에서는 ○○, 나머지 2개 분석에서도 같은 방향이었습니다" — 이것이 곱셈 없이 다중 소속을 정직하게 전달하는 방법이다.

## 2. 병렬 카드 관련

### 2-1. "환자 기저치 절대 수치 — 변경이 안 되었는데?"

지난 회차 반영이 **카드 하단 요약 박스에만** 적용되고 지표별 행은 상대효과 그대로였다 — 지적이 맞다. 이번에 **지표별 행의 주 표시를 환자 맥락 절대 수치로 전면 교체**했다:

- 악화율: "연 3.0회 → 약 1.4회 (CI 0.9–1.8)" ← 주 표시. RAR 0.45와 GRADE는 부 표시(작은 글씨)로.
- OCS: 환자 입력 용량 기준 "7.5 → 약 3.8 mg/day (CI …)". 감량률 CI 하한이 −100%를 넘는 경우(omalizumab −153%) 0mg에서 절단하고 "중단 가능성 포함" 표기.
- ACQ·FEV1·AQLQ: 원래 절대 지표(MD)이므로 "ACQ 약 0.3점 개선 (CI 0.1–0.4)" 문장형으로.
- omalizumab 악화 지표는 발생률비(event RR)라 횟수 환산이 성립하지 않음 → "악화 위험 약 32% 감소"로 표기(측정지표 차이를 각주로 명시).

### 2-2. 환자가 읽기 어렵다 — 이중 모드 UI 도입

데모에 **[의료진 보기 / 환자 보기] 토글**을 넣었다. 환자 보기 원칙:

- 전문 기호 제거 (RAR·CI·⊕·MCID 용어 미노출), 근거 확실성은 말로("높음/중간/낮음")
- 자연 빈도 문장: "1년에 3번 → 약 1번"
- MCID 미달의 환자어 번역: "검사 수치와 증상 점수도 좋아지지만, 뚜렷이 체감될 정도는 아닐 수 있어요"
- 점수·순위 숨김 ('우선 검토 후보' 배지만 유지), 마지막 줄은 항상 "담당 의사와 상의해 결정하세요"
- 향후: 아이콘 어레이(10명 중 몇 명 그림) 등 위험 소통 표준 기법 적용 검토

### 2-3. 선호도 축 ↔ 지표 매핑과 축 내 가중치

지적대로 '효과' 축 하나에 여러 지표(악화·OCS·조절도·폐기능·삶의 질)가 접힌다. **축 내 지표 가중치의 근거는 이미 확보되어 있다 — I-7 환자 설문의 '기대효과 중요도 100점 배분'(표7.2)이 정확히 지표 수준의 환자 가중치다:**

| 표7.2 항목 (환자 배분 평균) | 대응 지표 | 축 내 가중치 u |
|---|---|---|
| 증상 개선 33.5 | ACQ/ACT | 0.335 |
| 스테로이드 부작용 위험 감소 21.4 | OCS 감량 | 0.214 |
| 검사 수치 개선 15.8 | FEV1 | 0.158 |
| 입원·응급실 감소 14.7 | 악화율 | 0.147 |
| 일상생활 제약 해소 14.6 | AQLQ | 0.146 |

**지표별 점수의 표준화는 MCID 배수**로 한다 (지표마다 단위가 달라 직접 비교 불가하므로): r_j = |효과_j| / |MCID_j|, 1.5배에서 상한. 그러면:

```
s_효과(d) = Σ_j u_j × min(r_j, 1.5)/1.5 × 100

처리 규칙:
- 유의하지 않은 지표(ns): r=0 (효과 없음의 근거이므로 0점)
- 근거 자체가 없는 지표(예: reslizumab OCS): 해당 u를 제외하고 재정규화
  + "일부 지표 근거 없음" 표기 (근거 부재 ≠ 효과 없음이므로 0점과 구분)
```

이 설계의 장점: ① 축 내 가중치가 연구진의 임의 설정이 아니라 **환자 108명 조사 결과**라는 정당성, ② MCID 배수라는 무단위 표준화로 지표 간 합산이 성립, ③ I-5 전문가 조사(핵심적/중요한 2단계)를 대안 가중치로 민감도 분석 가능. 데모에 이 계산을 구현했다. 대안으로 v3에서 이산선택실험(DCE) 기반 정밀 가중치 도출 가능.

### 2-4. 비용

**(a) 기간 통일** — 동의. 투여 주기가 달라(벤라 8주 vs 두필 2주) 기간을 고정해야 비교가 성립한다. 제안: **① 첫 12개월(로딩 포함), ② 유지 12개월, ③ 반응 평가 시점까지(예: 16주)** 3개 창을 계산하고 기본 표시는 '첫 12개월'.

**(b) 급여 기준 충족 전제** — 동의, 분석 단순화에 합리적. 전제 명시: "급여 인정 환자, 외래 원내 투여, 본인부담률 파라미터(기본 30%, 설정 가능)". 자가투여 처방(약국 조제) 경로는 본인부담 구조가 다를 수 있어 별도 시나리오.

**(c) 실손보험 반영 — 가능하다. 단 '자동 판정'이 아니라 '환자 입력 파라미터'로.** 실손 조건은 가입 세대(1~4세대)·특약별로 달라 자동 추정이 불가능하므로, 환자가 자기 증권 기준을 입력하는 계산기 구조로:

```
입력: 실손 가입 여부 / 세대(또는 직접 입력) / 통원 1회당 보장한도(예: 25만원)
     / 자기부담(정액 공제 + 정률 %) / 연간 보장한도·통원 횟수 한도

세션(통원 1회)당 실질 부담 =
  본인부담금 − min( max(본인부담금 − 정액공제, 0) × (1−정률), 회당 한도 )
연간 실질 부담 = Σ 세션 × 연간 투여 횟수  (연간 한도·횟수 한도에서 절단)
```

주의점 두 가지를 고지: 4세대 실손은 급여/비급여 분리 보장(급여 통원 공제·정률이 다름), 그리고 **회당 한도 구조 때문에 투여 간격이 긴 약제(벤라 8주)와 짧은 약제(두필 2주)의 실손 후 실질 부담 순위가 뒤집힐 수 있다** — 두필은 통원 횟수가 많아 회당 한도를 26번 활용, 벤라는 6.5번. 이것이 실손 반영이 중요한 실질적 이유이며, 도구가 보여줄 가치가 있는 비자명한 결과다.

**(d) RSA 환급 — 반영 불가하지만, 반영할 필요도 없다.** 환급형 RSA의 환급률은 제약사-공단 간 **비밀 계약**이라 약제별 조건 분석 자체가 불가능하다. 그러나 환자 본인부담금은 **표시가(고시 상한금액) 기준으로 부과**되고 환급은 공단-제약사 사이에서만 일어나므로, **환자 관점 비용 계산에는 표시가 사용이 오히려 정확하다.** RSA 미반영으로 왜곡되는 것은 보험자(공단) 재정 관점의 비용뿐이다. 도구에 "환자 본인부담 관점 · 고시 표시가 기준 (보험자 실질 부담과는 다를 수 있음)" 한 줄을 명시하면 해결된다.

## 이번 회차 반영 사항 (데모)

1. 6개 약제 카드 전부 KQ1~6 실측치로 교체 완료 (가상 효과값 소멸 — 비용·편의 축 점수만 가상 유지)
2. 지표별 행 주 표시를 환자 맥락 절대 수치로 교체 (2-1)
3. 의료진/환자 이중 모드 토글 (2-2)
4. 효과 축 점수를 'MCID 배수 × 환자 설문 지표 가중치' 합성으로 교체 (2-3)

## 운영위 결정 사항 (누적 갱신)

1. NMA: 주 분석 축 위계(호산구 > OCS 의존 > FeNO > 알레르기성) 승인 여부, 출판 전략(지침 논문과 분리 여부)
2. 효과 축 내 가중치: 환자 설문(표7.2) 기반 vs 전문가 조사(I-5) 기반 vs 병기 — 기본값 선택
3. 비용: 기간 창(첫 1년/유지 1년/평가 시점) 기본값, 본인부담률 파라미터, 실손 계산기 포함 여부
4. 환자 보기 문안 감수 (환자 위원 참여 권장)
