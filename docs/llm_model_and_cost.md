# 프로세스별 LLM 모델 추천 + 환자 1인 전체 처리 토큰·비용 (item 12)

> 산정 방법: 실제 코드의 프롬프트를 문자 기준 토큰 근사(한글 음절 ≈1토큰, ASCII ≈4자/토큰,
> o200k_base 근사)로 계산 + gpt-4o **high-detail 이미지 타일 공식**(85 + 170×타일)으로 이미지
> 토큰 산정. **유료 호출 없이** 측정했습니다(정확 출력 토큰은 실호출로만 확정 — 필요 시 아래
> "실측 옵션" 참고). 단가는 공개 가격 기준이며 변동될 수 있습니다.

## 1. 파이프라인 단계별 LLM 필요 여부 + 모델 추천 (item 12-a)

| 단계 | LLM 필요 | 추천(1순위) | 대안 | 이유 |
|------|:--------:|-------------|------|------|
| **OCR (검사지 이미지 → 구조화 JSON)** | ✅ | **OpenAI gpt-4o** (vision) | Anthropic Claude(표 정확도), Google Gemini 2.0 Flash(대량 저비용) | UniCAP=ImmunoCAP 검사지, JSON 모드 안정성·다열 MAST 표 판독. 의료 표 OCR은 vision 품질이 결과 신뢰도를 좌우 |
| **알러젠 매핑·SNOMED/CDM 코딩** | ❌ | — (레지스트리·규칙) | | `allergens.json` + 매퍼로 결정론적. LLM 불필요(재현성·감사성) |
| **문진 생성·판정(감작 vs 임상)** | ❌ | — (규칙 엔진) | | 성분 교차반응 엔진·category_resolver 등 데이터 주도. LLM 배제가 안전 |
| **교차반응 파생(OAS/성분)** | ❌ | — (component 엔진) | | 구조화 데이터. LLM 불필요 |
| **FHIR 변환(Observation/AllergyIntolerance)** | ❌ | — (fhir_service) | | 표준 매핑, 결정론적 |
| **카드뉴스(HTML)** | ❌ | — (템플릿) | | 결정론적 생성, 비용 0 |
| **맞춤 리포트(내러티브)** | ⭕ 선택 | **Anthropic Claude**(한국어 공감형 장문) | OpenAI gpt-4o, 저비용은 gpt-4o-mini/Claude Haiku | 기본은 **결정론적 리포트(무료)**. 감성적 서술이 필요할 때만 LLM |
| **상담 챗봇(Q&A)** | ✅(대화형) | **gpt-4o-mini** 또는 **Claude Haiku** | gpt-4o(복잡 질의) | 지연·비용 최적. 1회 실행 파이프라인엔 미포함(메시지당 과금) |

**핵심:** 전체 12단계 중 **LLM이 반드시 필요한 곳은 OCR 1곳**뿐입니다. 나머지는 구조화
데이터·규칙 엔진으로 이미 결정론적이라 **비용 0 + 재현성·안전성**을 확보합니다. 리포트
내러티브만 선택적으로 LLM을 씁니다.

> 참고: 개발(코드 작성)은 사용자 요청대로 **Fable 5(Claude)** 로 진행하며, 위 표는 **제품
> 런타임**의 단계별 모델 선택입니다(별개 사안).

## 2. 환자 1인 전체 처리 토큰·비용 (item 12-b)

측정 기준값(실제 코드):
- OCR 프롬프트+시스템: **≈569 토큰**(2,115자)
- gpt-4o high-detail 이미지: **1,105 토큰/장**(A4 스캔 1024²~2048² 모두 6타일 동일)
- OCR 출력 JSON: 항원당 ≈35토큰 → 40개 **≈1,400** / 90개 **≈3,150**
- 결정론적 리포트: **≈1,582 토큰**(2,178자) — LLM 리포트의 입력 본문

### 2-1. 토큰 집계 (대표: 단일 이미지 + MAST 40~70 항원)

| 단계 | 모델 | 입력 토큰 | 출력 토큰 |
|------|------|----------:|----------:|
| OCR | gpt-4o | 1,105(img) + 569(prompt) = **1,674** | **≈2,000** (40~70항원) |
| 리포트(LLM, 선택) | gpt-4o | 1,582 + 지시 ≈500 = **≈2,100** | **≈3,500** (내러티브, max 9,600) |
| 문진·판정·교차·FHIR·카드뉴스 | — | 0 | 0 |

### 2-2. 비용 (gpt-4o 단가 $2.50/1M 입력, $10.00/1M 출력)

| 시나리오 | 계산 | USD | KRW(₩1,380/$) |
|----------|------|----:|----:|
| **OCR만** (기본, 결정론적 리포트) | 1,674×2.5 + 2,000×10 (÷1e6) | **$0.0242** | **≈₩33** |
| **OCR + LLM 리포트** | 위 + (2,100×2.5 + 3,500×10)/1e6 | **$0.0645** | **≈₩89** |
| 대형 패널(2장 이미지 + 90항원) OCR만 | (2×1,105+569)×2.5 + 3,150×10 | **$0.0389** | **≈₩54** |

**요약:** 환자 1인 **표준 실행 ≈$0.024(₩33)** — OCR만, 리포트는 무료 결정론적.
감성 리포트까지 LLM으로 생성 시 **≈$0.065(₩89)**.

### 2-3. 저비용 대안 (동일 파이프라인, 모델만 교체)

| 구성 | OCR | 리포트 | 환자 1인 |
|------|-----|--------|---------:|
| 현행 | gpt-4o | gpt-4o | $0.065 |
| 절충 | gpt-4o | gpt-4o-mini($0.15/$0.60) | ≈$0.027 |
| 최저 | Gemini 2.0 Flash(≈$0.10/$0.40) | 결정론적(무료) | ≈$0.001~0.01 |

> OCR 출력 토큰이 비용의 대부분(출력 단가가 4배)입니다. 항원 수가 많은 대형 MAST일수록
> 출력 토큰이 늘어 비용이 선형 증가합니다.

## 3. 실측 옵션(정확 출력 토큰 확정)

정확한 출력 토큰은 실제 API 응답의 `usage` 필드로만 확정됩니다. 원하시면 제공하신 키를
**환경변수로만**(`export OPENAI_API_KEY=…`, 파일/커밋 금지) 주입해 샘플 검사지 1건을
실행하고 `usage.prompt_tokens/completion_tokens` 실측표를 드립니다.

## 4. ⚠️ 보안 — API 키 회전 필요

item 11에서 키를 **평문으로 공유**하셨습니다. 저장소·로그·커밋 어디에도 저장하지
않았지만(코드/문서에 미포함), 평문 노출된 키는 **즉시 회전(재발급)**을 권고드립니다:
OpenAI 대시보드 → API keys → 해당 키 revoke → 신규 발급 → `.env`(gitignore) 또는 배포
비밀관리자에만 저장. 이 문서에도 키는 포함하지 않았습니다.
