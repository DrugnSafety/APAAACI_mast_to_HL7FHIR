- [ ] 개인정보·민감정보·선택 동의를 구분한다.
- [ ] 연구자 현장 절차와 안전 계획을 제출한다.
- [ ] HIS·서버·위탁·보관 계획을 제출한다.
- [ ] 임상 문진과 별도 사후 설문·문안을 제출한다.
- [ ] 사후 선택 동의와 추가 알림·부담을 설명한다.
- [ ] 사후 24시간 최소 응답창과 중복 차단을 검증한다.
- [ ] 모집 안내문과 동의 취득 장소를 확정한다.
- [ ] 연구자 이력·교육·위임·이해상충 서류를 갖춘다.
- [ ] 기관 기준의 피해 구제와 보험 적용을 확인한다.

## 6. 개발 자료와 전향적 연구의 구분

기존 스캔 평가는 29건의 개발 자료를 사용했습니다.
MAST 25건과 피부단자검사 4건입니다.
UniCAP 실제 스캔은 이 묶음에 없습니다.

다운로드 모음은 입력원별 87개 생성 세트입니다.
참조값·OpenAI·로컬 모델 입력을 각각 사용했습니다.
이 세트에는 환자의 실제 문진 답변이 없습니다.
임상 관련성은 '확인되지 않음'으로 유지했습니다.

이 29건을 이번 연구의 새 동의 대상자로 세지 않습니다.
기존 사진의 연구 이용 근거와 재사용 범위는 별도로 확인합니다.
기존 OpenAI 비교는 병원 환자자료 외부 전송의 허가가 아닙니다.
기본 운영안은 병원 승인 내부 서버와 내부 모델입니다.
