# 연구자 설명문과 현장 운영 절차

> 버전 0.2 · 2026-10-29 · IRB 심의용 초안 · 미승인
> 실제 모집·HIS 연계·환자 발송 전에 승인을 받습니다.
> 표본과 일정은 작성자 제안입니다. 책임연구자와 IRB가 확정합니다.

## 1. 연구자에게 요청하는 업무

충북대학교병원 알레르기내과 검사실 환자를 모집합니다.
소아를 포함하되 법정대리인 동의를 받습니다.
아이의 이해 수준에 맞는 설명과 승낙 절차도 시행합니다.
아이가 거부하면 참여를 진행하지 않습니다.

연구자는 통상 진료 검사와 모바일 문진을 연결합니다.
시스템은 리포트, 카드뉴스와 FHIR 파일 초안을 만듭니다.
FHIR는 국제 의료정보 교환 형식입니다.
연구 담당자는 모든 환자용 자료를 대조합니다.
자격을 갖춘 의료진은 임상 내용을 승인합니다.

## 2. 연구 기본안

| 항목 | 작성자 제안 또는 확정 필요 항목 |
| --- | --- |
| 연구기관 | 충북대학교병원 알레르기내과 검사실 |
| 연구책임자 | 강민규 · 제출 전 책임지정 확인 |
| 모집 수 | 120명 · 성인 90명, 소아 30명 |
| 연구 기간 | IRB 승인일부터 24개월 |
| 개인 참여 | 해당 검사 결과 확정일부터 최대 30일 |
| 임상 문진 | 10~15분 |
| 사후 만족도 설문 | 6문항·선택 의견 300자 · 약 2분 설계 목표 |
| 임상 문진 응답 기간 | 첫 문진 안내 후 14일 |
| 임상 문진 추가 안내 | 3일째와 7일째, 최대 2회 |
| 사후 초대 | 첫 본인 확인 열람·연구자 수령 확인 후 24시간 |
| 사후 응답창 | 초대 후 7일·결과 확정 후 30일 중 이른 때까지 |
| 사후 재알림 | 초대 후 3일, 최대 1회 |
| 검수 목표 | 문진 완료 후 3영업일 · 보장 시간 아님 |
| 연구 기록 | 종료 후 3년 보관 제안 · 법령과 기관 규정 확인 |

18세 대상자의 동의 경로는 IRB가 확정합니다.
승낙 연령과 부모 동의 인원도 IRB가 확정합니다.
제안값을 확정 전 운영 설정으로 적용하지 않습니다.

## 3. 역할과 승인 권한

| 역할 | 책임 | 승인 또는 접근 범위 |
| --- | --- | --- |
| 연구책임자 | 연구 수행·변경·안전 보고 | 연구 운영 승인 |
| 설명 담당자 | 자발성 확인·동의·사본 제공 | 교육 이수 후 동의 취득 |
| 임상 검수자 | 검사 해석·위험 내용·개별 안내 검토 | 환자용 임상 내용 최종 승인 |
| 연구 담당자 | 자료 대조·누락 확인·질 관리 | 위임 범위의 연구 검수 |
| 의료정보센터 | HIS·서버·GPU·인증·알림톡 연계 | 기관 승인 시스템 운영 |
| 정보보호 담당자 | 접근통제·위탁·사고 대응 | 보안 기준 검토 |
| 소아 협력자 | 설명 수준·보호자 권한 확인 | IRB 승인 소아 절차 지원 |

연구 담당자의 검수로 의료진의 임상 승인을 대체하지 않습니다.
운영자는 자신의 권한을 임의로 늘리지 않습니다.
모델 실행 권한과 환자 발송 권한을 분리합니다.

## 4. 모집 전에 확인할 사항

- 최신 승인 설명문과 동의서를 준비하십시오.
- 연구자 교육과 위임 기록을 확인하십시오.
- 진료와 연구 참여를 구분하여 설명하십시오.
- 연구 거절이 진료에 영향을 주지 않음을 알리십시오.
- 질문할 시간과 숙고할 시간을 제공하십시오.
- 연구 연락처와 권리 문의처를 제공하십시오.

응급 상태에서는 연구 설명을 우선하지 않습니다.
판단 능력이 없는 성인에게 성인 동의 경로를 적용하지 않습니다.
치료 결정을 유도하는 표현을 쓰지 않습니다.

## 5. 성인 설명과 동의

1. 설명문 버전과 대상자 신원을 확인하십시오.
2. 연구 목적과 전체 절차를 설명하십시오.
3. 수집할 검사값과 문진 항목을 설명하십시오.
4. 개인정보 침해와 잘못된 해석 위험을 설명하십시오.
5. 사람이 검수한 뒤 자료를 보냄을 설명하십시오.
6. 카카오 안내와 인증 절차를 설명하십시오.
7. 철회 방법과 이미 받은 파일의 한계를 설명하십시오.
8. 대상자가 이해한 내용을 말하도록 요청하십시오.
9. 질문에 답한 뒤 참여 의사를 확인하십시오.
10. 연구·개인정보·민감정보 동의를 각각 확인하십시오.
11. 선택 동의는 별도로 확인하십시오.
12. 서명과 날짜를 기록하고 사본을 제공하십시오.

이해 확인은 시험이나 참여 압박으로 사용하지 않습니다.
참여자는 필수 절차를 이해하지 못하면 설명을 다시 받습니다.
연구자는 사전 선택된 체크박스를 사용하지 않습니다.

## 6. 소아와 보호자 절차

1. 병원 기준으로 법정대리인 권한을 확인하십시오.
2. 관계와 확인 방법을 승인 서식에 기록하십시오.
3. 보호자에게 설명문을 제공하십시오.
4. 아이에게 발달 수준에 맞게 설명하십시오.
5. 아이의 질문과 거부 의사를 확인하십시오.
6. 보호자 동의와 아이의 승낙을 각각 기록하십시오.
7. 보호자 수신번호와 대리응답 권한을 확인하십시오.
8. 설명문과 동의서 사본을 제공하십시오.

동행한 성인을 법정대리인으로 자동 등록하지 않습니다.
보호자 응답은 아이의 직접 응답과 구분합니다.
가족관계 증명 자료는 병원 기준의 최소 범위로 확인합니다.
불필요한 신분증 사본을 연구 자료에 보관하지 않습니다.
참여 중 연령이나 의사결정 능력이 바뀌면 재동의를 검토합니다.

## 7. HIS 결과와 연구 대기열 연결

병원정보시스템을 HIS라고 합니다.
결과가 저장되면 동의와 검사 적격성을 확인합니다.
확정 상태의 승인된 검사만 대기열에 등록합니다.
주 분석은 대상자별 첫 적격 검사 회차를 사용합니다.
반복 검사는 별도 분석 단위로 표시합니다.

대기열은 같은 사건을 중복 처리하지 않아야 합니다.
식별자는 연구번호, 검사 회차와 결과 버전을 조합합니다.
주민등록번호와 성명은 분석용 대기열에 넣지 않습니다.
병원 환자번호와 연구번호의 연결표는 별도로 보호합니다.

수정 결과가 들어오면 이전 결과를 덮어쓰지 않습니다.
기존 승인을 취소하고 새 버전의 검수를 요청합니다.
철회 상태는 등록 시점과 발송 직전에 다시 확인합니다.

## 8. 임상 문진 안내와 응답 처리

알림톡 본문에 검사명과 검사값을 넣지 않습니다.
인증 주소에는 환자번호와 검사값을 넣지 않습니다.
대상자는 만료 기간이 있는 안내 주소로 접속합니다.
서버는 본인 또는 승인 보호자의 권한을 확인합니다.

1. 동의 상태와 수신번호를 다시 확인하십시오.
2. 승인된 알림톡 양식으로 설문 주소를 보내십시오.
3. 응답자와 환자의 관계를 기록하십시오.
4. 저장한 답변과 문항 버전을 기록하십시오.
5. 미응답과 알 수 없음을 구분하십시오.
6. 임상 문진을 완료하면 그 재알림을 중단하십시오.

미응답을 증상 없음으로 바꾸지 않습니다.
수신 실패는 설문 거절과 구분합니다.
추가 안내 횟수와 기간은 승인된 범위를 따릅니다.
급성 증상에 대한 진료 안내는 설문과 구분합니다.

## 9. 자료 생성과 임상 검수

의료정보센터가 관리하는 내부 GPU를 사용합니다.
병원이 승인한 내부 모델의 식별자와 실행 조건을 기록합니다.
병원에서 승인한 모델과 지식 자료 버전을 고정합니다.
실제 환자정보의 외부 API 처리는 기본안에 포함하지 않습니다.

모든 생성 파일은 검수 대기 상태로 저장합니다.
검수자는 원본 결과, 문진과 생성 자료를 함께 봅니다.

| 검수 항목 | 확인 내용 |
| --- | --- |
| 대상자 | 연구번호·검사 회차·응답자·수신자 일치 |
| 검사값 | 항원명·수치·단위·등급·검출한계 표기 |
| 피부단자검사 | 직경·평균값·대조군·판독 기준 |
| 문진 | 실제 답변·미응답·대리응답 구분 |
| 임상 해석 | 감작과 임상 알레르기 구분 |
| 근거 | 근거 출처·버전·적용 범위 확인 |
| 리포트 | 잘못된 금식·약물 중단·치료 권고 방지 |
| 카드뉴스 | 환자값과 연결된 내용·가독성·누락 |
| FHIR | 환자 연결·자원 형식·상태·용어·단위 |
| 최종 파일 | 버전·해시·검수자·승인 시간 |

양성 검사만으로 알레르기를 확정하지 않습니다.
문진이 없으면 임상 관련성을 확인되지 않음으로 표시합니다.
FHIR 형식 검증은 임상 정확성 검수를 대체하지 않습니다.

검수자는 승인, 반려 또는 보류를 선택합니다.
수정하면 새 파일을 만들고 다시 검수합니다.
승인은 검수한 파일 해시에 연결합니다.
승인 뒤 파일이 바뀌면 발송을 차단합니다.

## 10. 검수 완료 자료 전달

기본안은 카카오 메시지의 인증된 다운로드 주소입니다.
환자는 PDF와 카드뉴스를 확인할 수 있습니다.
FHIR 파일은 별도 선택한 경우 제공할 수 있습니다.

PDF 직접 첨부는 서비스 지원과 병원 승인이 필요합니다.
첨부를 쓰려면 실제 전송 항목과 위험을 별도로 설명합니다.
첨부 동의가 없으면 인증 주소 경로를 사용합니다.

1. 최신 동의와 파일 승인을 확인하십시오.
2. 대상자와 수신자를 다시 대조하십시오.
3. 만료 기간이 있는 결과 주소를 발급하십시오.
4. 승인 양식으로 안내를 보내십시오.
5. 제공 파일 버전과 발송 결과를 기록하십시오.

클릭 기록을 실제 내용 이해로 해석하지 않습니다.
자료는 진료와 응급 대응을 대체하지 않습니다.

## 10A. 선택 사후 만족도 설문

사후 설문은 APAAACI-SAT-01 버전 0.1입니다.
6문항과 선택 의견 300자로 구성합니다.
약 2분은 설계 목표이며 예비 조사로 확인합니다.
검증된 척도로 부르거나 점수를 합산하지 않습니다.
이해도 정답 퀴즈를 별도로 시행하지 않습니다.

1. 사후 참여와 별도 안내 수신 선택을 확인하십시오.
2. 임상 문진과 별도인 추가 부담을 설명하십시오.
3. 자료의 첫 열람 또는 수령 확인을 기록하십시오.
4. 본인 확인 후 열람인지 확인하십시오.
5. 연구자 수령 확인이면 확인 방법을 기록하십시오.
6. 첫 확인 기록 후 24시간으로 초대를 예약하십시오.
7. 초대 직전 동의와 수신 권한을 확인하십시오.
8. 초대 직전 정정과 철회 상태를 확인하십시오.
9. 남은 응답시간이 24시간 미만이면 보내지 마십시오.
10. 제출과 거절·미응답·미열람을 구분하십시오.

위 사후 일정은 작성자 제안이며 IRB가 확정합니다.
알림톡 전달 영수증만으로 수령과 읽음을 단정하지 않습니다.
수령 확인도 내용 이해의 증거로 쓰지 않습니다.
응답창은 초대 후 7일과 결과 확정 후 30일 중 이른 때까지입니다.
재알림은 초대 후 3일에 최대 1회만 제안합니다.
제출·거절·철회·만료 후 재알림을 보내지 않습니다.

정정 중에는 사후 초대 예약을 보류합니다.
이미 초대한 검사 회차에는 자동 추가 초대하지 않습니다.
임상 문진의 14일 창과 3일·7일 안내와 구분합니다.
임상 문진 재알림은 최대 2회입니다.
사후 응답 여부로 진료와 자료 전달을 제한하지 않습니다.

응답자는 본인·입력 도움을 받은 본인·보호자로 구분합니다.
입력 도움은 본인의 답을 보호자의 답으로 바꾸지 않습니다.
보호자는 자신이 받은 안내 경험을 평가합니다.
미열람자는 이유를 고르고 점수 6문항을 건너뜁니다.
미응답·평가 어려움·미열람을 0점으로 바꾸지 않습니다.

연구진은 연구번호와 등록 검사 회차로 답변을 연결합니다.
익명 설문이라고 설명하지 않습니다.
의견은 300자 상한을 확인하고 식별정보 입력을 막도록 안내합니다.
응답과 자유 의견을 외부 AI나 언어모델에 보내지 않습니다.
사후 설문만 중단하면 그 범위의 예약과 접근을 차단합니다.
주 연구의 동의 철회 시 모든 사후 예약과 접근도 차단합니다.

## 11. 철회와 사고 대응

철회 요청을 받으면 새 처리와 발송을 중단합니다.
대기열, 재시도, 예약 안내와 다운로드 권한을 차단합니다.
사후 초대·재알림 예약과 설문 주소도 차단합니다.
법령상 보관 기록과 이미 완료한 분석은 구분하여 설명합니다.
통상 진료의 HIS 기록은 연구 철회로 삭제하지 않습니다.
이미 내려받은 PDF는 원격으로 회수할 수 없습니다.

오발송이나 노출 의심 시 추가 발송을 중단합니다.
접근 주소를 폐기하고 사고 대응 담당자에게 보고합니다.
실제 노출 항목과 접근 기록을 보존합니다.
기관 기준에 따라 통지와 IRB 보고를 진행합니다.
정정 자료도 다시 검수한 뒤 제공합니다.

## 12. 가동 전에 통과할 조건

- [ ] IRB 승인과 확정 문서 버전을 등록한다.
- [ ] 연구자 교육과 위임 기록을 갖춘다.
- [ ] 보호자 권한과 소아 승낙 경로를 확정한다.
- [ ] HIS 수정·중복·철회 시험을 통과한다.
- [ ] 내부 GPU와 모델 사용 조건을 승인받는다.
- [ ] 외부 모델 자동 우회가 차단되는지 확인한다.
- [ ] 알림톡 계약과 위탁·재위탁 범위를 확정한다.
- [ ] 인증·권한·만료·오발송 차단 시험을 통과한다.
- [ ] 검수 전 파일 노출이 차단되는지 확인한다.
- [ ] 사후 선택 동의와 초대 기한 시험을 통과한다.
- [ ] 사후 철회·미열람·중복·정정 분기를 검증한다.
- [ ] 백업 복구와 운영 중단 훈련을 수행한다.
