**버전 0.2 · 2026-10-29 · 미승인 · 모집과 실제 발송 전**

목적: 연구 범위와 제출 전 확정 항목을 확인한다.

## 2. 용어

| 용어 | 이 연구의 뜻 |
|---|---|
| HIS | 병원정보시스템 · 진료 검사 결과를 저장하는 체계 |
| 적격 결과 | 동의 후 확정한 연구 대상 검사 결과 |
| 문진 | 증상과 검사 관련 경험을 묻는 모바일 설문 |

| 검수 승인 | 의료진이 최종 임상 내용을 확인한 상태 |
| 인증 전달 | 확인한 수신자가 인증 후 자료에 접근한 상태 |

## 3. 연구 목적과 설계

연구진은 검사 결과 설명자료의 실행가능성을 평가한다.
연구진은 결과값과 설명자료의 정확성도 평가한다.
본 연구는 전향적 단일기관 연구이다.
본 연구는 치료 효과를 입증하는 임상시험이 아니다.

대상자는 통상 진료로 알레르기 검사를 받는다.
연구진은 연구용 추가 검사를 시행하지 않는다.
연구진은 검체를 추가 채취하지 않는다.
연구진은 통상 진료와 처방을 바꾸지 않는다.

연구 범위는 MAST, 피부단자검사(SPT), 특이 IgE이다.
특이 IgE에는 UniCAP과 ImmunoCAP 등 해당 검사를 포함한다.
실제 포함 장비와 검사코드는 승인 전에 확정한다.

연구자는 모집 전에 IRB 심의를 받아야 한다.
[생명윤리법 제15조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025168733)를 적용한다.

## 4. 대상자와 제안 수치

아래 수치는 **작성자 제안(PROPOSED)**이다.
책임연구자와 IRB가 수치와 기간을 확정한다.
아래 수치는 승인된 모집계획이 아니다.

| 항목 | 작성자 제안(PROPOSED) |
|---|---|
| 총 모집수 | 120명 |
| 성인·소아 목표 | 성인 90명, 소아 30명 |
| 연구기간 | IRB 승인일부터 24개월 |
| 대상자 참여기간 | 해당 검사 결과 확정일부터 최대 30일 |
| 본 문진 시간 | 10~15분 |
| 사후 만족도 설문 | 6문항·선택 의견 300자 · 약 2분 설계 목표 |
| 임상 문진 응답기간 | 최초 문진 발송 후 14일 |
| 임상 문진 재알림 | 최초 문진 발송 후 3일과 7일 · 최대 2회 |
| 검토 목표 | 임상 문진 완료 후 3영업일 이내 |
| 임시 접근 URL | 발급 후 최대 30일 · 철회 시 즉시 폐기 |
| 연구기록 보관 | 연구 종료 후 3년 · 추가 규정은 확인 |
| 금전 보상 | 없음 · 제안 |

검토 목표는 결과 제공을 보장하는 기한이 아니다.
전체 연구비와 피해 구제 절차는 별도 확정한다.
통상 진료비와 개인 통신요금은 별도이다.

모든 연령의 적격 환자를 모집 대상으로 한다.
소아는 법정대리인 동의 절차를 거친다.
연구진은 발달 수준에 맞춰 소아에게 설명한다.
소아의 승낙과 거부를 기록하고 존중한다.
18세 경로와 승낙 연령대는 IRB가 확정한다.
필요한 부모 동의 인원도 IRB가 확정한다.

대리 동의는 대상자의 의사에 반할 수 없다.
[생명윤리법 제16조](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsId=009628&lsJoLnkSeq=900406343&print=print)를 따른다.
14세 미만 개인정보 동의에는 별도 확인이 필요하다.
[개인정보 보호법 제22조의2](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029331669)를 따른다.

## 5. 대상자 절차 6단계

1. 연구진은 병원에서 연구를 설명하고 동의를 받는다.
2. 의료정보팀은 동의 후 확정한 HIS 결과를 큐에 등록한다.
3. 병원 알림톡 서비스는 문진 URL을 발송한다.
4. 병원 서버는 응답을 받고 자료 후보를 생성한다.
5. 의료진은 자료 후보를 검수하고 승인한다.
6. 병원 서비스는 승인 자료의 접근 방법을 안내한다.

생성 자료는 결과 보고서 PDF, 카드뉴스, FHIR이다.
연구진은 완결성과 기술적 오류를 먼저 확인한다.
의료진은 최종 임상 검수를 담당한다.
연구진의 비임상 확인만으로 환자에게 발송하지 않는다.
자료를 다시 생성하면 의료진이 다시 검수한다.

기본 PDF 전달 방식은 인증 후 다운로드 URL이다.
카드뉴스는 인증 URL로 제공한다.
FHIR은 대상자 또는 보호자가 원할 때 제공한다.
직접 PDF 첨부는 플랫폼과 보안 검토 후 결정한다.
승인 전에는 직접 첨부를 시행하지 않는다.
알림톡 본문에는 검사값과 진단명을 넣지 않는다.

## 6. 시스템 범위

기본안은 병원 내부 서버에서 환자정보를 처리한다.
의료정보센터가 관리하는 GPU 사용을 협의한다.
연구진은 내부 qwen3.8 운영 구성을 제안한다.
정확한 모델 식별자와 배포 가능성은 확인하지 못했다.
DGX Spark에서 병원 서버로의 이전은 향후 협의 사항이다.

병원 HIS와 병원 알림톡 서비스 연계가 필요하다.
현재 이 문서는 설치와 연계 완료를 증명하지 않는다.
의료정보팀 협의 내용은 별도 요청서에서 확인한다.
[의료정보팀 협조 요청서](../../medical_information_cooperation_2026-10-29/index.html)

실제 환자정보의 외부 모델 API 전송은 제외한다.
국외 이전과 모델 학습 이용도 기본안에서 제외한다.
범위를 추가하면 변경심의와 적법한 절차를 거친다.

## 7. 주요 평가변수

일차 지표는 30일 내 승인 자료의 인증 전달률이다.
30일 기준은 **작성자 제안(PROPOSED)**이다.

분모는 동의 후 적격 HIS 확정 결과가 생긴 등록자이다.
대상자당 첫 적격 검사 사건 1건을 일차 분석에 쓴다.
분자는 의료진 승인 후 인증 전달을 마친 대상자이다.
수신자 확인과 결과 확정 후 30일 이내 조건을 적용한다.
발송업체의 수신 접수는 인증 전달로 세지 않는다.

미응답과 생성 실패는 일차 분모에 남긴다.
검수 반려와 전달 실패도 일차 분모에 남긴다.
완료자만 분모로 삼아 성공률을 높이지 않는다.
연구진은 비율과 Wilson 95% 신뢰구간을 제시한다.
본 연구는 탐색 연구이며 치료 효과를 입증하지 않는다.

이차 지표는 다음 항목을 포함한다.

- 보고서별·검사값별·검사유형별 오류율.
- 중대한 오류의 건수와 종류.
- 문진 완료율과 검수 시간.
- 사후 만족도 6문항의 분포와 전반 만족도 S6.
- S6의 유효한 1~5점 응답 중 4~5점 비율.
- 성인과 소아의 기술 통계.
- 본인 응답과 보호자 대리 응답의 별도 결과.

사후 설문은 APAAACI-SAT-01 버전 0.1을 사용한다.
6문항과 선택 의견 300자로 구성한다.
약 2분은 설계 목표이며 예비 조사로 확인한다.
사후 설문은 검증된 척도가 아니다.

응답자는 본인·입력 도움을 받은 본인·보호자로 구분한다.
미열람자는 미열람 이유만 고르고 점수 문항을 건너뛴다.
본인과 보호자의 평가를 같은 응답으로 합치지 않는다.
설문 거부와 미응답은 진료와 자료 전달에 불이익이 없다.

초대는 승인 자료의 첫 확인 기록 24시간 후를 제안한다.
기록은 본인 확인 후 열람 또는 연구자의 수령 확인이다.
알림톡 전달 영수증만으로 수령과 읽음을 단정하지 않는다.
응답창은 초대 후 7일과 결과 확정 후 30일 중 이른 때까지다.
재알림은 초대 후 3일에 최대 1회만 제안한다.
초대 시 응답 가능 시간이 24시간 미만이면 보내지 않는다.

설문은 연구번호와 검사 회차로 가명 연결한다.
익명 설문이 아니며 새 식별정보를 추가하지 않는다.
철회하거나 사후 설문을 거부하면 예약과 접근을 중단한다.
사후 설문 완료를 일차 전달 성공의 조건으로 삼지 않는다.

기존 개발용 스캔 29건은 전향적 모집수에 넣지 않는다.
기존 파일의 연구 동의를 받았다고 가정하지 않는다.

## 8. 위험과 보호 조치

위험은 시간 부담, 불안, 잘못된 해석, 정보 유출이다.
잘못된 환자와 수신자의 연결도 위험에 포함한다.
연구진은 환자와 검사 사건을 이중 확인한다.
소아 자료는 확인한 법정대리인에게 전달한다.
선택한 사후 설문은 별도 알림톡과 추가 응답 부담이 있다.

구조화한 HIS 결과를 우선 사용한다.
OCR을 쓰면 원본의 모든 결과 행을 사람이 대조한다.
판독 불가 값은 정상값이나 음성값으로 바꾸지 않는다.
의료진은 환자에게 제공할 최종 내용을 확인한다.
자료는 응급 연락이나 진료를 대신하지 않는다.

직접 식별정보와 분석자료는 분리한다.
연구번호를 써도 자료를 완전 익명이라고 표현하지 않는다.
건강정보 동의는 민감정보 동의로 구분한다.
[개인정보 보호법 제23조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334793)를 따른다.

발송 위탁과 제3자 제공은 실제 계약으로 구분한다.
업체명과 실제 처리 항목은 승인 전에 확정한다.
[개인정보 보호법 제26조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029331867)와 [제17조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334815)를 검토한다.

## 9. 철회와 보관

대상자는 참여를 거부하거나 동의를 철회할 수 있다.
거부와 철회는 통상 진료에 불이익을 주지 않는다.
연구진은 매 발송 전에 유효한 동의를 다시 확인한다.
철회하면 대기 발송을 취소하고 접근 URL을 폐기한다.
이미 내려받은 파일은 원격 회수할 수 없다.
연구 철회가 HIS 진료기록의 삭제를 뜻하지 않는다.

연구기록은 연구 종료 후 3년간 보관한다.
추가 보관은 법령과 병원 규정을 IRB와 확인한다.
[생명윤리법 시행규칙 제15조](https://law.go.kr/lsInfoP.do?chrClsCd=010202&lsId=009628&lsiSeq=56388&urlMode=lsEfInfoR&viewCls=lsPtnThdCmp)를 따른다.
연락처와 임시 링크의 별도 삭제 시점은 확정한다.

## 10. 제출 전 확정 항목

- 현행 병원 신청서와 동의서 서식을 확인한다.
- 책임연구자와 담당자의 현재 정보를 확인한다.
- 제안 수치와 표본수 근거를 확정한다.
- 18세와 소아 승낙 경로를 확정한다.
- 법정대리인 확인 방식과 서명 인원을 확정한다.
- 서버 위치와 GPU·모델 배포 구성을 확정한다.
- 발송업체·재위탁·정보 항목·처리 위치를 확정한다.
- PDF 직접 첨부의 허용 여부를 확정한다.
- 보관·피해 구제·연구비 기준을 확정한다.
- 의료정보팀은 모의자료로 연계 시험을 수행한다.
- IRB 승인 후 대상자 모집과 실제 발송을 시작한다.
