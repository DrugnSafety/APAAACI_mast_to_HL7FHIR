# 문진·증례기록서·알림톡 문안

> 버전 0.2 · 2026-10-29 · IRB 심의용 초안 · 미승인
> 문항과 발송 양식은 심의와 기관 검토 후 확정합니다.
> 아래 내용은 현재 서비스에 등록된 승인 문안이 아닙니다.

## 1. 문진 첫 화면

이 설문은 연구 참여에 동의한 분을 위한 문진입니다.
답변에는 약 10~15분이 걸립니다.
답하기 어려우면 알 수 없음이나 응답하지 않음을 고르십시오.
설문은 응급 상담 창구가 아닙니다.
급한 증상이 있으면 병원의 진료 안내를 따르십시오.

보호자는 법정대리 권한 확인 뒤 답하십시오.
아이의 직접 답변과 보호자의 답변을 구분합니다.
언제든 참여 중단을 요청할 수 있습니다.
문의·철회 연락처: [연구 전화·병원 이메일 기입]

## 2. 응답자 확인

| 항목 | 선택 또는 입력 |
| --- | --- |
| 응답자 | 환자 본인 / 확인된 법정대리인 |
| 보호자 관계 | 부 / 모 / 기타 법정대리 관계 |
| 아이의 참여 | 함께 답함 / 보호자가 대신 답함 |
| 문항별 응답자 | 소아 직접 / 보호자 대리 / 함께 응답 |
| 작성 상황 | 스스로 작성 / 도움을 받아 작성 |
| 계속 참여 의사 | 참여 유지 / 연구 담당자와 상담 희망 |

신원 확인은 병원 승인 인증 절차에서 수행합니다.
이름과 환자번호를 공개 URL에 입력하지 않습니다.

## 3. 임상 문진 문항표

문항마다 모름과 응답하지 않음 선택지를 제공합니다.
분기 문항은 선행 답변에 따라 표시합니다.
문진 버전과 분기 조건도 IRB 자료에 포함합니다.

| 번호 | 질문 초안 | 답변 방식·분기 |
| --- | --- | --- |
| Q1 | 의료진에게 들은 알레르기 질환이 있나요? | 비염·천식·피부염·식품·기타·없음·모름 |
| Q2 | 최근 어떤 증상이 있었나요? | 코·눈·숨참·쌕쌕거림·기침·피부·소화기·기타 |
| Q3 | 증상은 언제 생기거나 심해지나요? | 계절·실내외·직장·집·식사·운동·특별한 시점 없음 |
| Q4 | 특정 물질에 닿은 뒤 증상이 생겼나요? | 있음 / 없음 / 모름 / 응답하지 않음 |
| Q4a | 어떤 물질이며, 얼마나 뒤에 증상이 생겼나요? | 노출·시간·증상·반복 여부 · Q4 있음일 때 |
| Q5 | 노출을 피하면 증상이 줄었나요? | 줄음 / 같음 / 피한 적 없음 / 모름 |
| Q6 | 같은 상황에서 증상이 다시 생겼나요? | 반복됨 / 반복되지 않음 / 재노출 없음 / 모름 |
| Q7 | 음식 섭취 뒤 의심 증상이 있었나요? | 있음 / 없음 / 모름 / 응답하지 않음 |
| Q7a | 음식·양·증상·발생 시간을 알려주세요. | 자유 입력·다중 선택 · Q7 있음일 때 |
| Q7b | 해당 음식을 지금도 먹을 수 있나요? | 증상 없이 먹음 / 피함 / 다시 먹지 않음 / 모름 |
| Q8 | 호흡곤란이나 실신으로 치료받은 적이 있나요? | 있음 / 없음 / 모름 / 응답하지 않음 |
| Q8a | 당시 진료와 처치를 알려주세요. | 응급실·입원·주사·기타·모름 · Q8 있음일 때 |
| Q9 | 현재 알레르기 약을 사용하나요? | 약명·사용 여부·효과·모름 |
| Q10 | 검사나 진료에서 더 설명받고 싶은 점은 무엇인가요? | 선택 자유 입력 |

모름과 빈 답변을 음성 증상으로 바꾸지 않습니다.
설문에서 의심 음식을 다시 먹으라고 안내하지 않습니다.
설문을 위해 약을 중단하도록 안내하지 않습니다.
검사 양성과 임상 반응을 별도 변수로 저장합니다.

## 4. 선택 사후 만족도 설문

설문 식별자는 APAAACI-SAT-01입니다.
설문 자체 버전은 0.1이며 IRB 문서 버전은 0.2입니다.
기준은 별도 survey_definition.json입니다.
6문항과 선택 의견 300자로 구성합니다.
약 2분은 설계 목표이며 예비 조사로 확인합니다.
검증된 척도가 아니며 합산 점수를 만들지 않습니다.

지식 정답을 채점하는 이해도 퀴즈는 사용하지 않습니다.

참여와 별도 사후 알림톡 수신은 선택 사항입니다.
거부와 미응답은 진료와 자료 전달에 불이익이 없습니다.
임상 문진 10~15분과 별도의 추가 부담을 설명합니다.
응답은 연구번호와 등록 검사 회차로 가명 연결합니다.
익명 설문이 아니며 새 식별정보를 받지 않습니다.

### 4-1. 응답자와 열람 분기

| 항목 | 선택 |
|---|---|
| 응답자 | 환자 본인 / 환자 본인 (입력 도움 받음) / 보호자 |
| 확인한 자료 | 결과 보고서 / 카드뉴스 / 둘 다 / 아직 보지 못했어요 |
| 미열람 이유 | 주소나 파일을 열기 어려웠어요 / 아직 볼 시간이 없었어요 |
| 미열람 이유 계속 | 어디에서 보는지 몰랐어요 / 다른 이유가 있어요 / 응답하지 않음 |

입력 도움을 받은 본인의 답은 본인 관점으로 기록합니다.
보호자는 자신이 받은 안내 경험을 답합니다.
보호자의 평가를 소아 본인의 만족도로 바꾸지 않습니다.
미열람자는 이유를 고르고 S1~S6을 건너뜁니다.
미열람자도 선택 의견을 남기거나 그대로 제출할 수 있습니다.

### 4-2. 문항과 응답

| 번호 | 영역 | 문항 |
|---|---|---|
| S1 | 가독성 | 글과 화면을 보기 쉬웠습니다. |
| S2 | 설명 이해 | 검사 결과의 설명을 이해하기 쉬웠습니다. |
| S3 | 생활 안내의 도움 | 생활에서 주의할 점을 이해하는 데 도움이 됐습니다. |
| S4 | 휴대전화 이용 편의 | 휴대전화에서 결과 자료를 확인하기 편리했습니다. |
| S5 | 전달 시점 | 결과 자료를 필요한 시점에 받았습니다. |
| S6 | 전반 만족도 | 전반적으로 이 결과 안내 서비스에 만족합니다. |

| 공통 숫자 응답 | 별도 선택 |
|---|---|
| 1 전혀 그렇지 않다 / 2 그렇지 않다 / 3 보통이다 / 4 그렇다 / 5 매우 그렇다 | 평가하기 어렵다 / 응답하지 않음 |

S7 선택 의견: 더 좋게 바꿀 점이 있으면 적어 주세요.
의견은 300자까지 입력하며 쓰지 않아도 됩니다.
이름, 전화번호, 자세한 건강정보는 적지 마세요.
응답과 자유 의견을 외부 AI나 언어모델에 보내지 않습니다.

### 4-3. 초대·만료·재알림 제안

아래 일정은 작성자 제안이며 IRB가 확정합니다.
기준은 승인 자료의 첫 열람 또는 수령 확인 기록입니다.
열람 기록에는 본인 확인을 완료한 조건을 적용합니다.
연구자의 수령 확인은 방법과 시각을 기록합니다.
두 종류 중 첫 기록 24시간 후 초대합니다.
알림톡 전달 영수증만으로 수령과 읽음을 단정하지 않습니다.

만료는 초대 후 7일과 결과 확정 후 30일 중 이른 때입니다.
초대 때 잔여 응답시간이 24시간 미만이면 보내지 않습니다.
재알림은 초대 후 3일에 최대 1회만 제안합니다.
완료·거절·철회·만료 뒤에는 재알림을 보내지 않습니다.
임상 문진의 14일 창과 3일·7일 최대 2회 알림과 구분합니다.

연구번호와 등록 검사 회차당 설문 1개를 사용합니다.
정정 중에는 예약을 보류합니다.
이미 초대한 회차에는 자동 추가 초대하지 않습니다.
사후 설문만 철회하면 그 예약과 URL을 중단합니다.
전체 연구를 철회하면 모든 사후 예약과 URL도 중단합니다.

### 4-4. 분석 기준

사후 설문의 주 관심 문항은 전반 만족도 S6입니다.
S6의 4~5점 비율은 S6의 1~5점 응답자를 분모로 씁니다.
평가 어려움·응답하지 않음·공란·미열람은 점수에서 뺍니다.
각 비수치 범주와 사유는 별도 건수로 보고합니다.

문항별 분포·유효 응답 수·중앙값·사분위 범위를 제시합니다.
응답자 3구분을 유지하며 보호자 결과를 따로 제시합니다.
성인·소아와 열람 자료 유형도 구분해 기술합니다.
초대 적격·초대·제출·미응답·미발송 수를 함께 보고합니다.
합산 점수와 이해도 정답 점수를 만들지 않습니다.
만족도는 임상 정확성이나 치료 효과의 증거가 아닙니다.

## 7. 알림톡 공통 원칙

병원 알림톡 담당자가 발신 프로필과 양식을 승인합니다.
카카오와 발송대행사의 법인명은 계약 후 기입합니다.
문안에 환자명·검사명·항원·양성 여부를 넣지 않습니다.
URL에는 환자 식별정보를 넣지 않습니다.
자유 입력값은 승인 양식의 변수에 그대로 넣지 않습니다.
