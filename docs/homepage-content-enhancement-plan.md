- 대상 사이트: https://pacen.myadr.care/
- 근거 문서:
  - 『임상진료지침 프로젝트 설명서』 (2026년 5월 1일 업데이트본, 이하 **[설명서]**)
  - 『성인 중증 천식 생물학적 치료제 가이드라인 연구개발계획서』 (RS-2025-02303166, 이하 **[계획서]**)
- 범위: 본 문서는 **페이지 구성(정보구조)과 콘텐츠 내용**에 한정한 제안이며, 기술 구현·디자인·호스팅은 다루지 않음.

## 1. 고도화의 기본 방향: "과제 소개 사이트"에서 "진료지침 공시·활용 플랫폼"으로

현행 홈페이지는 연구 **착수 시점의 과제 안내** 중심으로 구성되어 있다(과제 소개·필요성·목표·방법론). 그러나 [설명서] 기준으로 프로젝트는 이미 다음 단계까지 진행되었다.

- 8개 핵심질문(KQ) **권고문 초안 확정** (전부 조건부 권고, 근거수준 매우낮음~중등도)
- **Tezepelumab(anti-TSLP) 추가**로 대상 약제가 5종 → **6종**으로 확대, KQ 구성 개편
- 델파이 3라운드(71→61→33명)를 통한 **MCID 및 이상반응 허용 기준 합의 완료**
- 환자 108명 + 의료진 52명 대상 **가치·선호도 조사 완료**
- 중요한 건강결과(outcome importance) 전문가 조사 완료

[계획서]가 명시한 홈페이지의 역할은 ① 권고안 PDF 공시, ② 진료지침 기반 온라인 플랫폼(맞춤형 치료 결정 지원) 게시, ③ 의료인·환자용 소책자 배포 창구다. 또한 "환자용 설명자료 개발"은 **최소요구성과(가중치 20%)** 로 지정된 공식 산출물이다.

따라서 고도화의 핵심은 **이미 확보된 개발 산출물(권고안·MCID·환자 조사 결과)을 페이지로 승격**시키고, 계획서상 약속된 **환자 대상 콘텐츠 영역을 신설**하는 것이다.

## 4. 페이지별 콘텐츠 상세 방안

### 4.1 Introduction

**(1) 중증천식 가이드라인 (메인 페이지)** — 기존 앵커 구조(#Introduction/#Necessity/#Target/#Contents/#Methodology)는 유지하되 내용을 [설명서] I-1로 갱신:

- 과제 소개: 과제 공식 정보 명기 — 사업명(환자중심 의료기술 최적화 연구사업, PACEN), 과제번호(RS-2025-02303166), 주관기관(서울아산병원), 연구책임자, 연구기간(2025.4~2026.3), 위임 학회(대한천식알레르기학회).
- 과제 필요성: [설명서] I-1의 최신 서술로 교체 — 국내 천식 환자 약 208만 명·유병률 4%, 중증 천식이 천식 의료비의 50% 이상 점유, OCS 의존 20% 이상과 사망 위험, KoSAR 기준 생물학적 치료제 처방률 약 30%(제2형 염증 85% 대비 낮음), 국내 GRADE 기반 지침 부재.
- 개발 내용: **약제 6종 체계로 갱신** — 표 1(약제·표적·주요 적응 대상: omalizumab/anti-IgE, mepolizumab·reslizumab/anti-IL-5, benralizumab/anti-IL-5Rα, dupilumab/anti-IL-4Rα, tezepelumab/anti-TSLP)을 메인에 게시. "계획 수립 시점 5종 → tezepelumab 도입으로 6종 검토"라는 경과 설명 포함.
- 연구 방법론: GRADE·EtD 개요만 남기고, 상세는 신설되는 방법론 콘텐츠(4.6 참고)로 링크 위임.
- 페이지 하단에 "권고안 요약 바로가기" CTA 추가 — 방문 목적의 대부분이 권고안 확인일 것이므로 첫 화면에서 1클릭 도달 보장.

**(2) PACEN 프로젝트** — 1단계 연구(HC19C0318: 중증 천식 생물학적 제제 비교평가 후향연구, 환자 136명, 80% 이상 양호한 반응, anti-IL-5 효과–호산구 감소 연관 / dupilumab–FeNO 감소 연관)의 핵심 결과를 요약하고, "1단계 실사용 근거 → 2단계 진료지침 개발"의 연계 서사를 명확히 한다.

**(3) 대한천식알레르기학회** — 개발 위임 관계와 함께 [계획서]의 독립성 조항(학회·연구비가 지침 내용에 영향을 주지 않음)과 이해상충(COI) 관리 원칙을 명시. 학술대회·심포지엄을 통한 공유 계획 언급.

**(4) 연구진 소개 (대폭 개편)** — [설명서] I-2의 3개 위원회 체계로 재구성:

- 개발위원회(20명): 이름·소속·전공에 **담당 핵심질문(KQ1~8, MCID, 치료반응 요인)** 열을 추가한 표.
- 운영위원회(5명): 팀장·간사·방법론 전문가·MCID 조사·온라인 모듈 개발 등 역할 명시.
- 자문위원회(13명, 가나다순).
- 환자 참여: 개발위원회 내 환자 위원 참여와 환자 설문(108명) 반영 사실을 소개 — 환자 중심성(PACEN 사업 취지)의 대외적 근거.
- COI 공시(부록 IV-6) 링크.

**(5) ★ 개발 경과** — [계획서] 수행일정과 [설명서] 진행 상황을 타임라인으로: 킥오프 → PICO 확정·COI 작성 → outcome importance 조사 → 체계적 문헌고찰(검색일 2025-12-31, Medline·Embase·Cochrane·KoreaMed·ClinicalTrials.gov) → MCID 델파이(3라운드) → 권고안 합의 → 공청회·외부검토 → 학회 인증. 미완료 단계는 "진행 중" 상태로 표기해 투명성 확보.

### 4.2 Key Questions (최우선 고도화 대상)

**(1) ★ 권고안 요약 (섹션 랜딩)** — [설명서] II-0 표를 그대로 웹 표로:

| KQ | 핵심질문(요약) | 권고문(요약) | 근거수준 | 권고등급 |
|---|---|---|---|---|
| 1 | Omalizumab 사용 여부 | 조절되지 않는 중증 **알레르기성** 천식에서 추가 치료 제안 | 중등도 | 조건부 권고 |
| 2 | Mepolizumab 사용 여부 | 조절되지 않는 중증 천식(**호산구성**)에서 추가 치료 제안 | 중등도 | 조건부 권고 |
| 3 | Reslizumab 사용 여부 | 동일(**호산구성**) | 중등도 | 조건부 권고 |
| 4 | Benralizumab 사용 여부 | 동일(**호산구성**) | 중등도 | 조건부 권고 |
| 5 | Dupilumab 사용 여부 | 동일(**제2형 염증성**) | 낮음 | 조건부 권고 |
| 6 | Tezepelumab 사용 여부 | 조절되지 않는 중증 천식에서 추가 치료 제안 | 중등도 | 조건부 권고 |
| 7 | 6개월 이상 안정 조절 시 단계적 감량 | 단계적 감량 제안 | 매우 낮음 | 조건부 권고 |
| 8 | 반응 불충분 시 교체·추가 | 다른 생물학적 제제로 교체 제안 | 매우 낮음 | 조건부 권고 |

함께 게시할 해설 콘텐츠: 근거수준 4단계(⊕⊕⊕⊕~⊕◯◯◯)의 의미 표([설명서] 표4.2), 권고등급 4단계(강한/조건부 × 사용/미사용)의 의미 표(표4.3), "조건부 권고 = 환자 가치·선호와 임상 상황에 따라 다른 선택 가능"이라는 안내문.

**(2) ★ KQ1~KQ8 개별 페이지** — 8개 페이지를 동일 템플릿으로 표준화:

1. 핵심질문 전문
2. 권고문 + 권고등급 + 근거수준 (박스 처리)
3. PICO 구성 (대상/중재/비교/결과)
4. 근거 요약: 체계적 문헌고찰·메타분석 핵심 결과 (완성 시까지 "근거 프로파일 준비 중" 표기)
5. EtD 고려사항: 이득-위해 균형, 환자 가치·선호(I-7 조사 결과 인용), 비용·급여, 실행가능성
6. 임상 적용 시 고려사항: 표현형·생체표지자 조건(호산구, FeNO, IgE), 국내 급여기준은 최신 고시 확인 안내
7. 검색전략(PRISMA)·참고문헌 링크 (부록 IV-2)

KQ7·KQ8은 Response evaluation 페이지(MCID 기준)와 상호 링크 — "반응 평가 → 감량 또는 교체 판단"의 진료 흐름을 내비게이션으로 연결.

**(3) 유의사항** — 현행 페이지가 구 KQ 체계(구 KQ6 = "임상적으로 의미 있는 반응이란?")를 게시 중이라면, 신 체계(KQ6 = Tezepelumab, 반응 평가는 MCID 섹션으로 이동)로 반드시 교체. 구 체계 잔존 시 지침 본문과 홈페이지가 서로 모순된다.

### 4.3 Prediction & Response Evaluation

**(1) Prediction (치료 반응 예측)** — [계획서]의 '진료지침 기반 온라인 플랫폼' 구상을 이 메뉴의 정체성으로 명확화:

- 도입 콘텐츠: 중증 천식의 이질성(표현형·내재형)과 생체표지자(혈중 호산구, FeNO, 총 IgE, 알레르기 감작) 기반 약제 선택 원리 소개 ([설명서] I-1.2~1.3 요약).
- 약제 선택 흐름도(플로우차트): "호산구 ≥300? → 예/아니오", "알레르기성 + 고 IgE? → 예/아니오" 식의 분기 구조를 정적 콘텐츠(그림)로 먼저 게시하고, 향후 인터랙티브 도구로 발전시키는 2단계 접근.
- 치료반응 요인: 개발위원회의 '치료반응 요인' 파트 산출물(반응 예측 인자 문헌 정리)을 게재할 자리 마련.
- 면책 고지: "본 도구는 진료지침 권고안의 이해를 돕기 위한 참고 자료로, 개별 환자의 진료 판단을 대체하지 않음" 문구 필수.

**(2) Response evaluation (치료 반응 평가)** — 델파이 합의가 완료된 콘텐츠를 전면 반영 (완성도 높은 자산이므로 즉시 게시 가능):

- 건강결과별 MCID 표 ([설명서] 표6.1): 악화율 ≥20% 감소 / 연간 악화 <1회 / OCS ≥50% 감량 / OCS 유지용량 <5 mg/day / ACQ 0.5 / ACT 3 / AQLQ 0.5 / FEV1 ≥10% 또는 ≥0.2 L. "핵심적/중요한" 분류 표기 포함.
- 이상반응 허용 기준 표 (표6.2): Grade 1(허용, 합의율 89.9%) / Grade 2(치료 결정에 영향, 71.0%) / SAE(1건이라도 발생 시 중단·변경·재평가, 81.2%) / 신규 악성종양(합의 미도달, Evidence Profile에만 반영 — 별도 처리 사실도 투명하게 공개).
- 합의 과정 요약: 델파이 3라운드 개요(대상: 국내 중증천식 전문가, 1라운드 71명 → 2라운드 61명 → 3라운드 33명, 합의 기준: 동의율 >60% & 비동의율 <20%).
- MCID의 활용 설명: 메타분석 효과크기 판정 기준, EtD 이득 평가 기준, 권고등급 결정 근거로 사용됨 ([설명서] I-6).
- 중요한 건강결과 선정 결과 (표5): 천식 악화·OCS 사용 = 핵심적, 조절도·폐기능·삶의 질·이상반응 = 중요한.
- KQ7(감량)·KQ8(교체) 페이지로의 연결 링크.

### 4.4 Chatbot

- **★ 이용 안내 페이지 신설**: ① 챗봇의 지식 범위(본 진료지침 전문·부록 기반 RAG임을 명시), ② 두 모델의 차이를 이용자 관점에서 설명(로컬 모델: 원내·보안 중시 / API+Graph DB: 관계형 질의에 강함), ③ 한계·면책(의료적 판단 대체 불가, 최신 급여기준은 별도 확인), ④ 예시 질문("호산구 500인 OCS 의존 환자에게 어떤 약제가 권고되나요?", "mepolizumab 반응 평가는 언제, 무엇으로 하나요?" 등).

### 4.5 ★ For Patients (환자 마당) — 신설 필수

성과지표(환자용 설명자료, 가중치 20%)의 공식 게시 공간이자 PACEN 사업의 환자 중심성을 보여주는 영역.

- **환자용 가이드라인 요약**: 8개 권고안을 쉬운 우리말로 재서술 (전문용어 최소화, "제안한다 = 담당 의사와 상의하여 결정할 수 있다는 뜻" 등 권고등급의 환자용 해설 포함). 개발 완료 시 환자용 소책자 PDF 연동.
- **생물학적 치료제 알아보기**: 6종 약제를 환자 눈높이에서 — 어떤 환자에게 쓰는 약인지(알레르기성/호산구성/제2형 염증), 투여 방법·간격, 기대 효과(증상·악화·스테로이드 감량), 주의할 점. [설명서] 표1을 쉬운 표현으로 변환.
- **환자 가치·선호도 조사 결과**: 108명 조사 결과 공개 — 치료 결정 시 우선순위(1위 천식 개선 효과, 이후 경제적 부담·이상반응·편의성), 기대 효과 중요도(1위 증상 개선, 2위 스테로이드 부작용 감소), 지불 의향(월 25만원 미만 선호 다수). "환자의 목소리가 권고안에 이렇게 반영되었습니다"라는 설명과 함께.
- **FAQ**: 급여기준·비용, 치료 기간, 감량·중단 가능성(KQ7의 환자용 해설), 효과가 없을 때(KQ8), 부작용 대처 등.

## 6. 콘텐츠 운영 공통 원칙

1. **일관된 표기**: 근거수준(⊕ 4단계)·권고등급(강한/조건부) 표기와 색상 배지를 전 페이지에서 통일.
2. **급여기준 면책**: 약제 적응증·급여 관련 서술마다 "최신 허가사항·급여 고시 확인 필요" 고지 ([설명서] 표1 각주 방침 준용).
3. **의학적 면책**: 모든 임상 콘텐츠·챗봇·예측 도구에 "진료 판단을 대체하지 않음" 문구.
4. **버전·출처 표기**: 페이지별 최종 갱신일, 근거 검색일, 원문서(지침 전문) 섹션 참조 표기.
5. **이중 언어 고려**: 메뉴는 현행 영문 유지 시 한글 부제 병기 (예: "Key Questions — 핵심질문과 권고안"). 지침의 1차 이용자(국내 임상의사·환자)를 고려해 본문은 국문 우선.
6. **미완성 콘텐츠의 투명한 처리**: 아직 확정되지 않은 항목(근거 프로파일, 갱신 방법, 공청회 결과 등)은 감추지 말고 "개발 진행 중"으로 표기 — 개발 과정의 투명한 공개는 [계획서]가 명시한 신뢰 확보 전략.
