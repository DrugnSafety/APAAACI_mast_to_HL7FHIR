## B. 순위 없는 병렬 카드 — 구성안 (질문 3-2-1)

동작하는 데모를 별도 제작하였다 (benralizumab 카드만 KQ4 실측치, 나머지는 가상 예시값 명시). 카드 한 장의 해부:

```
┌──────────────────────────────────────────────┐
│ Benralizumab (anti-IL-5Rα)      [적격 · 부합 높음] │  ← ① 적격성 + 부합 강도
│ 근거: KQ4 프로파일 · 6 RCT · 조건부 권고(호산구성)      │
├──────────────────────────────────────────────┤
│ 악화율   RAR 0.45 (0.29–0.60) ⊕⊕⊕◯  [MCID 충족] │  ← ② outcome별 행:
│ OCS     −50% (−64.1~−35.9)  ⊕⊕⊕◯  [경계]      │     효과(CI)+근거수준+MCID 배지
│ ACQ     −0.32 (−0.45~−0.19) ⊕⊕◯◯  [MCID 미달] │     (미니 CI 바 시각화)
│ FEV1    +0.14 L (0.09–0.19) ⊕⊕◯◯  [MCID 미달] │
├──────────────────────────────────────────────┤
│ 이 환자 기준: 연간 악화 3.0 → 약 1.4회 (−1.6회)      │  ← ③ 기저치 결합 절대효과
├──────────────────────────────────────────────┤
│ 안전성: 전체 AE 위약 유사 · SAE 유의차 없음            │  ← ④ 안전성 요약
│ 투여: 8주 간격 SC (초기 3회 4주) · 급여 등재           │  ← ⑤ 실용 정보(비용·편의)
└──────────────────────────────────────────────┘
```

핵심 원칙:

- 카드 간 **순위·우열 서술 없음**. 정렬 기본값은 가나다/기전순이며, 선호도 가중 적용 시에만 "우선 검토 후보" 그룹핑이 표시된다(그때도 점수 산출 내역을 투명하게 노출).
- 비적격 약제는 숨기지 않고 **회색 카드 + 사유**("통년성 알레르겐 감작 없음 → 알레르기성 천식 기준 미충족")로 표시 — 필터의 투명성.
- 부합 강도는 KQ 문서의 하위군·등록기준에서 도출: 예) 호산구 450/µL 환자 → benralizumab "부합 높음(≥300 하위군 근거 일관)", 150–299 환자 → "부합 중간(<300군 효과 불확실 — KQ4 하위군 서술 인용)".
- 모든 수치에 근거수준(⊕)과 출처(KQ 문서 섹션)를 병기.

## C. Network Meta-analysis (질문 3-2-2)

### C-1. "약제별 메타분석 자료를 통합하면 NMA인가?" — 아니오, 그러나 80%는 준비됨

- 각 KQ의 쌍별(pairwise) 메타분석 결과(요약 효과)를 **나란히 놓는 것은 NMA가 아니다**. NMA는 별개의 통계 모형으로, **연구 단위 데이터**를 하나의 네트워크(모든 약제–위약 비교)로 동시에 모형화하여 약제 간 **간접 비교 추정치**(예: benralizumab vs dupilumab)를 산출하는 재분석이다.
- 다만 NMA의 진짜 비용은 통계가 아니라 체계적 문헌고찰(검색–선정–추출–질평가)이며, **이 부분이 KQ1~6에서 이미 완료**되어 있다. KQ4 문서의 포레스트 플롯이 보여주듯 연구별 추정치가 정리되어 있으므로, 남은 작업은 ① KQ 간 추출 테이블 통합(연구 × 약제 × outcome × 효과 × SE), ② 시점·정의 정합(PICOTS의 12–60주 창은 이미 공통), ③ 모형 적합(빈도론 netmeta 또는 베이지안), ④ 방법론 전문가 검토다.

### C-2. KQ별 상세 자료 수준이면 수행 가능한가 — 가능하되, 두 가지 구조적 한계를 설계에 반영

**성립 요건 (KQ4 문서로 확인됨)**: 연구별 효과 추정치 ○ / 공통 비교군(위약) ○ / 공통 outcome 프레임(AAER·OCS·ACQ·FEV1·AQLQ·AE) ○ / 연구별 등록기준 명세(Table 4-3) ○

**한계 1 — 별 모양(star-shaped) 네트워크**: 모든 비교가 위약 경유이고 head-to-head가 없어 닫힌 고리(closed loop)가 없다. 따라서 직접·간접 추정치의 일치성(consistency) 검정이 **원천적으로 불가능**하며, 결과 전체가 transitivity(이행성) 가정에 의존한다.

**한계 2 — 이행성 위협이 실재**: Table 4-3이 보여주듯 시험 모집단이 설계적으로 다르다(호산구 ≥300 층화, ≥150 단독, 알레르기성/IgE, T2 조건 등). 즉 "위약"이라는 공통 노드의 환자들이 시험마다 다른 사람들이다.

**완화 전략 (KQ 자료가 가능하게 하는 것)**:
1. **공통 하위군 네트워크로 제한** — 예: '호산구 ≥300' 하위군만으로 네트워크 구성. KQ4의 사전 계획 하위군 자료(SIROCCO·CALIMA·MIRACLE 층화)가 이 접근을 실제로 가능하게 한다. 다른 KQ도 동일 하위군 자료가 있다면 가장 방어 가능한 NMA가 된다.
2. 기저 호산구·악화력 등 효과수정인자에 대한 메타회귀·민감도 분석
3. CINeMA / GRADE-NMA 확실성 등급을 결과에 병기
4. 기존 발표 NMA(예: Kyriakopoulos 2024 Eur Respir Rev — 설명서 참고문헌에 이미 인용됨)와 교차 검증

**활용 수위 권고**: NMA 산출물(리그 테이블·SUCRA)은 **홈페이지 전면의 순위표가 아니라** ① MCDA 효과 축 점수의 내부 근거, ② 전문가용 방법론 부록으로 활용. 공개 화면에는 "약제 간 직접 비교 근거는 없음" 고지를 유지한다.

### C-3. 엄밀성과 유용성의 동시 달성 (질문 3-2-3) — 3-레이어 원칙

| 레이어 | 내용 | 논리적 오류 방지 장치 |
|---|---|---|
| 1. 사실 | outcome별 병렬 카드 (위약 대비 효과 + CI + 확실성 + MCID) | 약제 간 비교 서술 금지, 모든 수치에 출처·확실성 |
| 2. 매칭 | 환자의 **지배적 문제**(잦은 악화형 / OCS 의존형 / 폐기능 저하형 / 삶의 질 저하형)와 **표현형 부합 강도**로 카드 하이라이트 | "어느 약이 더 좋다"가 아니라 "이 환자 문제에 대한 각 약제 근거의 강도"를 보여줌 — 서술 단위가 약제 간이 아닌 약제-환자 간 |
| 3. 결정 | 선호도 가중(MCDA)은 마지막 단계에서, 산출 내역 전체 공개. 결과는 '우선 검토 후보'까지만, 최종 결정은 공유 의사결정 | 가중치·점수·근거 링크가 함께 출력되는 '진료 상담용 요약'으로 마무리 |

이 구조에서 도구의 실용 가치는 "정답 제시"가 아니라 **후보 축소(적격성) → 근거 구조화(카드) → 대화 자료(요약 출력)** 세 가지로 정의된다. 현장 의료진에게는 진료 중 5분 안에 근거를 정리해 주는 도구, 환자에게는 자신의 선호가 반영되는 과정을 보여주는 도구가 된다.

## D. 환자 선호도 설문과 개별 입력의 연결 (질문 3-3)

설문조사(N=108)와 개별 환자 입력은 **다른 역할**을 하며, 세 가지 방식으로 연결된다.

### 설문조사의 세 가지 역할 (이미 확보된 자산)

1. **축의 발굴**: 환자에게 중요한 결정 요인이 4축(개선 효과 / 경제적 부담 / 이상반응 / 편의성)임을 확인 — MCDA의 기준 구조 자체가 설문에서 나옴
2. **기본 가중치(prior)**: 평균 순위(효과 1.5 > 부담 2.37 > 이상반응 2.6 > 편의 3.35)를 정규화하면 대략 **효과 35 : 비용 25 : 이상반응 25 : 편의 15** 수준의 인구 기본값이 된다 (정확한 환산 방식은 운영위 확정 사항)
3. **검증된 문항 형식**: '100점 배분'과 '순위 지정'이라는, 환자들이 실제로 응답 가능했던 입력 형식을 제공

### 개별 환자 연결의 세 가지 방식

| 방식 | 동작 | 장점 |
|---|---|---|
| (a) 프리셋 기본값 | 도구 초기 가중치 = 설문 평균. 환자가 아무것도 입력하지 않아도 "한국 중증천식 환자 평균 선호"가 반영된 결과 표시 | 진입 장벽 0. "환자 조사 결과가 기본값"이라는 서사 |
| (b) 동일 문항 재사용 | I-7 설문의 100점 배분 문항을 입력 UI로 그대로 제공 → 개인 가중치 벡터 w 생성 → 가중합. **"나의 선호 vs 환자 평균" 비교 시각화** 병행 | 개인화의 정석. 설문-도구-지침이 같은 언어를 씀 |
| (c) 페르소나 프리셋 | 설문 응답 분포에서 유형 도출(예: 효과 최우선형 65.7%가 1순위 / 비용 민감형 24.1% / 편의 중시형) → 1클릭 버튼 | 짧은 진료 시간에 실용적 |

### 계산 구조 (요지)

```
우선순위 점수(약제 d) = Σ_k  w_k × s_k(d)     (적격 약제만 대상)

w_k : 환자 가중치 (100점 배분 → 합 1로 정규화; 미입력 시 설문 평균)
s_k : 약제 속성 점수 (0–100 정규화)
  s_효과   = 기저치 결합 절대 기대효과 (v3에서 NMA 점수로 대체 가능) ← Tier 2 입력 소비
  s_비용   = 급여 적용·본인부담 구간 점수                    ← 운영위 확정 필요
  s_이상반응 = KQ 근거 프로파일 AE 종합 (대부분 위약 유사)
  s_편의   = 투여 간격·경로·자가투여 (예: 8주 SC > 4주 SC > 2주 SC > IV)
```

워크드 예시(데모 수치): 호산구 450·악화 3회/년·OCS 7.5mg 환자가 가중치를 효과 50/비용 30/이상반응 10/편의 10으로 배분하면, 효과 축이 지배해 절대 악화 감소가 큰 약제가 상위로; 같은 환자가 비용 60/효과 20으로 바꾸면 본인부담이 낮은 약제가 상위로 이동 — **가중치에 따라 우선순위가 바뀌는 과정 자체를 보여주는 것**이 [계획서] MCDA 모델의 취지다.

### 주의
