# 약제별 제약사 환자용 브로셔·자료 수집 (10차)

> 수집 방식 주의: 본 작업 환경의 네트워크 정책상 외부 PDF 파일의 직접 다운로드가 차단되어(프록시 정책 거부), **검증된 공식 링크 모음**으로 제공한다. 링크는 2026-08 웹 검색으로 확인한 것이며, 파일 확보는 일반 브라우저에서 링크 접속으로 가능하다.
>
> **저작권 주의**: 제약사 브로셔는 각 사 저작물이다. 홈페이지(pacen.myadr.care)에 **파일을 직접 게재(재배포)하려면 각 제약사 한국법인의 허락이 필요**하며, 안전한 방식은 ① 공식 페이지로의 링크 제공, ② 제약사에 게재 허락 요청(학회 명의), ③ 진료실 비치용 인쇄물은 제약사 영업부를 통한 정식 공급 요청이다. FDA 라벨(Patient Information/Instructions for Use 포함)은 미국 연방정부 저작물로 퍼블릭 도메인이라 링크·활용이 자유롭다(단, 영어·미국 허가 기준).

## 종합 판단·다음 단계

1. **국문 환자용 브로셔는 6개 약제 모두 공개 다운로드가 없다** — 국내 제약사는 환자용 인쇄물을 의료진 경유로만 배포하는 관행. 학회 명의로 6개사에 일괄 요청(홈페이지 게재 허락 포함)하는 것이 가장 효율적.
2. 공개 링크가 확보된 것: 졸레어 국문 제품정보(노바티스 공식), 듀피젠트 영문 환자 브로셔 2종(미국·영국), 싱케어 FDA 라벨(퍼블릭 도메인).
3. 재배포 대신 **Resources(자료실) 페이지에 '공식 자료 바로가기' 링크 목록**으로 게재하면 저작권 문제 없이 즉시 가능 — 사이트맵의 자료실 세부항목으로 추가 제안.
4. 자가주사 교육 수요(페르소나 P3)에는 각 사 미국 사이트의 단계별 사용법·비디오 링크가 당장 활용 가능하며, 국문 버전은 제약사 요청 결과에 따라 교체.
