# 이중 관점 UI · 투약 스케줄 · 약가 Q&A (7차 아이디에이션)

확정된 결정: ① 의료진 가중은 우선 근사값(핵심 2:중요 1)으로 진행, 원자료 수령 시 정밀화 ② 환자 문제별 자동 재가중 **채택** (✅ 구현) ③ omalizumab 용량표 수령 (✅ 구현) ④ 약가는 검색 수행 (부분 확보, 하단)

---

## 1. 환자·의료진 관점의 UI 반영 — "합성하지 말고, 병기하라"

### 의미론적 원칙

두 가중은 서로 다른 질문에 대한 답이다: 환자 가중 = "환자에게 무엇이 중요한가"(가치·선호), 의료진 가중 = "전문가가 무엇을 중시하는가"(임상 판단 관점). GRADE/EtD와 공유 의사결정(SDM) 원칙상 **가치 판단의 주인은 환자**이므로 기본 계산은 환자 가중이 맞고, 둘을 평균해 하나로 합성하는 것은 권장하지 않는다 — 합성 비율이 임의적이고, 누구의 가치가 반영됐는지 불투명해지며, 관점 차이(상담의 재료)를 숨겨버린다.

### 권장 UI 구성 (✅ 데모 구현)

| 화면 | 효과 축 가중 | UI 요소 |
|---|---|---|
| **의료진 보기** | 기본 = 환자 설문 가중, 토글로 의료진 가중 전환 가능 | 가중 출처 토글 + **관점 일치도 표시** + 계산 상세 |
| **환자 보기** | 환자 가중 고정 (토글 미노출 — 단순성) | 쉬운 문장 카드, 점수 숨김 |

핵심 장치는 **관점 일치도(concordance) 표시**다: 환자 가중과 의료진 가중 각각으로 우선 후보를 계산해 — 합성 없이 —
- 1순위가 같으면 "관점 일치: 1순위 동일(약제명)" → 강한 신호
- 다르면 "관점 상이: 환자 가중 A vs 의료진 가중 B — 상담 포인트" → 그 자체가 진료실 대화 재료

즉 "동시에 반영한 단일 결과"를 만드는 대신, **두 관점의 결과를 나란히 보여주고 일치 여부를 판정**한다. 이것이 SDM의 정신(차이를 드러내고 대화로 해소)과 MCDA의 투명성 요건을 동시에 만족한다. 참고: 선호도 4축(효과/비용/이상반응/편의) 100점 배분은 어차피 **그 환자 본인**의 입력이므로 관점 문제가 없고, 관점 분기는 '효과 축 내부 지표 가중'에만 존재한다.

## 2. 점수화 방식 권장 순위 — "초과확률 > 로그 > 상한"이 맞다

- **상한 1.5**: 지배 문제만 해결. 1.5 초과 정보 소실 + 점추정치 편중 문제 그대로.
- **로그 감쇠**: 지배 문제를 더 부드럽게 해결(순서 보존). 그러나 **점추정치 편중 문제는 전혀 해결하지 못한다** — 순전히 크기의 스케일 변환이라 CI가 넓든 좁든 같은 점수.
- **MCID 초과확률**: 지배 문제(0~1 자연 유계)와 점추정치 편중(불확실성 통합)을 **동시에** 해결하고, NMA 논문의 해석 프레임과 일치. 그래서 최우선 권장.

초과확률의 특성 두 가지는 인지하고 쓸 것: ① MCID 경계에 정확히 걸친 효과는 0.5가 된다(benralizumab OCS −50% → 50% — 합리적 해석), ② '미달 확실' 지표들이 0 근처로 몰려 점수가 희소해진다 — 확실한 지표만 점수를 받는다는 뜻이므로 결함이 아니라 특성이다. 정규근사 가정은 메타분석 요약 효과에는 표준적으로 수용된다.

## 3. 비용 — 기간, 스케줄, 약가

### 3-1. 계산 기간: 두 창을 병기하고, 주 표시는 '반응 평가 시점까지'

의사결정 관점에서 두 질문이 다르다: "시작하면 평가까지 얼마가 드는가"(시도 비용)와 "지속하면 연간 얼마인가"(유지 부담). 권장:

- **주 표시: 치료 시작 → 반응 평가 시점까지 총액** — 환자가 처음 약속하는 금액이며, 초기 부하용량 차이(아래)가 정확히 이 창에서 드러난다. 평가 시점은 지침 확정을 따르되 확정 전 임시 16주.
- **부 표시: 첫 12개월 / 유지 12개월** — 연간 비교와 지속 부담.

### 3-2. 약제별 투약 스케줄 표 초안 (허가사항 대조 확인 필요 ⚠)

| 약제 | 초기 | 유지 | 16주까지 횟수 | 첫해 | 비고 |
|---|---|---|---|---|---|
| Omalizumab | 용량표 (✅ 구현) | 2주 또는 4주 | 5회(q4w)/9회(q2w) | 13/26회 | 회당 75~375mg — IgE×체중 표 |
| Mepolizumab | 100mg q4w | 동일 | 5회 | 13회 | |
| Reslizumab | 3mg/kg IV q4w | 동일 | 5회 | 13회 | 체중 비례 용량·병원 투여 |
| Benralizumab | 30mg q4w ×3회 | q8w | 4회(0·4·8·16주) | 8회 | |
| Dupilumab ⚠ | **초회 부하 2배(2 vial)** 후 q2w | q2w | 9회분+초회분 | 26회+초회분 | 부하 400/600mg·유지 200/300mg 구분은 적응증별 — 허가사항 확정 필요 |
| Tezepelumab | 210mg q4w | 동일 | 5회 | 13회 | |

"초회 2 vial"은 dupilumab의 부하용량이 대표 사례이며 ✅ 데모 표기에 반영했다. 표 전체는 게시 전 허가사항 원문 대조가 필요하다(특히 dupilumab의 적응증별 용량 구분).

### 3-3. Omalizumab 용량표 — ✅ 구현 (전사 검증 필요)

첨부된 IgE(30~1300)×체중(20~150kg) 매트릭스를 lookup 함수로 구현했다. 회당 용량(75~375mg)과 간격(2/4주)을 자동 판정하고, 회색 영역(권장 불가)은 "용량표 권장 범위 밖"으로 처리한다. 예: IgE 120·체중 65kg → 300mg q4w → 연 13회. **주의: 이미지에서 전사한 것이므로 게시 전 국내 허가사항 원문 표와 셀 단위 대조가 필요하다** (전사 오류 1칸이 용량 오류가 된다).

### 3-4. 약가 검색 결과 — 부분 확보

뉴스 검색으로 확인된 것:

| 항목 | 확인 내용 |
|---|---|
| 졸레어 150mg | **등재 상한가 271,700원**, 75mg 143,000원 (등재 시점 기준) — 이후 약가 인하 고시 기사가 존재하므로 최신가 재확인 필수 |
| 급여 연혁 | 졸레어 2020 급여, 싱케어·누칼라 2023.11 급여(누칼라는 RSA), 파센라 2024 급여 적정성 인정 |
| 미확보 | 누칼라·파센라·싱케어·듀피젠트(천식)·테즈파이어의 구체 상한금액 — 뉴스에 수치 없음 |

✅ 데모에는 확인된 졸레어 가격만 반영해 omalizumab 비용 라인(예: 300mg = 150mg×2 vial = 회당 543,400원 × 연 13회 ≈ 706만원/년, 표시가 기준)을 계산하고, 나머지 약제는 "약가 미확정 — 고시 확인 필요"로 정직하게 표시했다. **정확한 전 약제 약가는 심평원 '약제급여목록 및 급여상한금액표'(월별 엑셀 고시 파일)에서 제품코드로 조회해야 한다** — 팀에서 해당 파일(또는 6개 품목 상한가 스크린샷)을 주시면 즉시 반영 가능하다. 급여 적용 상태(특히 듀피젠트 천식·테즈파이어)는 시점별 변동이 커서 게시 시점 재확인이 필요하다.

## 이번 회차 구현 요약 (데모)

1. 환자 문제별 자동 재가중 — 채택 결정 반영 (악화 ≥3회 → 악화 ×2, OCS 사용 → OCS ×2, 체크박스로 온오프, 계산 상세에 조정된 가중치 노출)
2. 관점 일치도 표시 — 환자/의료진 가중 각각의 1순위 비교 배지
3. Omalizumab 용량표 lookup + 연간 투여 횟수 + 비용 계산(확인된 약가 한정)
4. 전 약제 연간 투여·비용 라인 (미확정 약가는 명시적 표기)

## 대기 중인 입력

1. I-5/I-7 의료진 설문 원자료 (정밀 가중) — 요청됨
2. 약제급여목록 상한금액 (6개 품목) — 심평원 고시 파일
3. Dupilumab 적응증별 용량 스케줄 확정 (허가사항)
4. Omalizumab 용량표 전사 검증 (허가사항 원문 대조)
5. 반응 평가 시점(주 표시 기간 창) — 지침 확정 대기
