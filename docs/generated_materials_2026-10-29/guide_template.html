검사값부터 생성 자료까지
같은 사진 ID로 확인하세요.

검사 29장에 저장한 3개 입력을 사용했습니다.
전체 목록은 87세트와 __FILE_COUNT__개 파일을 제공합니다.

원본 검수와 문진을 마친 뒤 실제 환자 자료로 사용하세요.현재 자료는 검사값 기반 연구용 미리보기입니다.
임상 검토와 외부 FHIR 검증은 수행하지 않았습니다.

1. 자료를 선택하세요.

  1. 생성 자료 목록을 여세요.
  2. 왼쪽 목록에서 사진 ID를 고르세요.
  3. 참조 전사, OpenAI OCR, Local OCR 중 고르세요.
  4. ‘검사값 전체’에서 입력을 확인하세요.
  5. 리포트와 카드뉴스를 확인하세요.
  6. 필요한 파일의 ‘다운로드’를 누르세요.

예: O03의 참조 전사를 고르면 해당 입력의 자료를 봅니다.
OpenAI OCR을 누르면 같은 사진의 다른 입력으로 바뀝니다.

광학문자인식(OCR)은 사진에서 글자와 값을 추출하는 단계입니다.
자료 생성은 저장한 값을 현재 서비스에 입력하는 별도 단계입니다.

전체 ZIP

사진 ID와 입력별 폴더로 정리했습니다.
각 입력은 13개 파일과 세트 목록을 담습니다.

저장된 PDF를 확인하세요.

  1. 리포트 PDF를 여세요.
  2. 카드뉴스 PDF를 여세요.
  3. 모든 페이지와 연구용 배너를 확인하세요.
  4. 파일 옆 SHA-256을 확인하세요.
  1. ZIP 파일을 내려받으세요.
  2. ZIP 압축을 푸세요.
  3. 압축을 푼 폴더의 index.html을 여세요.
  4. 목록에서 필요한 자료를 선택하세요.

인터넷 연결 없이 미리보기와 파일 열기를 제공합니다.

4. 입력 세 가지를 구분하세요.

참조 전사기존 전사와 리드 검토 기록
불확실 표시 18행 포함
OpenAI OCR저장 모델: gpt-5.4
실행일: 2026-10-09~10
Local OCR저장 모델: qwen3.8:27b
실행일: 2026-10-09~10

세 입력 모두 현재 로컬 서비스로 자료를 생성했습니다.
한국어 리포트와 카드뉴스는 로컬 템플릿이 만듭니다.
새 OCR 실행과 외부 모델 호출은 하지 않았습니다.

원문 수치, 미만 표기, Class 0, 단위를 보존합니다.
OCR 중복과 누락도 입력에 남습니다.
참조 SPT의 평균과 판정은 인쇄 크기에서 계산합니다.
출처 기록에서 계산 내역을 확인하세요.

피부단자검사(SPT)는 인쇄된 크기와 대조값을 사용합니다.
혈액검사 MAST는 인쇄된 Class와 수치를 사용합니다.
현재 파일 수는 MAST 25장, SPT 4장입니다.
UniCAP 실제 비교 파일은 없습니다.

생성 자료의 항목 수는 OCR 정확도 점수가 아닙니다.
중복 행과 서비스의 항원 묶음에 따라 개수가 달라집니다.
분모를 적용한 OCR 성능은 비교 페이지에서 확인하세요.

5. 해석 전에 범위를 확인하세요.

  • 환자 이름, 생년월일, 번호, 날짜를 제외했습니다.
  • 환자 대신 사진 ID를 사용합니다.
  • 원본 사진은 ZIP에 포함하지 않습니다.
  • 문진과 스크리닝은 제공받지 않았습니다.
  • 문진 답을 ‘아니오’로 추측하지 않았습니다.
  • 임상 관련성과 알레르기 진단은 미확정입니다.
  • 알레르기 FHIR는 unconfirmed 상태입니다.
  • 문진 FHIR는 생성하지 않습니다.
  • 근거 후보와 누락 상태는 그대로 남깁니다.
  • 생성 자료도 실제 검사값을 포함합니다.

참조 전사는 독립 임상의의 이중 판독본이 아닙니다.
기존 불확실 18행은 입력의 검토 표시에서 찾으세요.
현재 서비스 결과를 임상 진단으로 확정하지 마세요.

이름을 제거해도 검사값은 실제 건강정보입니다.
공유 전에 대상과 범위를 확인하세요.

리포트에는 문진 미제공 안내를 넣었습니다.

생성 기록은 해당 수정도 기록합니다.

PDF는 저장된 HTML을 오프라인으로 렌더링했습니다.
전체 ZIP은 HTML과 PDF를 함께 제공합니다.
세트 목록은 두 형식의 해시를 기록합니다.
