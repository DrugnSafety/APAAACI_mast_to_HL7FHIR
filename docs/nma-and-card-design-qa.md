## 1. NMA — "이 자료로 시행할 수 있을까?"

### 1-1. 자료 인벤토리 확인 결과: **가능하다**

5개 문서를 직접 확인한 결과, 각 KQ 문서는 동일한 표준 구조를 갖고 있다:

| 문서 요소 | NMA에서의 역할 | 확인 |
|---|---|---|
| SoF (GRADE 근거요약표) | outcome별 요약 효과 + 확실성 | KQ5 p7, KQ7 p7 등 확인 |
| **주요 지표 Forest Plot (연구별 추정치)** | **NMA 데이터셋의 원료** — 연구 단위 효과·CI가 수치로 기재됨 | 전 문서 확인 |
| 부록 1. 포함된 연구의 특성 | 모집단 비교(transitivity 평가) | 확인 |
| 부록 2. RoB 2 | 연구 질 → NMA 확실성 평가(CINeMA) 입력 | 확인 |
| **부록 4. 하위군 분석 Forest Plot** | **공통 하위군 네트워크 구성의 재료** (호산구·FeNO·알레르기·ICS 용량·과거 악화 횟수별) | KQ5·KQ6 확인 |

Excel이 없어도 된다 — 포레스트 플롯에 연구별 점추정치와 95% CI가 수치로 인쇄되어 있으므로, 이를 구조화 테이블로 옮기는 작업(문서당 1~2시간 수준의 전사 작업)만 하면 NMA 입력 데이터셋이 완성된다.

**실제 추출 예시 (문서에서 그대로 옮긴 값):**

| study | drug | outcome | measure | est | lo | hi | population note |
|---|---|---|---|---|---|---|---|
| Bleecker 2016 (SIROCCO) | benralizumab | AAER | RAR | 0.49 | 0.37 | 0.64 | eos 층화(≥300/<300) |
| FitzGerald 2016 (CALIMA) | benralizumab | AAER | RAR | 0.72 | 0.54 | 0.95 | eos 층화 |
| Nair 2017 (ZONDA) | benralizumab | AAER | RAR | 0.30 | 0.17 | 0.53 | eos ≥150, OCS 의존 |
| Harrison 2021 (ANDHI) | benralizumab | AAER | RAR | 0.51 | 0.39 | 0.65 | eos ≥150+추가조건 |
| Lai 2024 (MIRACLE) | benralizumab | AAER | RAR | 0.26 | 0.19 | 0.36 | eos 층화 |
| Castro 2018 (QUEST) | dupilumab | AAER | RAR | 0.54 | 0.43 | 0.68 | 제2형 지표 |
| Corren 2017 (PATHWAY) | tezepelumab | AAER | RAR | 0.28 | 0.18 | 0.46 | 표현형 무관 |
| Menzies-Gow 2021 (NAVIGATOR) | tezepelumab | AAER | RAR | 0.44 | 0.37 | 0.53 | 표현형 무관 |
| Wechsler 2022 (SOURCE) | tezepelumab | AAER | RAR | 0.69 | 0.44 | 1.09 | OCS 의존 |
| Yang 2025 (DIRECTION) | tezepelumab | AAER | RAR | 0.26 | 0.17 | 0.39 | — |

하위군 행도 동일하게 추출 가능: benralizumab eos ≥300 RAR 0.48 (KQ4), tezepelumab eos ≥300 0.26 (0.20–0.32) / eos <300 0.44 (0.24–0.63) / FeNO ≥25 0.24 / 알레르기성 0.31 (KQ6 부록4) 등.

**범위 주의**: NMA 대상은 **KQ1~6 (약제 vs 위약)** 이다. KQ7(감량 vs 지속)·KQ8(교체 vs 지속)은 비교 구조가 달라 위약 네트워크에 들어가지 않는다 — 이 둘은 별도의 쌍별 근거로 남는다.

### 1-2. 이해 확인: "대상군이 유사한 study로 제한해서 NMA" — 정확한 이해

맞다. 권장 분석 구조는 두 갈래다:

- **주 분석: 공통 하위군 네트워크** — 예: '호산구 ≥300' 하위군 추정치만으로 각 약제-위약 비교를 구성해 하나의 네트워크로 결합. 시험 모집단의 설계적 차이(이행성 위협)를 가장 직접적으로 통제하는 방법이며, 부록 4의 하위군 자료가 이를 가능하게 한다.
- **민감도 분석: 전체 모집단 네트워크** — 각 KQ의 주 분석 추정치 전체로 구성하되, 결과를 '민감도'로만 제시.

한 가지 방법론적 주의: 하위군 자료의 질이 KQ마다 다르다. **KQ4는 무작위배정 단계의 사전 층화**(SIROCCO·CALIMA·MIRACLE) 기반인 반면, **KQ6의 하위군은 문서에 명시된 대로 사후(post-hoc) 분석**이다. 공통 하위군 NMA를 하더라도 이 차이를 확실성 평가에 반영해야 한다.

### 1-3. "그럼 환자가 해당 group일 때만 NMA 결과를 적용할 수 있겠네?" — 정확하다, 그리고 이것이 도구의 규칙이 된다

이 통찰이 도구 설계의 핵심 규칙이 된다:

```
환자 입력 → 공통 하위군 소속 판정
  ├─ 호산구 ≥300 (NMA 분석 모집단과 부합)
  │    → 병렬 카드 + [약제 간 비교 참고치(NMA·확실성 등급)] 모듈 활성화
  └─ 그 외 (예: 호산구 150–299, 비호산구성)
       → 병렬 카드만 표시 (약제 간 비교 비활성 + 사유 고지:
         "약제 간 비교 근거는 호산구 ≥300 환자군에서 도출되어 이 환자에게 적용되지 않습니다")
```

적용 범위가 좁아지는 것은 단점이 아니라 도구의 정직성이다. 실제로 임상 질문("이 환자에게 어떤 약제가 더 나은가")에 대해 근거가 존재하는 환자군과 존재하지 않는 환자군을 구분해 보여주는 것 자체가 근거중심 진료지원의 역할이다. 비부합 환자에게는 쌍별 카드(각 약제 vs 위약)와 표현형 부합 강도가 여전히 제공된다.

## 2. 병렬 카드 상세 설명

카드 한 장 = "이 약제를 이 환자에게 썼을 때 기대할 수 있는 것"의 구조화된 요약. 위에서 아래로 5개 층:

| 층 | 내용 | 데이터 출처 | 갱신 주기 |
|---|---|---|---|
| ① 적격성·부합 강도 | 적격/비적격 + 사유, 부합 강도(높음/중간) | 권고문 조건 + 허가·급여 기준 + KQ 하위군·등록기준 | 고시 변경 시 |
| ② 효과 프로파일 | outcome별 행: **환자 기저치 결합 절대효과(주 표시)** + 위약 대비 상대효과·CI(부 표시) + MCID 판정 배지 + GRADE ⊕ | KQ 근거 프로파일 (Figure X-1, SoF) | 지침 개정 시 |
| ③ 안전성 요약 | 전체 AE·SAE·약제 특이 반응 한 줄 | KQ 바라지 않는 효과 섹션 | 지침 개정 시 |
| ④ 실용 정보 | 투여 간격·경로·자가투여, 급여 상태 | 허가사항·고시 | 고시 변경 시 |
| ⑤ 선호도 반영 점수 | 가중합 + 축별 기여 분해 (투명 공개) | ②③④ + 환자 가중치 | 실시간 계산 |

카드 간에는 우열 서술이 없고, 정렬만 선호도 점수를 따른다(산출 내역 공개). 비적격 카드는 회색+사유로 표시해 필터의 판단 근거를 숨기지 않는다.

## 3. "환자 기저치 기반 실제 변동 수치 + 95% CI를 보여주는 게 낫지 않나?" — 낫다. 논리적 오류 없으며, 반영 완료

**결론: 제안이 옳고, 방법론적으로도 표준이다.** 데모를 절대효과 주 표시로 업데이트했다.

- **원리**: 상대효과(RAR)와 그 CI를 환자 기저치에 곱하면 절대 기대효과와 그 CI가 된다. 예: 기저 3회/년 × RAR 0.45 (0.29–0.60) → 기대 약 1.4회/년 (95% CI 0.9–1.8). 이는 GRADE SoF 표의 절대효과(assumed risk × relative effect) 계산과 동일한 표준 기법이다.
- **문서 자체의 지지**: KQ5·KQ6 본문이 명시적으로 "실제 예방되는 악화 횟수의 절대 크기는 환자의 치료 전 기저 악화 빈도에 따라 달라질 수 있다"고 서술한다. 즉 개발위원회의 서술 프레임과 일치한다.
- **MD 지표(ACQ·FEV1·OCS%)는 이미 절대량**이므로 변환 없이 그대로 보여주면 된다.

단, 세 가지 라벨 규칙을 지켜야 논리적 오류가 없다 (데모에 문구 반영):

1. **이 CI는 '평균 효과'의 신뢰구간이다** — "비슷한 환자군에서 평균적으로 기대되는 효과의 범위"이지, **이 환자 개인 결과의 예측구간이 아니다**(개인 간 변동은 훨씬 크다). "당신의 결과가 이 범위에 있을 것"이라고 쓰면 그것이 논리적 오류다.
2. **상대효과 일정 가정** — 기저 위험이 달라도 상대효과가 유지된다는 가정 하의 환산임을 밝힌다(표준적이며 수용되는 가정이나, 가정은 가정이다).
3. **기저값의 측정 오차** — 지난 1년 악화 횟수는 변동이 크고 평균 회귀가 있다. "최근 12개월 기준" 입력 정의를 명확히 하고, 기저 0회 환자는 환산 대상이 아님을 처리한다(데모 구현됨).

## 4. 점수 계산에 선호도가 반영되는 방식 — 구체 설명

데모의 실제 계산을 그대로 풀면:

```
1) 가중치 정규화
   환자 입력(100점 배분): 효과 35 / 비용 25 / 이상반응 25 / 편의 15
   → w = (0.35, 0.25, 0.25, 0.15)   합이 100이 아니면 비율로 정규화

2) 축별 점수 s_k (0–100)
   s_효과   = 이 환자의 절대 악화 감소 ÷ 적격 약제 중 최대값 × 100
             (예: 기저 3회 환자 — teze 3×(1−0.37)=1.89회 감소 → 100점,
              benra 3×(1−0.45)=1.65회 → 87점, dupi 3×(1−0.54)=1.38회 → 73점)
   s_비용   = [가상 점수 — 실제 산정식은 5절]
   s_이상반응 = [가상 점수 — KQ 근거 프로파일 AE로 대체 예정]
   s_편의   = 투여 간격·경로 기반 (8주 SC 95 > 4주 SC 75 > 2주 SC 60 > 4주 IV 40)

3) 종합 = Σ w_k × s_k
   benra: 0.35×87 + 0.25×72 + 0.25×87 + 0.15×95 = 30.5+18.0+21.8+14.3 ≈ 84.5
   → 카드에 축별 기여(30.5/18.0/21.8/14.3)를 막대로 분해 표시
```

선호도가 바뀌면 w만 바뀌고 s는 그대로이므로, "비용 민감형" 프리셋(25/45/20/10)을 누르는 순간 비용 축 기여가 커지며 순서가 재배열된다 — 어느 축이 결과를 움직였는지 기여 막대로 즉시 확인된다. 이것이 "가중치에 따라 우선순위가 달라지는 유연성"([계획서] MCDA 모델)의 구현이다.

한계 고지: 효과 축이 현재 '악화'만 반영한다. OCS 의존 환자라면 OCS 감량이 핵심 outcome이므로, v2에서 효과 축을 환자의 지배적 문제에 따라 구성(악화 중심 / OCS 중심 / 복합)하는 옵션이 필요하다 — 운영위 결정 사항.

## 5. 비용 — "실제 약제 비용을 계산한 거야?" — 아니다 (가상 점수). 실제 산정식은 다음과 같다

현재 데모의 비용 점수(55~72)는 **임의의 가상 점수**다. 실제 구현 시 산정식:

```
연간 본인부담 추정액(d) =
    투여당 약가(심평원 약제급여목록 상한금액, 고시 기준)
  × 연간 투여 횟수(허가 용법 기반)
  × 환자 본인부담률
  + 투여 행위료·방문 비용(선택 반영)

s_비용(d) = 적격 약제들의 연간 본인부담 추정액을 0–100으로 역스케일
```

필요한 데이터와 주의점:

| 항목 | 내용 |
|---|---|
| 약가 | 건강보험심사평가원 약제급여목록의 상한금액. 위험분담제(RSA) 환급이 있는 약제는 표시가와 실제가가 다를 수 있음 — 표시가 기준임을 고지 |
| 연간 투여 횟수 | 용법에서 도출: benralizumab 첫해 8회/유지 약 6.5회, mepolizumab·tezepelumab 13회, dupilumab 26회, reslizumab 13회(IV), omalizumab은 IgE·체중 기반이라 **환자별 용량 가변** — 입력값으로 계산하거나 구간 표시 |
| 본인부담률 | 급여 인정 여부·외래/입원·산정특례 해당 여부에 따라 상이 — 단일 값 단정 불가, 시나리오(급여 인정 시/비급여 시) 병기 권장 |
| 갱신 | 약가·급여 기준은 고시로 수시 변경 — 비용 축에 "기준일" 표기 필수 |

이 산정은 보험·급여 실무 확인이 필요한 영역이므로 **운영위 + 급여 전문가 검토 사항**으로 분류한다. 참고로 환자 설문의 지불의향 분포(월 25만원 미만 다수)는 s_비용의 구간 경계 설정에 활용할 수 있다.

## 정리 — 이번 회차로 확정 가능한 것

1. NMA: KQ1~6 문서 수준으로 **실행 가능**. 주 분석은 호산구 ≥300 공통 하위군 네트워크, 전체 모집단은 민감도. 산출물은 도구 내 '약제 간 비교 참고치' 모듈(환자가 해당 하위군일 때만 활성)로 사용.
2. 병렬 카드: 환자 기저치 결합 **절대효과+CI를 주 표시**로 확정 (라벨 3원칙 준수). 데모 반영 완료.
3. MCDA: 가중치×축점수 구조와 기여 분해 공개 방식 유지. 효과 축의 outcome 구성(악화 단독 vs 환자 문제별)은 운영위 결정.
4. 비용 축: 현재 가상 — 연간 본인부담 산정식으로 대체하는 작업이 별도 필요 (급여 전문가 검토).
